## 实测间距和草地

从构建产物实际加载的八块网格提取踏面轮廓，检查全部 28 对石板，轮廓两两分离。整体外接范围为世界 X 3.871–6.798、Z 0.832–1.922。小径距水潭底座至少 1.469，距右柱脚至少 1.292，单位均为场景单位。

| 草缝 | 场景边到边距离 | 全景踏面投影最近距离 |
| --- | ---: | ---: |
| D–E 细缝 | 0.070 | 约 1.30 个渲染采样格 |
| F–G 斜缝 | 0.124 | 约 1.92 个渲染采样格 |
| B–C 开口 | 0.213 | 约 3.76 个渲染采样格 |

草地避让使用和踏石网格相同的轮廓。和基准版逐点对照，240 株普通草与 144 朵花的位置和属性一致。旧缝间草有四处通过宽缝校验并保留，短草根中心距最近石边为 0.068–0.128 场景单位。窄缝在像素画面里以露出草底为主。后续实体青苔可试放 A 的外角和 E 的端部，B、D 保留较大的亮色石面。 [共享踏石轮廓](../../src/scene/pathLayout.ts) · [植被实测记录](evidence/step-2/validation.json)

## 网页验证

`npm run build`（含 TypeScript 检查）通过。使用生产构建在 Chromium 浏览首页，操作「全景 → 水潭 → 全景」和「像素画面 → 正常画面 → 像素画面」，确认场景时间正常推进、画面切换成功，页面和资源加载均无报错。额外检查了可选浮动花瓣的启动和避让入口。冻结时间的前后对照中，两张截图的像素差异都落在小径及其近旁范围。 [浏览器与绘制记录](evidence/step-2/validation.json)
