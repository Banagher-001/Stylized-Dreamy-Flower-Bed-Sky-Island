# 第六步 · 踏石改造终检

成品版本为 `sakan-paving-final-bbc12628`。首页原机位能读出左端小石和宽石的错位、中段细长石的斜向以及右端单石收尾。近景能看清 B、H 的断角，A、E 的实体主苔斑和 C、F 的低矮边苔。实拍与随时间变化的云影均达到本轮标准，成品采用第五步的石面、配色、苔斑和短草参数。

## 终检数据

| 对象 | 实测结果 |
| --- | --- |
| 八块踏石 | 八块均为闭合实体，共 956 个三角面。复核全部 28 对占地轮廓，石板两两分离。正常近景可见倒角、厚薄变化与贴地边线。 |
| 四处青苔 | A、C、E、F 共用一个光照材质，合计 380 个三角面。苔体底面嵌入石面约 0.002，各自的顶面轮廓都有支撑。全景连续苔绿依次为 3、2、4、2 个渲染采样格。 |
| 三处关键草缝 | 草地平面实测 D–E 为 0.070、F–G 为 0.124、B–C 为 0.213。 |
| 五簇短草 | 草尖距地面 0.064–0.079。按真实草叶顶点及最大 ±2.5° 风摆复核，整个摆动范围的最小净距下限为 0.0554 场景单位。 |
| 植被批次 | 四个实例批次，含 240 簇普通草、五簇缝间短草和 144 朵花。 |

恢复环境播放后，着色器的风时间与云影偏移随帧推进。同机位取样显示 B、D、H 的石面随云影逐步变暗。强云影下，A、C、E、F 的近景连续苔绿仍为 21、12、26、11 格。 [实际网格与云影取样](evidence/step-6/validation.json)

## 网页与成品包

- 生产构建通过 TypeScript 检查。解压后用包内脚本启动，Chromium 验证了上下滚轮运镜、全景与水潭往返、像素与正常画面切换、环境播放和暂停。
- 390 × 844、DPR 2 的 Chromium 触屏模拟中，进入稳定阅读后可从「水潭」打开庭院现场。现场加载了八块踏石、四处青苔与五簇短草，切换项目档案并关闭后返回水潭阅读位置。
- 项目档案的「当前庭院 · 全景」及分享图已采用最终场景在 5.322 秒的同机位 WebP 渲染。浏览器核对了两个地址提供的图像和最终成品相同。 [庭院档案封面](../../src/assets/courtyard-orb-cover.webp) · [分享图](../../public/share-cover.webp)
- 交付 ZIP 内含 69 个生产文件、启动脚本和校验清单。 [成品 ZIP](../../release/sakan-paving-final-bbc12628.zip) · [SHA-256 校验值](../../release/sakan-paving-final-bbc12628-SHA256SUMS) · [验收数据](evidence/step-6/validation.json)

安装 Node.js 22.12 或更新版本后，完整解压成品包。Windows 可以双击包内 `START-PREVIEW.cmd`，也可以在解压目录运行以下命令，并打开终端显示的本机网址。

```bash
node scripts/preview-site.mjs --port 0
```
