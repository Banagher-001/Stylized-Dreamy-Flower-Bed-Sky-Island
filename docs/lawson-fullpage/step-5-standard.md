## 3. 状态与重试

prepared 为尚未创建；loading 为等待当前原页；约 12 秒无确定结果进入 slow。实际 fatal 显示、API error 或 body error 优先判为 error；只有当前 API ready 为 true 且无错误才 ready。HTML load 不代表成功；未确认的等待不伪造失败。

每次观察重新读取当前 document/API，以实例代次和文档代次隔离旧结果。原重试刷新当前 iframe 文档，重新观察且保留原按钮；宿主重试先清理旧实例，再创建新实例。旧 load/error/timer 不能覆盖新状态。

loading 保留原加载界面；slow/error 提供清楚的宿主提示和重试，同时保留原错误/控制台操作。提示不得遮挡原页，ready 后收起。所有状态返回和独立打开可达，不制造进度。

关闭后，同视口恢复原位置/触发焦点；改尺寸/字号后按原锚点比例恢复。原播放/暂停设置保留，导览不自动继续。离开 live 会销毁原页，重新进入按原默认状态加载，不增加跨退出状态保存。
