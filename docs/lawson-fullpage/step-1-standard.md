# 新版第一步：原网页版本冻结与完整功能基线

适用目标：将罗森原网页完整嵌入个人网站的大尺寸作品层，原有页面、控件、逻辑、模型和本地依赖保持原版。此次只补齐独立原页的基线，主站集成属于后续步骤。

## 执行要求

1. 核对两个仓库本地/远端提交和工作区；核验旧核查封存材料及原运行输入。保留所有已有工作。
2. 固定 HTML、CSS、JavaScript、GLB 与 vendor 的完整依赖清单、大小和 SHA256，保留原目录关系。
3. 记录原默认界面、时间、相机、面板状态、画质与自动运行行为。原页已有自适应变化按实际记录。
4. 盘点全部静态控件、动态灯光控件、快捷键、17 类物件及自主运行流程。已验证项引用具体旧证据，新增缺项用原按钮、真实键鼠/触摸补核。
5. 原公开状态接口及测试观察包装只辅助读取结果；观察包装须调用原函数、保留原实参和原时钟，不能替代真实点击或制造反馈。
6. 单独记录帮助/文档与实际绑定的差异，原页自身问题与设备限制单列，不能伪装正常。随机行为说明观察覆盖，不宣称穷尽所有分支。
7. 记录就绪/错误信号、原全屏及漫游退出、重试和刷新默认行为。源码和依赖不修改，原问题本步只记录。

## 结果分类

- 原页正常：真实操作或条件相符的既有证据已确认。
- 原页已有问题：独立原页可复现，附影响与复现步骤。
- 设备/浏览器限制：说明设备与支持范围。
- 需补核：证据不足，不能视作通过；本步结束前关键入口须有明确结论。

## 完成判据与产物

版本、文件、用户操作清单完整；关键操作无未解释的缺项；原有问题有复现及影响记录；原始运行文件及旧封存材料保持完整。产物为新基线、完整文件表、功能对照表、操作证据和问题清单。

证据只写入 `docs/evidence/lawson-fullpage-step-1/`，工具位于 `tests/lawson-fullpage/`。旧 `lawson-integration-step-1` 资料保持原样；旧文档中关于重排原页控制台、修改原页手机界面及加入子页通信桥等建议不作为新版执行要求。当前不接入正式页面、不推送 GitHub、不发布网站。
