## 2. URL 解析约定

iframe 与“独立打开”共享同一入口解析函数，按 Vite 网站 base 及当前站点位置处理。当前构建 `base: './'`，不能把地址固定为根路径 `/experiments/lawson/index.html`。

第三步测试根路径与仓库同名项目子路径，二者都读取同一个实际 dist，没有改写原 HTML。正式宿主接入仍需要对自己的 URL 解析函数和部署方式再做集成检查。

禁止使用第二步样稿的 `?standalone=lawson` 地址，也不指向私有仓库 raw 文件。它们分别属于设计示例和开发来源，不是运行入口。

## 3. 第四步按设计实现宿主外层

采用第二步 [设计定稿](step-2-design.md) 和 [接口契约](step-2-interface.md)：

1. C2 默认罗森，庭院可切，站点 ID/运镜区间与 stop 保持原值。
2. 作品注册表提供 `lawson` / `courtyard`，公开打开调用为 `open(projectId, tab, trigger?)`。
3. 罗森紧凑工具栏常规 56px、小屏/小横屏 48px；文字放大允许自然换行，剩余空间给原页。
4. 活动作品统一提供身份和 tab，不能把所有 live 视为庭院现场。
5. 庭院绘制门控、导览停止、媒体互斥、阅读 capture/restore 及焦点恢复由宿主协调。
6. 庭院失败与罗森加载分别判断，档案和返回入口持续可用。
7. 庭院现有档案视频及早期帧图继续保留，不能用设计样稿的简版档案替换。

第四步的外层准备工作不能伪装成第五步真实 iframe 已接入；以各阶段验收范围为准。

## 4. 第五步挂接原页面

- 只在罗森 live 按需创建 iframe，一次最多一个；档案、关闭和 dispose 清理实例。
- 正式 iframe 占满外层内容区，不采用样稿图片的 contain、缩放、裁切或固定比例。
- 保留原文档、CSS、JS、控制台和本地依赖，不注入桥接脚本。
- 读取原 `__LAWSON__.ready/error`、body ready 标记和 fatal 实际显示；错误优先，HTML load 不等于场景就绪。
- 原重试会刷新 iframe 当前文档，观察器必须重新取 document/API，并使旧文档结果失效。
- 宿主重试及关闭先失效旧实例回调，再移除，避免晚到的 ready 重开旧场景。
- 允许原全屏，鼠标锁定沿用用户手势与原逻辑；焦点在原页内时不将 Esc 直接用于关闭整个作品。
- 罗森现场时主庭院实际停绘；关闭恢复原阅读、作品选择和播放设置，自动导览等待手动继续。

## 5. 原版状态与已知问题

原默认时间为黄昏 18.5，8 组灯光开启，控制台展开、屋顶可见、漫游关闭。真实初始相机在 hero 坐标，但原 UI 缓存的默认 cameraMode 为 orbit。原画质可自适应变化；不能为匹配测试而改默认值。

R 复位惯性、漫游退出缓存、起点 W/S 碰撞、N 文档差异、车体点击说明、手机布局、减少动态与 pauseAll 等原问题均保持原样。完整说明见 [原页问题](original-issues.md)，原功能列表见 [功能矩阵](feature-matrix.md)。

第三步的最小操作核查不是最终完整功能对照。真实 iframe 权限、全屏/锁定/Esc、输入隔离、主庭院停绘和跨尺寸返回由第四至第六步验证；第七步对照原 41 控件和 17 类点击完成正式集成回归。
