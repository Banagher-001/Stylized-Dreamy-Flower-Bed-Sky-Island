## 6.2 明确隔离对象与观察方式

| 对象 | 实际检查 | 通过条件 |
|---|---|---|
| 文档/脚本 | 当前 iframe 地址、Window/Document、原 API 和引擎来源；正常加载过程的请求 | 原页在自己的文档运行，没有把原场景脚本/引擎塞入主站；父/子状态按各自归属读写 |
| 样式/DOM | 主站标题、导航、作品索引、查看器工具栏的关键布局/计算样式；原页 UI 展开、隐藏、画质切换后再核对 | 原页操作不改主站布局、字体或可见性，宿主样式不覆盖原控制台 |
| 启动范围 | 冷启动主站→选择瓶中海洋→看档案→进入现场 | 进入现场之前没有运行 HTML 请求或隐藏 iframe；封面和档案图片可以正常加载 |
| 状态归属 | 项目、现场/档案、实例、Document、canvas 与故障记录 | 旧实例/旧文档/旧画布不写当前作品状态；重复点击当前现场不叠加实例 |

使用浏览器正常输入和真实网络/图形条件。测试侧可以保存原只读诊断、记录 DOM/绘制与可信事件；若包装绘制函数计数，必须将原参数原样委托一次，不能改变原调度或结果。测试观察代码只存在测试上下文，不写进正式原 HTML。

不写 ready、相机、模拟状态或错误字段来制造结果，不篡改 Date/performance/RAF/dt/随机数，不派发假的图形、可见性或输入事件冒充真实操作。

验收：隔离结论来自浏览器实际效果、对象和生命周期，而非只看 iframe 标签存在或控件数量。

## 6.3 完整检查输入、焦点与主站阅读隔离

先记录主站阅读锚点/位置、当前作品、导览、动效选择与焦点；在瓶中海洋内进行下列原生操作：

| 输入 | 实际动作与核查 |
|---|---|
| 鼠标 | 左键旋转、右键平移、滚轮远近；核对原相机真实变化，主站阅读位置与石柱运镜进度不被推进 |
| 面板滚动 | 指针在原控制台滚动到下方项目再返回；原控制台滚动，不把滚动传给主站 |
| H | 在原画布焦点下隐藏/恢复原 UI，原恢复按钮可用；主站 UI 不受影响 |
| Space | 画布焦点暂停/继续原模拟；原 input/按钮焦点按原保护及原生激活行为执行，不能顺带切换主站环境播放 |
| Escape | 原编辑模式中退出放置，查看器保持打开；宿主工具栏有焦点时按宿主规则关闭。若当前全屏，先尊重浏览器退出全屏的行为 |
| Tab/Shift+Tab | 从宿主工具栏实际进入原控件并返回；记录原生焦点序列，允许 Firefox 先停在子 Document，不要求各浏览器一步相同，不新增全局键盘陷阱 |
| 触摸 | 手机模拟中原生点按面板、单指旋转和双指缩放，核对原相机变化及主站没有误滚动；触摸模拟与真机分开标注 |

分别在主站原来播放、原来暂停的条件下检查。实际启用减少动态偏好时，遵守主站既有选择；瓶中海洋仍按原版播放语义运行，不擅自让父/子播放开关同步。

验收：每次输入只产生其所属页面的预期结果。关闭后焦点回到有效入口，页面可继续滚动、导航与阅读；没有残留 inert、滚动锁或不可见遮罩。

## 6.4 连续生命周期与迟到任务检查

Chromium 至少完成 10 轮有效往返，覆盖下列组合；这是总轮数，不要求每个组合各做 10 轮。其他引擎按 6.9 的代表范围执行。

| 组合 | 必查结果 |
|---|---|
| 正常进入→操作→返回→重开 | 原页可操作；返回移除旧 iframe，重开从原默认状态开始 |
| 现场→档案→现场 | 档案期间无活动原页；重开是新文档，不偷偷恢复旧参数/装饰 |
| 当前现场重复点击 | 复用当前实例，不多出 iframe、载入尝试或观察任务 |
| 瓶中海洋→罗森→瓶中海洋 | 使用真实可达的关闭、作品选择和入口；旧实例先退出，标题/反馈/重试归属正确 |
| 瓶中海洋→庭院→瓶中海洋 | 庭院使用主站场景，独立网页按需卸载/创建，不同时驻留两个独立作品 |
| 载入中返回或去档案 | 旧请求送达后仍不挂回原现场，不污染当前作品 |
| slow/error 重试后立刻去档案、返回或打开另一作品 | 旧尝试作废，新响应/错误/事件不能改当前现场 |

每轮记录操作序列、当前项目/标签/状态、iframe 数量及身份、Document/timeOrigin、旧 Frame 是否 detached、退出后观察窗口。观察至少覆盖共用容器的最长常规轮询间隔，并另外释放受控的旧响应检查迟到结果。

创建 RAF 尚未执行的极快退出与“iframe 已创建但网络响应未到”分开记录。若未实际触发前一种时序，保留取消路径的代码审查与未观测说明，不能用后者冒充已经覆盖。真实同 iframe 重载也要作为新 Document 验证，旧 ready 不能继续生效。

验收：任一查看器最多一个活动独立网页，退出后为零；当前身份与状态正确，旧文档、定时器和监听没有继续影响主站。短时显存读数不能替代这些证据，也不据此声称显存同步归零。

## 6.5 网络、错误文档与意外导航

| 条件 | 构造与期望 |
|---|---|
| 正常根路径/项目子路径 | 实际访问根路径及 `/portfolio-check/` 前缀；内嵌和独立打开指向同一原成品，资源返回正确内容而非 SPA 回退页 |
| 真实慢载入 | 延迟实际请求并等待至少 12 秒，loading→slow；退出/档案/独立打开/重试可用，释放原字节后可自然 ready，首次响应不抹去已出现的 slow |
| HTTP 404 / HTTP 200 错误内容 | 返回明确错误文档，不能因 HTTP 成功或 load 事件宣布 ready；原按钮重试能恢复原页 |
| 请求被中断/无法取得可靠文档 | 按真实可观察信号显示 error，或无可信失败信号时 loading→slow；不虚构浏览器没提供的 HTTP 信息，不无限显示假 ready，用户始终能退出和重试 |
| 同 iframe 正常重载 | 新 Document、原初始化与加载反馈重新确认；旧参数按原重载规则处理 |
| 意外同源路径 | 真实导航至非预期文档，不沿用之前的 ready；提供不可用反馈和重试 |
| ready 后导航到 about:blank | 区分第一次创建的暂时空白和已运行文档被空白替代；确认为后者时转 error，不能沿用旧就绪或无限等待，并保留恢复/退出 |
| 文档变为不同源/不可访问 | 用本步自有的不同本地 origin 构造真实导航；宿主保留正常阅读/工具栏，不出现未捕获跨源异常，不能把旧就绪当成功 |

错误文档、网络延迟和导航仅在测试服务器/浏览器中构造，不修改正式运行 HTML。跨源用自有本地服务，正常路径不因测试增加外部联网依赖。每项故障退出或重试后，再完成一次真实可用操作，证明恢复的是当前原页。

验收：正常、慢、不确定、明确失败与文档替换有对应去向；异常页面不占死主站，不自动无限重试，不借旧 ready 隐藏故障。

## 6.6 父/子图形故障与能力

初始化故障按 `window === top` / `window !== top` 明确选择父/子，不根据 initScript 时可能还是 `blank` 的 pathname 选择；记录实际被阻止的原 WebGL 创建和原错误结果。

| 场景 | 必须取得的结果 |
|---|---|
| 子页 WebGL 初始化失败 | 原页真实创建失败，宿主 error；档案/独立入口/返回可用；放开能力后由原重试按钮建立新文档恢复 |
| 子页实际上下文丢失 | 使用原 renderer 的真实 WEBGL_lose_context 扩展；在当前连接 canvas 上记录 trusted 原事件，宿主识别故障 |
| 丢失后真实恢复事件 | 原 ready 仍为真也不能恢复为 ready；当前文档维持要求重新载入的提示，新文档才重新判定 |
| 故障后退出并打开罗森/庭院 | 原画布后续事件与错误不污染另一作品；各作品仍按各自原信号判断 |
| 主站 WebGL 创建失败 | 个人介绍/作品档案可读，瓶中海洋可用其自己的图形能力运行；庭院按主站既有不可用规则处理 |
| 主站真实上下文丢失/恢复 | 有真实扩展能力时检查主站现有恢复与提示；子页仍按自己的状态运行，不借父/子故障互相误报成功。恢复后再检查主站阅读与庭院 |

不派发图形事件、不手工改原 error/ready，不为检测额外创建图形上下文。扩展/恢复实际不支持时记录具体条件；不得把人工构造事件标成真实故障通过。

原网页已有的全屏等能力按实际界面核查：以真实用户操作进入、退出后再操作；若浏览器拒绝，应有准确能力说明且普通现场/下载/返回可用。瓶中海洋原页没有的全屏或指针锁动作不作为新增功能，不通过新增按钮/全局转发来凑测试。已有能力持有时退出作品，应释放属于该实例的全屏/指针锁。

验收：父/子故障独立归属，故障不困住查看器；已支持的原能力保留，不支持的能力不被假报可用。

## 6.7 尺寸、下载、覆盖资源与返回

尺寸在第五步基础上补最窄及异常反馈布局：桌面 1440×900、1280×720；手机 390×844、844×390；至少补 320×740。检查主站根字号 200%，明确这是字体放大测试，不冒充系统/浏览器缩放。

至少一组在同一已就绪原文档中连续改变视口/方向，保持 iframe 与 timeOrigin，用户已改变的参数不被重置，canvas CSS 尺寸和像素尺寸按原 resize/DPR 规则变化。进入、slow、error 时都检查宿主返回/重试/独立打开可达，长错误提示换行不遮原控制台，原控制台可展开/折叠和滚动到末端。

原截图使用真实原按钮下载；至少两组实际子视口/DPR，按 `canvas CSS × min(DPR,2)` 核对 PNG 尺寸并查看内容。保留文件与文件名、下载失败信息，不用宿主截图 API 冒充原下载，不要求含 DOM 面板。

资源与返回分开核查：

1. 选择实际会持续绘制的主庭院条件，先证明覆盖前绘制在推进；作品覆盖后父页停止持续绘制，子页可以正常推进，去档案也不能提前让被覆盖庭院恢复。
2. 关闭后旧 Frame detached、iframe 为零；原主站播放则恢复绘制，原来暂停则保持暂停。原模拟暂停仍绘制，不能当作卸载证据。
3. 同尺寸返回核对阅读位置；变尺寸返回核对原语义锚点及焦点，不能机械要求旧 scrollY 不变。关闭后实际滚动/导航一次，确认锁与遮罩清理。
4. 用原按钮实际启动主站导览后打开作品，确认停止；返回不自行续播，用户主动继续时仍可运行。

验收：大尺寸现场可操作，小屏主要入口/原控制台可达，下载保留；返回恢复阅读和用户选择，没有双场景持续绘制或遗留覆盖层。
