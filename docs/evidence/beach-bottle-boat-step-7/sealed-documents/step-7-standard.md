比较静态配置、数值有效性与功能响应；自然时钟、随机性和惯性导致的相位不同，不以逐帧坐标或逐像素完全相等验收。原页重复性不足的量说明其范围，不修改原随机数、暂停时钟或重放内部状态制造一致。

## 7.7 PNG、尺寸和浏览器范围

原按钮在两端都要实际触发下载，至少两组匹配的子画布尺寸/DPR；其中一组 DPR 大于 2，实际确认导出上限。可包含 UI 显示时直接点击，以及隐藏 UI 后保留有效原按钮焦点用真实 Enter 激活的原行为，不临时添加导出按钮。
