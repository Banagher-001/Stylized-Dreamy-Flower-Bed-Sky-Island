# 卡牌改进 · 第六步操作引导

桌面控制栏会显示滚轮横移、自动展示、暂停和固定阅读的当前操作。一屏可读的分类显示「本类已全部展示」，第一笔滚轮交给页面。判断卡牌能否横移时，提示和输入区读取同一套卡槽宽度。滚轮接管自动轨道时，显示手动横移的提示，自动选择继续保留。

「操作说明」按浏览、详情和继续浏览组织。桌面面板在卡排内贴近说明按钮，窄屏、稳定阅读和大字号使用控制栏下方的展开布局。用键盘打开时焦点进入标题，关闭后回到原按钮。卡排继续提供读屏可读的操作描述，分类切换按原有方式播报。

在带触屏的桌面上滑动卡牌时，卡排由浏览器处理手势和惯性。直接点按详情由同一个原按钮接收。转回鼠标或键盘后，从原分类和位置继续，自动展示按之前的选择恢复。系统切换到减少动态时，正在进行的飞行和滚轮惯性会收束，仍可直接横移并阅读详情。

## 验收

`npm run build` 成功。同一生产构建通过 10 项本步浏览器检查、1 项实际浏览器缩放检查和 12 项既有交互回归。触屏与混合输入使用 Chromium 触摸模拟，200% 缩放由有界面的 Chromium 接收原生快捷键。另测了根字号 200% 和 320px 窄屏。

| 场景 | 实测 |
| --- | --- |
| 桌面暂停后切到后期与视觉制作 | 左右留白与牌面横移时页面和镜头原位。移出后的首笔滚轮进入页面 |
| 一屏卡片分类 | 显示「本类已全部展示」，区内首笔滚轮直接移动页面 |
| 纯键盘浏览 | 完成翻卡、读详情、开合说明和进入 AI 影像。关闭说明后焦点回到入口 |
| 390px、320px、混合输入 | 横滑卡排、纵滑页面和单次点按详情通过。混合设备从详情按钮起手也能横滑 |
| 飞入、飞出和缓停中启用减少动态 | 动画与缓停清理，手动横移仍有效 |
| 浏览器实际缩放到 200% | 视口由 1652 CSS px 切到 826 CSS px，说明可展开、关闭，下一部分可到达 |

滚轮打断飞入的回归曾有一次采样值为 261.5ms，超过 245ms 阈值。该次页面实际落位时间为 210.5ms。同一构建按原阈值复验两次，分别测得 190.3ms 和 193.7ms。[时序记录](evidence/step-6/regression.json)
