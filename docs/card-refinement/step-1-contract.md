# 卡牌入场与轮控改进 · 第一步交互合同

本轮共七步，本步执行用户已确认的“统一交互区域与输入归属”。实际交付为版本基线、只读判定模块和可选调试检查。第二步调整入场，第三步接入实际滚轮横移；本步没有更改旧 wheel、入场、轨道或自动播放控制器。

## 区域

使用外层工具区的完整矩形：左右对齐下方操作栏，顶部从分类栏底部开始，底部到操作栏顶部。它包括牌面、间隙、两侧和上下留白，不包含标题、分类和操作按钮、右侧章节导航。

每次检查依据真实布局计算，并与浏览器视口相交。固定导航、其他控件若在该坐标前方，优先保留其操作。飞行卡的当前位置不扩大区域；返回后的分类、字体、窗口变化重新测量，不缓存旧截图像素。

横移资格来自当前真实卡槽逻辑宽度之和、间距与内边距，相对滚动视口允许 1 CSS px 的舍入误差。使用未变换的卡槽宽度，不用悬停、透视、飞行之后的牌面边界，也不以程序轨道、自动开关、三维能力或减少动态偏好作为资格门槛。

## 判定顺序

| 顺序 | 场景 | 建议归属 / 原因 |
| --- | --- | --- |
| 1 | Ctrl / Command / Alt 与滚轮组合 | browser / browser-modifier，保留浏览器 |
| 2 | 原生模态弹层开启，包括其背景 | overlay / modal-reading |
| 3 | 稳定模式的全部工具全文 | page / catalog-reading，保留原生竖向阅读 |
| 4 | 卡排隐藏、失效、不可交互或完全离开视口 | page / region-hidden |
| 5 | 鼠标落在打开的帮助面板内 | overlay / help-reading |
| 6 | 鼠标在区域外、其他控件或原生输入框上 | page / 对应原因 |
| 7 | 当前分类全部放下 | page / all-cards-visible |
| 8 | 区域内且存在横向内容 | cards / scrollable-region |

cards 归属再给出计划动作：普通卡为 scroll，预览为 collapse-preview-and-scroll，固定详情为 collapse-pinned-and-scroll。当前只返回判定，不执行动作，不解除固定、不暂停或恢复任何动画，也不调用 preventDefault。

## 后续行为约定

- 自动开启和自动暂停都可手动横移；鼠标开始操作只临时接管，移出后遵守原来的自动选择。
- 切换分类清除旧惯性，保留明确的自动偏好；进入区域不能擅自开启自动。
- 预览或固定详情遇到换卡滚轮时收起再横移；仅移开鼠标仍保持固定。
- 一笔输入由一个控制器消费。首尾仍由卡区接管，平缓停住，不将同一段输入突然泄漏给运镜。
- 区域外的新输入交给页面，卡排旧惯性可以短暂收尾；继续浏览按钮保持可用。
- 全部放下的分类保留页面滚动，并在后续提示步骤说明“本类已全部展示”。
- 手机原生横向与纵向手势、按钮、文字选择、键盘与浏览器缩放继续有效。减少动态时取消大动画，不取消横移资格。

以上为后续控制器必须遵守的合同，行为接入与手感验收在第三步执行，本步只核实几何和归属。

## 实现与检查入口

`src/tour/about-refresh/cardInteractionRegion.ts` 的 createCardInteractionRegion 接受现有 root / rail / filters / controls 与只读状态回调。inspect(input?) 返回 bounds、visibleBounds、contentWidth、viewportWidth、overflow、active、mode、category、automatic、reading、entrance、departure、layout，以及 inside / owner / reason / action。

后续可以直接传入原生 WheelEvent，由第三步控制器根据返回结果决定是否消费事件。模块本身没有监听、滚动、属性写入或帧循环。

`createToolBrowser.ts` 创建这份判定对象，仅在 URL 有 `debug=1` 时启动 `createCardRegionDebug.ts`。普通入口没有新增诊断节点或监听。调试层位于 document.body，处于原三维和内容测量链之外，aria-hidden / inert / pointer-events:none。观察器只请求合并后的单次绘制，销毁时终止监听、断开观察器、取消待执行帧并移除自己的节点。

开发或 HTTP 预览打开 `/?debug=1`，进入工具区后移动鼠标。虚线显示可见区域，左下文字显示“只读，不接管输入”和建议归属、逻辑宽度、分类、当前自动与阅读状态。调试层不是新的轮控实现，普通入口仍保留原来的实际行为。
