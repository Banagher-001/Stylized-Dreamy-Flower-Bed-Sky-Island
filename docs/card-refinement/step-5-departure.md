# 卡牌改进 · 第五步离场与归位

在卡牌区滚到首尾，有限轨道会减速贴边。鼠标移出区域后，新滚轮接回页面运镜。镜头越过「工具与方法」的阅读边界时，可见卡片向两侧飞离，反向浏览时接回原位置。

## 边界和归属

原生轨道用真实剩余距离控制最后 48 CSS px。朝边缘的位移随距离平滑缩小，接近 1px 时贴到边界。同一段连续向外滚动触发一次约 160ms 的浅绿边缘反馈，反馈结束后卡排保持在边界。反向输入从该位置进入新的移动。程序轨道沿环形相位通过接缝，一屏能放下的分类使用页面滚动。

区域外的新输入走现有原生页面滚动。卡牌飞离接管时，捕获当前分类、卡位、阅读及自动选择，再清理旧尾段并冻结原卡。相机仍以实际 `scrollY` 更新，显式导航直接设置现有目的地。跳转出站会撤掉卡牌飞离占用。

回归中，软件图形环境给原生首笔留下的积分时间可能偏短。因此在一次新的原生纵向手势或明确反向时先应用最多 12px 的有界增量，后续沿第三步的速度推进。增量经过同一边界阻尼。入场被打断时，其 140ms 归槽与离场采用同一单调取时。

## 飞离与反向

在 A3 的可读区间 0.32–0.78 内，镜头停稳且首轮入场就绪时，实际阅读状态准备飞离。向下超过 0.80 或向上低于 0.30 后开始。选当前可见原牌，最多五张。普通编排每张 420ms，错峰 45ms。两侧向外飞，带俯仰、退远和转面，投影终点以离开真实裁剪边界为准。快速经过可见区会缩到约 220–280ms 的收束，越过可见区的直接跳转执行清理。

向下离场后的内侧回位线为 0.76，向上离场后的为 0.34。镜头停在紧邻边界的完全可读范围时也允许归位。飞到一半折返使用当前姿态，回位时长约 300ms。再次向外移动从当前姿态重定向，同一批原卡继续使用原来的一份位置记录。

归位时主动移入牌面可暂停飞行，实际按压由第四步的同一份记录保持到原生点击。返回恢复当前分类和固定。窗口变化、减少动态及后台切换清理本次飞行、临时输入和交互占用。稳定阅读和手机提供原生卡片及页面手势。

## 验收

最终构建通过 22 项检查。1652×949 的普通入口使用可信滚轮、鼠标点击和实际绘制帧。测试记录红框内外归属、首尾速度、相机目标、真实牌面投影、分类和返回卡位。单独测已固定卡离场及返回、原生窗口切后台、缩窗和减少动态。移动端使用 390×844 的浏览器触控仿真。

| 验收 | 实测 |
| --- | --- |
| G6 原生卡排首尾 | 横向范围 0–416px。此组中段峰值 334.8 CSS px/s，近首尾分别约 195.9、199.7，连滚保持同一页面位置 |
| 从首端反向 | 首个实际绘制样本即移动超过 8px，首帧采样距事件约 2.5ms |
| 正常向下离场 | 四张、555ms。接手前后偏差 0px，实测有可见的背面，最长可见横向行程约 415px |
| 快滚离开可见区 | 采用 220ms 收束。直达 AI 影像的按钮进入原目的地 |
