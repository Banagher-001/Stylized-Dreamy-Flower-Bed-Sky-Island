# 关于我改版 · 第九步：悬停阅读与鼠标倾斜

本步在第八步轨道上实现有意悬停、临时停留、抬升放大、鼠标跟随、边缘完整阅读和阴影分层修复。更多内容的正式展开仍由第十步接入；现有详情按钮保持可用。未提交、推送或发布。

## 进入与离开

只有真正 A3 可读、入场已结束、宽屏精细指针且空间允许时启动。鼠标真实移动累计至少 1.5 CSS px 后才考虑候选，停留同一张真实牌面 120 ms 再进入。静止鼠标下自动经过的卡牌不触发；用户滚轮后至少安静 220 ms、输入尾段已结束且实际速度不超过 40 px/s，才接受新的鼠标意图。

进入阅读时 `holdReading(true)` 使轨道停止，保留当前自动选择和方向。一次只存在一张阅读卡，切到邻卡时先完成旧卡回位再激活最新候选。离开有 90 ms 容错和 240 ms 回位；之后按当下的自动选择恢复原有 500 ms 留白及 300 ms 起速。关闭状态始终关闭，离开不重放旧滚轮尾段。

实际进入阅读通知主导览交还控制。离开只可能恢复工具轨道，主导览仍由用户主动开启。

## 空间与姿态

`createToolCard` 把基础姿态与阅读姿态组合。position 层保留飞入/轨道位置；reading 层处理局部 X/Y/Z 与缩放；orientation 层将基础角度随阅读权重收正，再叠加鼠标倾角。轨道与飞入仍用原来的 setPose，悬停通过 setReading 更新，无复制节点或独立 Three 渲染器。

| 参数 | 实现值 |
| --- | --- |
| 进入 | 260 ms smoothstep |
| 回位 | 240 ms smoothstep |
| 鼠标响应 | 70 ms 指数响应；目标误差小于 0.015° 后停帧 |
| 默认俯仰/偏航 | ±5° / ±7° |
| 默认上提 | 8 CSS px |
| 默认阅读深度 | 相对共同轨道平面向前 36 px |
| CSS 默认缩放 | 1.10，并补偿基础投影比例；加上透视后目标约 1.14 倍 |
| 紧凑档 | CSS 1.08/1.06/1.04，世界深度 34/32/30，倾角依次收敛 |

边缘牌原本处于较深的弧轨位置，需要补偿其基础 Z，使抬升后的真实深度处于邻卡之前。仅增加一个固定局部 Z 会让边缘卡在反向倾斜时被邻卡覆盖，已通过真实 elementFromPoint 网格查出并修复。

鼠标映射使用激活时冻结的参考平面，不根据持续变形的矩形重新计算，因此没有自我追逐。按下鼠标时冻结当前姿态，原生 click 分发完毕后再处理详情或回位，支持正文选择与首次按钮点击。键盘进入同一张原本由鼠标选中的卡，也会切到正面、无指针倾斜的阅读姿态。

## 真实边界与空间预留

激活前检查四个极限角度的十个实体面与阴影范围，阴影按 blur 的三倍加投影缩放预留。目标包围盒与轨道内缘至少间隔 8 px。空间不足依次尝试紧凑档；局部 X/Y 做最小校正，最多三次投影校验。这个测量只在激活时完成，恢复初始姿态后再开始动画，不触发主站容量测量。

两侧局部卡通过阅读层移动到安全范围，原槽位、数据顺序、其他卡牌和轨道相位不改变。回位完整结束后才重新运行轨道；活动放大牌不参与离屏循环换位。

宽屏预先设置卡排上下留白 40 px，1000 px 以上高度采用 56 px。工具标题、分类、控制与继续区的小幅留白调整抵消部分新增高度，保留字号和 44 px 按钮；1440×900 继续使用花园沉浸模式，避免首次悬停才顶高布局。手机、大字与减少动态仍用原有阅读布局。

## 阴影修复

阴影从 position 层移到实体内部，与牌面共用 orientation；位于背面之后 `-depth-3px`，并设置背面不可见。它不会再和前牌面处于相同深度，前后翻转也不会让阴影覆盖背面装饰。

阅读过程中阴影源形状内缩从 5 px 到 14 px、模糊从 7 px 到 7.2 px，保持石牌靠近时柔和而清楚的轮廓。所有实例均沿用同一个有厚度的 HTML 正面，正文及本地图标不改。阴影可见与隐藏的静帧内区像素对比用于验证是否仍覆盖正文，不把改变 z-index 当作深度修复。

## 输入与生命周期

卡排的合格滚轮事件先清理阅读，再由原有单一横移时钟接管，同一事件就产生效果。横向手势仍将第一事件转移一次后交给原生浏览器，缩放修饰键保持原生。离开卡排后页面滚动与运镜可立即使用。

原生浏览与一屏可放完的分类也可以在宽屏获得悬停效果，不自动开启程序轨道。原生滚动会取消阅读；键盘焦点引起的原生对齐后延迟 180 ms 稳定进入。键盘进入时保持正面，Enter 展开现有详情，Escape 回到基础姿态且保留焦点。

切类、全部工具、详情、离开 A3、后台、尺寸/媒体设置变化、恢复及销毁都清理候选、计时器、活动姿态和临时停留。快照不保存悬停。一个按需 RAF 只处理当前卡及回位，静止后取消；没有 22 个常驻循环，也没有新增横移时钟。
