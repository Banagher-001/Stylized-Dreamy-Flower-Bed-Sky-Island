# 关于我改版 · 第十一步交接

第十一步接入真实第三屏的当前卡片飞离、中途折返和返回恢复。下一步为第十二步操作说明，先细化、再按用户指示实施。本步未提交、推送或发布。

[实现说明](step-11-departure.md) · [验收](step-11-verification.md)

## 当前结构

- createCardDeparture：idle / exiting / departed / returning / disposed，持有有限帧、当前可见实体、空间终点和暂停中的指针。
- ToolCardView.setFlight：在 position → reading → flight → orientation → entity 中更新独立飞行变换；不覆盖基础轨道或阅读姿态，不复制正文。侧边受光包含飞行角度。
- createToolBrowser：协调捕获逻辑快照、暂停轨道/阅读、解除持有，以及同一次输入的后续操作。
- createAboutView：转发 presentToolsDeparture / cancelToolsDeparture。
- createPillarReader：显隐前捕获离场，放置后处理返回；measuring 不驱动飞离，真实阅读模式变化先清理持有。

## 第十二步可直接使用的操作事实

| 状态/入口 | 实际操作 |
| --- | --- |
| 自动横排 | 可以暂停或继续；停止滚轮后按原选择和最近方向展示 |
| 鼠标在卡排内滚动 | 控制横向速度与方向，快慢和惯性沿用第八步 |
| 临时悬停 | 显示完整介绍；移开收起，点击可固定 |
| 固定阅读 | 移开仍保留；收起或 Escape 关闭；滚轮交给页面 |
| 页面向下或向上离开第三屏 | 当前可见卡片飞离，保留分类和阅读位置 |
| 离场后返回 / 中途折返 | 接回当前卡片，首次四张开场不重播 |
| 返回时主动把鼠标移到卡面 | 暂停回收，方便对准按钮；移开继续 |
| 返回时点击、键盘或滚轮 | 解除剩余回收并处理同一操作，第一下有效 |
| 快捷章节导航 / 继续浏览 | 目标立即生效，不等待完整飞离 |
| 手机、稳定阅读、大字与减少动态 | 原生阅读、横滑和点按详情，保持完整内容 |

说明文案应短、贴近当前状态。不要把计时、phase、ID、几何预算、暂停租约或测量过程放进访客界面。第十二步统一提示与入口，不重新设计三维运动。

## 后续必须保持的约束

1. 每工具一个真实节点、一份可访问正文和原生按钮。不要因说明浮层额外复制交互牌面。
2. 飞离时浏览器本身脱离正文 opacity，分类和控制区单独淡出。不要把 opacity/filter 放到共同三维链上，避免牌面提前消失或透视被压平。
3. 逻辑快照只保存原有分类、固定 ID、轨道位置、方向和用户选择，不保存飞行姿态、指针暂停或动画中间帧。恢复不能覆盖更新的用户操作。
4. 飞离持有期间轨道、悬停和宽度时钟暂停；departed 没有帧。返回时在原几何基础上回收，解除持有后才恢复正常展示或收起。
5. pointermove 只接受真实鼠标移动意图，静止光标下经过的卡不主动暂停。pointerdown 保持变换到原生 click，按钮逻辑执行后才重置飞行。
6. 固定阅读的立即恢复同帧求值，避免回收完成瞬间出现窄卡。保持第十步的原生宽卡堆叠层级及手机固定 ID 对齐。
7. 只用真实主站可读上下文准备飞离，容量测量不能触发、消耗或重置动画。不要凭 wheel 事件本身判断离开第三屏。
8. 稳定阅读、窗口/字号变化、隐藏、减少动态、指针取消和销毁都恢复节点交互与单位飞行姿态。不存在第二套 DOM 或需要丢弃的前景副本。
9. 首批入场、自动横排、滚轮惯性、悬停阅读、固定详情与飞离各自分工。主导览和环境播放选择保持独立。
10. 保留 22 张正文、图标与两套排序；不增加履历项目、奖项或作品关联按钮。影像、罗森与漂流瓶功能保持。

原始开发检查与最终采纳结果保存在 evidence/step-11。后续建立新基线，不改写此前证据。开发使用 npm run dev，生产检查使用 npm run build；系统适配与整体验收仍分别属于第十三、十四步。
