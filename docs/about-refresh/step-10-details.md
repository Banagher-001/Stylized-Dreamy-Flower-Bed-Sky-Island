# 关于我改版 · 第十步：全文预览与固定阅读

本步把第九步悬停阅读接上完整介绍，统一临时预览、点击固定、收起、键盘与触屏。资料和 22 张工具卡正文、排序及图标继续复用；新增文案仅为必要的操作提示。未提交、推送或发布。

## 内容与牌面

实施前用第九步真实卡牌 DOM 测量全部 22 张内容，在测试浏览器临时设置 340/360 px 宽和标签/按钮同行。两档均无横向溢出，最大自然高度约 306.28 px，按钮最小高度 44 px；这份先行测量与最终实现验收分开记录。

正式阅读优先使用 360 px，空间较紧时尝试 340 px。普通槽位仍为 232/240 px 宽，卡排占位高度仍是 300 px；实体可按实际内容自然长到约 306 px，再按真实牌面、厚度和阴影检查安全范围。正文 16 px，内容顺序为分类、名称、用途、完整介绍和操作。宽牌页脚让按钮保持左侧，标签放在右侧，空间不足允许标签换行。

一张工具卡始终只有一份 HTML 正文、真实按钮及棱柱。物理宽度逐帧改变，字体正常重排；工厂在同帧更新十面实体的几何，原 ResizeObserver 继续处理真实尺寸。牌面沿用暖白石材、草绿正文与淡刻纹，没有额外内容弹窗或第二套渲染器。

## 状态契约

| 状态 | 详情 | 自动选择 | 卡内按钮 |
| --- | --- | --- | --- |
| summary | 隐藏全文 | 保持原规则 | 展开详情 |
| preview | 显示全文，临时停流 | 不改变开关 | 固定阅读 |
| pinned | 全文保持，逐渐收正 | 显式暂停 | 收起详情 |
| catalog | 全部工具静态全文 | 不参与轨道 | 沿用列表返回按钮 |

临时预览不写快照；固定内容复用 CardsSnapshot.expandedId。显示全文不再等同于禁止整个轨道上下文，因此不会一展开就取消自身。轨道仍保留一个横移时钟，阅读层统一管理宽度、正文显隐与三维姿态。

## 进入与退出

有意悬停识别继续沿用第九步：真实鼠标移动与 120 ms 停留；滚动和惯性优先，静止鼠标下经过的牌不触发。

| 动作 | 时间 |
| --- | --- |
| 横向展开 | 220 ms smoothstep |
| 阅读抬升/姿态 | 260 ms |
| 正文出现 | 第 210 ms 开始，140 ms 完成；淡入并上移 4 px |
| 回位 | 正文先用 100 ms 淡出，再用 200 ms 收宽；姿态在第 60～300 ms 回位 |
| 鼠标跟随 | 70 ms 指数响应，默认俯仰 ±3°、偏航 ±5°，按空间收敛 |

确认查看后约 350 ms 全文出现。文字在宽度接近稳定时进入，不在窄牌中强塞全文。回位完全收紧、实体几何归位后才释放轨道 hold。合格滚轮事件直接收束临时详情，再立即消费同一事件的横向输入，保留第八步的速度与惯性。

默认阅读深度仍为共同轨道前方 36 px，并补偿边缘牌基础 Z；紧凑档收敛到 34/32/30 px。激活前对全文、最终宽度和四角极限姿态作同步测量，确认阴影三倍模糊范围及牌面均离裁切边缘至少 8 px。探测过程中不发送布局或用户交互通知。

## 点击、焦点与固定

pointerdown 冻结宽高、姿态和正文进度，直到原生 click 分发。预览转固定只改变状态，不先收回再打开。鼠标阅读切到同一卡的键盘焦点也保留已展开内容，再平滑收正。按钮始终是同一个元素，aria-controls 指向同一正文，aria-expanded 与实际可见性一致。

固定阅读移开后继续保留；按收起或 Escape 后关闭，并抑制当前卡立即重开，直到鼠标离开或焦点离开再返回。普通卡直接点击/Enter 即可固定；手机没有先点一下触发悬停的中间步骤。

固定状态的滚轮交还页面，不再推动卡轨。提示“固定阅读中 · 滚轮浏览页面”；触屏提示“再次点按收起 · 上下滑动阅读”。点击继续自动展示时先收起，再按最新开关选择恢复。临时 hold 在原生轨道尚未绑定时也有效，防止收牌过程中提前绑定运动、保存到非静止的变换。

## 切换与保存

阅读时序号跟随当前阅读 ID。上一张/下一张以该 ID 为起点，固定状态切换后继续固定；保留当前分类顺序及原有程序循环/原生边界规则。切类清除固定目标。

查看全部时暂停当前呈现、保留固定 ID 和位置；全量列表显示全部 22 份全文。返回后按当前可用空间重建同一内容的阅读姿态，焦点恢复到原返回入口。章节切换、快照及重挂同样保留固定 ID，临时预览清理。

缩到手机、大字或减少动态时，全文转为原生流式阅读，清除旧程序锚点，并把当前固定卡横向对齐到可见位置。恢复原生位置的异步帧也优先使用固定 ID，避免重新覆盖成旧的首卡位置。尺寸恢复后重新测量，固定内容与暂停选择保持。

原生轨道中各卡具有各自的局部透视，阅读深度不能决定相邻卡的绘制顺序。因此原生模式下的宽阅读卡另保留 z-index: 2；程序轨道继续采用共同三维空间的深度排序。最后视觉复核发现了恢复宽屏后右侧正文被邻卡盖住的问题，新增真实命中网格先复现，再验证修复，不能仅凭包围盒未溢出判定全文可见。
