## 关键实测

- 鼠标预览后第一次真实浏览器触摸，按住期间按钮四边最大移动 **0.000 px**，随后固定 ComfyUI 正文成功；取消、横向滑动与切回鼠标也通过。触摸滑动后的第一次鼠标停留即可展开，不需要再次移动或额外点击。没有合成点击或复制卡片。
- 横向拖动前后位置为 **0 → 251 px**。按住与拖动期间容量探测均为 **0 次**，滚动安静后完成 **1 次**补测；字号变化期间则能优先测量并切换稳定阅读。
- 1440×900 的默认控制栏与说明展开时均为 **62 px**，没有为本步增加默认高度。320×740、390×844、430×932、844×390、768×1024、1024×768、1280×720、1440×900、1920×1080 与 1179/1180/1181 临界宽度均完成浏览、说明和详情检查。
- 固定阅读在窄屏、横竖屏、200% 字号、减少动态与模式往返中保留。能力恢复不擅自开启自动；同一模式内调整尺寸可保留有效的自动选择。背景返回不补跑旧惯性。
- 图形连接在屏幕外恢复为 **restored**，等待超过原四秒超时后中断提示仍隐藏；画布可见后成为 **ready**，返回阅读仍保留固定对象和节点身份。
- 十次重挂后，当前工具浏览器只有一个；一次相同操作的有效回调次数与干净实例均为 **[2, 2]**，旧实例已销毁。卡片/说明静止后的状态与任务清理经专项和既有回归核对。
- 按实际 CSS 盒检查的最小操作目标为 **44 px**；已检查的正文/按钮色板配对最低对比度 **4.63:1**，焦点轮廓满足对应检查。键盘与 Escape 优先级通过；不等同于辅助软件完整认证。
