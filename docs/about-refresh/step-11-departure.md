# 关于我改版 · 第十一步：卡片飞离与折返

本步为真实 A3“工具与方法”接入当前可见卡片的三维飞离、途中折返和离场后的返回。资料、22 张正文、图标及顺序继续复用，未提交、推送或发布。

[验收记录](step-11-verification.md) · [第十二步交接](step-11-handoff.md)

## 实际实现

卡片工厂增加独立的 flight 层，结构为 position → reading → flight → orientation → entity。它在当前基础姿态和阅读姿态之外叠加位移与旋转，侧边的风格化受光也计入飞行角度。静止时该层为单位变换，不改宽高、正文或十面实体。

飞离保持原节点、原槽位和原透视链，不搬移牌面或复制节点。卡片浏览器在持有飞离时不参与正文整体透明度变化，分类和操作区单独沿用正文淡出；轨道仍裁切实体、背面和阴影，导航与后续模块不被额外前景覆盖。

这一实现满足独立呈现的目标，同时避免移入另一个透视舞台时产生投影跳位。接管前后逐一比较实际十面的边界，并保留测量值用于验收。

## 触发与状态

新控制器 createCardDeparture 接收真实宿主上下文 active / enabled / progress / readable。主站先在更改 A3 的显隐前调用，再在放置后调用，使离场能捕获旧呈现，返回能使用真实可用尺寸。所有容量测量均跳过调用。

完整可读、相机停稳且首轮入口已就绪后，在阅读进度 0.32—0.78 范围内准备离场。向下跨过 0.80 或向上跨过 0.30 后开始；完全跳过可见离场区的快捷导航直接清理，不补播。这里复用现有阅读区间，不改相机路线或阅读时长。

状态为 idle → exiting → departed → returning → idle。departed 保留逻辑位置与当前实体，但隐藏轨道且不运行帧。正常离场后返回或中途重新进入 0.30—0.80 可读区，均接续当前姿态回收；再次向外移动时从当前姿态改向，不生成第二组动画。返回完成后需重新进入内部可读范围才准备下一次完整离场，减少边界重复触发。

卡排内滚轮继续用于横向展示，只有实际宿主阅读进度能触发飞离。分类、详情、全部工具和按钮操作不作为离场信号。

## 当前可见内容与编排

从当前轨道真实牌面投影选择可见实体，包含两侧局部露出的卡，按实际横向位置排列，最多五张。分类有一张或两张时只处理实际内容，不使用固定的首批四张清单。

每张的主时长为 420 ms，错峰 45 ms。常见四张合计 555 ms，五张为 600 ms，两张为 465 ms。前段轻抬 14 px；空间移动略晚于转身，随后向左右两侧和深处退去。向下离开略向上散开，向上离开略向下。

深度为 -220/-275/-330 px，俯仰 ±14°，小幅旋转 7/10°。左右转身按位置选择 78/98°，中部一张到 112°，安排可见的侧边和背面刻纹。牌面透明度不参与飞行。

每张终点通过实际十面及阴影三倍模糊范围校准，确保完整投影离开展示窗口至少约 36 px。校准发生在接管时，渲染前恢复零飞行姿态；运动帧主要更新变换与侧边受光，不逐帧测量整页容量。

## 阅读、横排与自动选择

接管前记录分类、实际阅读 ID、固定 ID、轨道位置、循环相位、方向和自动选择。保存的是现有 ToolBrowserSnapshot，不把飞行角度或中间进度写入快照。

轨道与悬停分别提供 suspendForDeparture。持有期间停止横移、宽度和鼠标姿态时钟，保留当前实体呈现和用户选择；飞离控制器负责唯一的卡片运动。停在离场状态时也没有活动帧。

展开牌按当前真实宽度直接飞离，不先收起。固定阅读返回后恢复同一份全文和暂停选择；临时预览不成为固定内容，回收后沿用正常的收起过渡。立即恢复固定内容在同一帧求值，避免归位瞬间短暂显示窄卡或隐藏正文。

回收主时长 300 ms。原先开启自动展示的卡排在回收和必要的阅读收起完成后继续；原先暂停则保持暂停。旧滚轮惯性不重放，主导览与环境播放独立。

## 返回中的操作

返回时，真实鼠标主动进入卡面会暂时停住运动，方便对准按钮；移开后按扣除暂停时长的时间线继续，静止鼠标下经过的卡不会自行触发此暂停。pointerdown 继续固定呈现直到原生 click 分发。

按钮 click 到达后才结束剩余回收并执行原操作，保持第一次点击有效。分类、全部工具、键盘和滚轮也先解除飞离持有，再处理同一操作；过期回调不能覆盖新的分类、固定内容或播放选择。

飞离时卡片退出交互，原焦点若位于即将离开的牌中，转到仍可见的全局阅读入口。返回不抢走用户的新焦点。指针取消、失焦、窗口变化、字体变化、页面隐藏和减少动态变化均能结束持有并清理。

## 适配与范围

完整运动限于空间足够的桌面沉浸模式。稳定阅读、手机、大字与减少动态保持原生全文和浏览功能；切换模式会先把飞行姿态归零、恢复交互，再执行原布局。

本步不改个人资料或增加项目、奖项，不改变影像、罗森、漂流瓶的嵌入与控制，也不改相机路线。下一步仍是第十二步操作说明；整体系统适配和总验收继续归属第十三、十四步。

验收证据保存在 evidence/step-11，原始失败探针保留，最终采用结果与当前源码核对后另列。运行用 npm run dev；生产检查用 npm run build。
