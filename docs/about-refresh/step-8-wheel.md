# 关于我改版 · 第八步：滚轮速度、方向与缓冲

本步只扩展工具卡轨道的输入与运动。首批四张飞入、石质卡牌、浅弧轨道及原有内容继续复用；悬停放大、鼠标倾斜、扩展内容展示与飞离编排分别留给后续步骤。用户已授权本步在工作区执行，未提交、推送或发布。

## 使用规则

- 进入 A3、首批入场结束、卡牌与控制区完整可读时，宽屏精细指针设备可在程序轨道中使用纵向滚轮。向下滚动使卡牌向左，向上使卡牌向右。
- 轻滚小幅推动，快速连续滚动明显加速。反向输入先制动、经过零速后再反向。停止输入后渐缓，保留已经走过的位置。
- 自动展示开启时，缓冲后回到最近所选方向的 28 CSS px/s；暂停自动展示时，滚轮仍可手动推动，缓冲后完全停止。滚轮不修改自动展示开关。
- 暂停按钮立即清除速度与输入尾段。继续从当前位置平缓起动，不重放旧输入。上一张、下一张、分类、详情、全部工具、键盘阅读和指针按下先停止运动，首次操作正常执行。
- 捕获区仅为卡牌这一横排。标题、分类、底部按钮与继续阅读区域保留页面滚动；移出横排后，下一个滚轮事件立即交还页面。提示为“滚轮控制快慢与方向 · 移出卡牌继续下滑”。
- 横向触控板手势交还原生横向滚动，不叠加 JS 惯性。程序轨道的首个横向事件只转移一次位移，后续交由浏览器。一个手势在 180 ms 间隔内保持轴的归属，避免斜向抖动反复切换。
- 稳定模式默认仍采用原生浏览；主动开启卡牌展示后才可捕获。飞入期间、卡牌能一屏放完、详情展开、全部工具、手机、大字、减少动态等情况均保留原生阅读。Ctrl/Meta/Alt 滚轮与不可取消事件不接管。

## 运动与输入

`cardWheelInput.ts` 提供无计时器的归一化、轴归属和近期输入目标。`createCardTrack` 的现有单一 requestAnimationFrame 同时处理基础展示与手动缓冲，没有另建横移时钟或渲染器。

| 参数 | 最终值与用途 |
| --- | --- |
| 基础速度 | 28 CSS px/s，带方向 |
| 实际总速度上限 | 560 CSS px/s，正反向一致 |
| 近期输入窗口 | 100 ms，按距离与频率共同计算强度 |
| 输入换算 | pixel 直接使用；line 用实际行高；page 用卡牌视窗宽；不乘 DPR |
| 异常单事件限制 | 每轴 ±1200 CSS px，非有限值和零输入不推动 |
| 速度响应 | 指数响应，时间常数 70 ms |
| 输入目标 | 近期距离 × 10 × 0.23，饱和后不继续累加 |
| 停止输入 | 保留 80 ms 后按 140 ms 时间常数衰减；阈值 1.5 px/s 后清零 |
| 移出横排 | 取消保持段，按 90 ms 时间常数缩短尾段 |
| 明确反向 | 清除旧方向的样本趋势，目标改为新方向，实际速度连续变化 |
| 小幅反向噪声 | 近期小于 1.5 CSS px 的相反尾段不改写方向 |
| 基础起动 | 保留 500 ms 阅读留白和 300 ms 起速，空间弧度不随继续操作重置 |

手动输入停止后不做位置吸附。暂停且没有输入尾段时取消帧请求；后台、离开 A3、布局切换、尺寸变化和销毁时清空输入与实际速度。快照保存卡牌锚点、带符号的相对位置、开关选择、最近方向、空间弧度及首次接缝准备信息，不保存速度或等待队列，不按离开时长追赶。

## 双向首尾与原生交接

保留一个工具一个真实节点、原始 DOM 顺序、两套既定排序和原有唯一 ID。正反向都采用带符号的相位积分与循环归一化，只有整个牌面及阴影在画面外时才换位。速度缓冲不修改卡面姿态与石质外观。

初始入场留下的左侧空白需要单独准备：未走过接缝前，循环周期暂加 86 px 离屏余量，使第一张之前的末尾牌能够从画面外连续进入。接缝两侧都安全离屏后移除该余量，此后牌间距恢复原有 24 px。积分内部以不超过 8 px 的小步检查安全窗口，五张卡的分类在高速度下也不会错过整理机会；只在最终帧绘制一次。

左侧换位预算包括 64 px 的透视与阴影范围；整理时右侧另留 40 px。记录实际投影和阴影边界验证，不能只检查未旋转的容器。带符号锚点让首次反向接缝处转入原生滚动时继续保留当前阅读卡牌；原生滚动仍遵守浏览器首尾范围。
