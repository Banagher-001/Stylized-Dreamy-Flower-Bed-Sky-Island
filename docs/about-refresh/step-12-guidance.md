# 关于我改版 · 第十二步：操作提示与说明

本步统一工具区状态提示、操作说明、继续阅读提示和全量工具说明。个人资料、22 张卡正文与图标继续复用；未提交、推送或发布。

[验收记录](step-12-verification.md) · [第十三步交接](step-12-handoff.md)

## 默认界面

控制栏保留上一张、下一张、序号与自动展示开关，右侧为一条当前提示和“操作说明”。桌面不增加默认行高；卡片仍有展开详情、固定阅读和收起详情。继续入口旁的提示随固定阅读和输入方式变化。

原有桌面/触摸两份提示合为一个实际可见节点，卡排 aria-describedby 指向这一节点。序号保留关闭自动播报，并增加“第几张、共几张”的可访问名称；分类只在用户主动切换时播报名称与数量。

## 状态与文案

toolGuidance.ts 集中管理新增状态文案与说明条目，继续复用旧按钮词表，不改 content.ts。优先处理说明、入场、飞离/返回，再处理固定/临时阅读，最后按当前输入方式和轨道状态给出常规提示。

| 状态 | 默认鼠标文案 |
| --- | --- |
| 入场 | 卡片入场中 · 可直接操作 |
| 自动开启 | 自动展示已开启 · 滚轮调速 |
| 自动暂停 | 已暂停 · 滚轮仍可浏览 |
| 手动滚轮 | 正在手动浏览 · 悬停查看详情 |
| 临时预览、自动开启 | 临时阅读 · 移开后继续展示 |
| 临时预览、自动关闭 | 临时阅读 · 移开后保持暂停 |
| 固定阅读 | 已固定 · 滚轮浏览页面 |
| 飞离 | 正在离开工具卡片 |
| 返回 | 返回中 · 可移入卡面暂停 |
| 返回时停住 | 卡片已停住 · 可点击查看 |
| 说明打开 | 操作说明已展开 |

触摸优先左右滑动与点按；键盘优先 Tab、Enter 和 Escape；不支持悬停时使用点击说明。原生横向浏览和一屏完整分类不承诺滚轮加速。混合设备以本区最近输入为准：触摸打开说明时不沿用已绑定程序横排的鼠标文案，触摸返回也不提示移入暂停。

说明条目包括浏览、阅读、可用时的自动展示、继续浏览、返回和键盘操作。实际支持自动展示时额外解释本区控制卡片、顶部导览控制镜头。全量工具增加“已列出全部工具，返回后接续原浏览位置。”

## 说明呈现

createToolHelp 使用真实按钮与一个非模态 region。入口在打开后显示“收起说明”，面板有“如何浏览工具卡片”标题及 44 px 以上的关闭按钮。视觉沿用浅米白、草木绿和细边线，文字保持正向排版。

桌面沉浸模式采用 360 px 上限的面板，位于卡片三维链之外，按卡排、控制栏、导航与底栏的实际安全空间定位。面板不参与父级高度；说明过长可内部滚动，显示“说明可上下滚动”，标题与关闭入口保持在面板顶部。

稳定阅读、窄屏和大字使用内联展开，允许页面自然滚动，不做高度动画。根布局在容量测量时临时进入 immersive，CSS 即将面板移出文档流，避免内联说明高度让沉浸能力被错误判为不足；测量不打开、关闭说明或触发卡片动画。

## 状态衔接

说明开关只增加 helpHold，与现有 readingHold 合并后交给轨道。打开说明时保持当前相位和用户自动选择；临时预览正常收起后，说明仍能保持横排暂停。固定卡的正文和阅读目标不被关闭。

关闭说明按最新选择释放持有，不恢复过期快照。说明的状态不写入 ToolBrowserSnapshot。首轮入场被说明中断时，沿用原有 cancelled 规则，不重播或强制开启自动。显式打开说明停止主导览，关闭后不擅自重启主导览；环境播放独立。

真实离开第三屏、进入全部工具、状态恢复、布局变化、后台与销毁会清理说明。稳定阅读中滚动查看说明本身不触发关闭。窗口与字号变化使用既有阅读适配和固定 ID 对齐。

## 点击、键盘与输入

桌面点击面板外先关闭再处理该次操作，面板自身在卡排之外，内部滚轮不触发卡排加速。稳定阅读不靠外部 pointerdown 折叠正文，避免移动点击目标；明确的按钮操作在 click 到达后处理关闭。

键盘打开后焦点进入标题；Tab 可到关闭入口，PageDown 可阅读滚动内容。说明打开时 Escape 优先关闭说明并返回入口，保留固定阅读。关闭后 Escape 仍可收起固定内容。帮助目标不会被普通工具区 focus/keydown 暂停规则误改自动选择。

鼠标、触摸、键盘从实际事件识别；真实鼠标移动才改变鼠标方式。说明内不暴露 phase、ID、速度值或测量信息，也没有拖拽、方向键切卡等新增快捷操作。

## 更新与保护

控制文字只在实际改变时写入节点。悬停倾斜不会替换提示文本或说明列表；说明不拥有轮询或动画时钟。飞离/返回及指针暂停增加状态通知，复用既有控制更新，不修改运动轨迹或时长。

本步边界为提示与说明。三维运动、世界场景、相机路线、影像、罗森与漂流瓶不重新设计。第十三步仍为系统适配，第十四步为整体验收。
