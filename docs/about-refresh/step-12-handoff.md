# 关于我改版 · 第十二步交接

第十二步统一了状态短提示、操作说明、继续提示和全量工具说明。下一步是第十三步系统适配，须先细化并按用户指示执行。本步未提交、推送或发布。

[实现说明](step-12-guidance.md) · [验收](step-12-verification.md)

## 当前接口与数据

- toolGuidance.ts：纯状态到文案的转换，输出 hint、leave、rows、note；不访问 DOM 或创建时钟。
- createToolHelp：一个真实入口和一个非模态 region；open、popover、contains、close、update、dispose。沉浸模式弹出，稳定阅读内联。
- createToolBrowser：持有输入方式、readingHold 与 helpHold，合并后交给原轨道；说明状态不进入快照。控制文字仅在实际值变化时更新。
- createCardDeparture.changed：通知阶段及返回暂停变化，复用提示刷新，不改飞行动画。
- AboutViewOptions.onToolLeaveHint：把同一状态的继续提示交给 A3 继续入口。主站真实模式切换调用 cancelToolsHelp，测量不调用。

## 输入与交互约束

1. 鼠标、触摸、键盘来自实际事件，不能只按视口宽度认定设备。触摸输入即使出现在已绑定程序横排的设备上，也使用滑动/点按说明。
2. 说明打开时临时停住横排，保持自动选择；临时预览收起后仍由 helpHold 持有。固定阅读内容保留。关闭只释放自己的持有，不用旧快照覆盖新的选择。
3. 首次入场被说明中断，仍沿用 cancelled 的现有规则；关闭说明不擅自开启自动或重播开场。
4. 说明的触发器和面板不走普通工具区 focus/keydown 的显式暂停分支。Escape 优先关闭说明，第二次仍能收起固定阅读；键盘和外部点击的焦点处理不同。
5. 桌面外部 pointerdown 关闭不会移动目标；内联阅读不依靠外部 pointerdown 折叠。其他按钮在真实 click 到达后处理关闭，首次操作有效。
6. 面板滚动与卡排滚轮分开，键盘 PageDown 可读说明；没有全页滚动锁或嵌套模态框。进入全部工具前关闭说明。
7. 返回时有意移入暂停仍由第十一步管理。说明入口可以结束剩余回收并打开，旧动画回调不能覆盖帮助或用户操作。
8. 后台、窗口/字号/模式变化、状态恢复和销毁清理说明。沿用既有隐藏/不可用时的暂停规则，不恢复过期自动选择。

## 第十三步重点承接

| 方向 | 核对内容 |
| --- | --- |
| 响应式与容量 | 默认控制栏高度、卡牌实体安全边界、说明开启/关闭、长名称、200% 字号与矮屏 |
| 沉浸/稳定切换 | 保留章节锚点、分类、位置、固定 ID 与焦点；说明自动收起且没有残留持有 |
| 混合输入 | 触摸与鼠标往返、触控板原生横向交接、键盘切入、真实设备上的首个操作 |
| 减少动态 | 静态全文与必要操作完整，提示不要求悬停或三维运动 |
| 生命周期 | 页面隐藏、恢复、窗口变化、字体准备、图形不可用/恢复、组件重挂与销毁 |
| 可访问性 | 触摸面积、对比度、标题层级、可见焦点、Escape 优先级和有效描述关联 |
| 性能 | 提示没有帧循环，静止没有文本重建；卡片持有正确释放，画布与真实卡节点数量稳定 |
| 原有作品 | AI 影像、罗森、漂流瓶、环境播放、全站导览保持独立且完整 |

本步浏览器测试的模拟触摸、生命周期与原生输入在验收中分别标记，不能把它们写成实体手机、辅助软件或跨浏览器实测。后续若扩展验证范围，按实际证据报告。

## 不应改动的既有约定

资料、22 张卡正文/标识/两套排序保持，内容没有新增项目或奖项。每工具一个真实节点；位置、阅读、飞行和实体朝向仍分层组合。自动选择、主导览和世界播放独立，首批入场不重播。

说明是卡片三维链外的稳定 UI。沉浸布局下 CSS 保证面板脱离文档流，包括容量探测期间；不要把 opacity、filter 或高度动画加回共同三维链。

提示与可访问描述共享一个可见节点。自动计数不持续播报，分类的主动操作才提供一次必要反馈。帮助文案不暴露 ID、时钟、速度数值或内部状态。

第十三步开始前建立新基线，不覆盖 evidence/step-12 或前序记录。开发使用 npm run dev，生产检查使用 npm run build；第十四步仍为最终整体验收。
