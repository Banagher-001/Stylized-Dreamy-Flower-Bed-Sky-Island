# 关于我改版 · 第十三步：系统适配与状态衔接

本步基于第十二步完成版本，沿用既有视觉与三维结构，补齐输入切换和容量测量的衔接。个人资料、工具正文与标识、分类排序，以及场景和作品保持。第十四步尚未开始，未提交、推送或发布。

[验收记录](step-13-verification.md) · [第十四步交接](step-13-handoff.md)

## 修复一：触摸点击时保留实际按钮

问题：桌面鼠标悬停放大后，首次触摸「固定阅读」时，旧逻辑在 pointerdown 就拆下程序轨道。按钮横向移动约 85 px，touchup 无法命中原按钮，详情未固定。修改前的原生 CDP 输入与坐标记录保存在 inspection-baseline.json。

现在按住卡片按钮时，暂停运动并保留真实节点及其位置，让原生 click 先完成；点击处理完成后再交接到原生触摸浏览。没有合成点击，也没有复制或重建卡片。移动超过 8 px 则转为滑动；取消、失去布局能力、恢复状态及销毁都会清理这次持有。没有 click 的指针抬起使用一次 350 ms 兜底释放，不存在常驻轮询。

悬停组件增加实际触摸输入状态。触摸后不沿用鼠标临时预览与倾斜，固定全文用原生布局显示；真正的鼠标移动或键盘操作重新获得对应能力。鼠标识别放在捕获阶段，先于卡排对同一次移动的悬停判断，保证切回后的第一次停留即可展开。提示直接复用悬停组件的实际可用判断。切回鼠标不会开启自动展示，仍由按钮明确选择。

## 修复二：容量测量避开原生滚动手势

问题：容量探测会暂时隐藏真实章节。触摸拖动中，提示/计数变化触发探测，浏览器原生滚动链随之中断；210 px 的拖动在约 56 px 处停止，后续 touchmove 到达但不再滚动。drag-diagnosis.json 保留完整事件顺序。

现在文字引起的测量等待手指离开且工具区原生滚动安静 160 ms，再进入既有的 120 ms 合并测量；惯性滚动的 scroll 事件会延后这次处理。原生横向滚轮也采用这一规则。视口、稳定视口高度或字号发生变化时优先重新适配，不等待旧手势。

同一批次的强制测量请求会合并保留，延迟期间不会丢掉字体或内容引起的重新检查。后台不探测，返回后再处理待办；销毁清理事件和等待计时。测量仍复用原有节点与既有调度，没有新增动画循环。

## 修复三：图形连接恢复与首帧分开处理

在稳定阅读中，庭院画布可能位于屏幕外。图形连接已经恢复时，首帧会按既有可见性规则等到画布出现再绘制。旧恢复分支提前返回，导致原有四秒超时和中断提示没有结束。

现在连接恢复立即取消旧超时、收起中断提示、恢复可用控件，并标记 restored；真正提交首帧后才成为 ready。阅读位置与固定对象保持，画布仍按原可见性规则运行，不为了更新提示强制回到封面或启动环境播放。

## 能力与状态约定

| 条件 | 行为 |
| --- | --- |
| 空间、字号和输入能力允许 | 沿用沉浸浏览、三维阅读与可用的自动展示 |
| 当前空间不足 | 采用稳定阅读，保留章节、分类和固定对象 |
| 触摸操作 | 原生左右浏览、点按全文、上下翻页；不依赖悬停 |
| 触控板横向输入 | 接续当前卡片位置，采用原生横向浏览 |
| 键盘操作 | 可见焦点、真实按钮、既有 Escape 优先级 |
| 说明打开 | 临时暂停横排，保留自动选择和固定正文 |
| 减少动态、后台或能力失效 | 沿用暂停与静态阅读规则；恢复条件不擅自开启自动 |
| 同一模式内调整尺寸 | 清除旧惯性，按最新有效选择重新呈现 |
| 图形中断 | 稳定阅读继续可用，恢复后保留阅读状态 |

尺寸不单独决定模式。卡牌、正文、导航、页头页尾和字号的实际容量继续参与判断。宽屏稳定阅读仍可在支持时由用户手动开启卡排自动展示。
