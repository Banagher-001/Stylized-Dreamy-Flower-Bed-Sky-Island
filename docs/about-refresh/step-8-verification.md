## 实测

- 普通 120 像素单次滚轮在暂停状态下前进约 **58.52 CSS px**，约四分之一张卡；随后减速并取消轨道帧。
- 轻缓输入峰值约 **74.21 px/s**，快速输入峰值约 **559.99 px/s**；极端输入也未超过 560 上限。
- 使用同一 animation frame 中的实际 DOM 位移与时间差，测得基础展示正向 **28.00 px/s**、反向 **-28.00 px/s**。
- 真实滚轮加速完成正反两圈，见到全部 22 张卡，记录 **50 次**完整离屏换位；五张分类另记录 **16 次**。原节点实例和 DOM 顺序始终相同，首次反向未在可见区弹出尾牌。
- 暂停立即清空速度；自动关闭时滚轮仍能手动推动，尾段归零；自动开启时按最近方向回到基础速度。离开 A3、后台、重挂、尺寸和减少动态设置均不恢复旧惯性。
- 标题、分类、按钮与继续区滚动页面；卡牌横排捕获合格纵向输入；横向首事件转移一次后由浏览器接手；缩放修饰键保留原生。首次点击首牌、末牌和局部卡的按钮均成功，键盘焦点保持。
