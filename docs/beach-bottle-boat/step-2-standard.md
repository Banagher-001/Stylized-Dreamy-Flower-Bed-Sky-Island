## 4. 载入状态与真实就绪

查看器是否打开、哪个项目、现场/档案，与下面的独立网页载入状态分开记录。关闭时无实例；档案无需运行原网页；prepared 表示尚未建立可用现场。

| 状态 | 判定与含义 | 用户可用操作 |
|---|---|---|
| prepared | 当前作品可描述，但尚未开始原页现场载入 | 档案、返回；入口已保存时可独立打开 |
| loading | 正在创建/初始化当前文档，尚未满足就绪条件 | 返回、档案、独立打开 |
| slow | 当前文档载入满 12 秒仍无明确成功或失败；继续观察 | 继续等待、重试、独立打开、返回 |
| ready | 当前文档满足该作品的完整就绪条件 | 原网页全部操作及宿主工具栏 |
| error | 明确初始化失败、错误文档、图形丢失或无法可信观察当前应为同源的文档 | 重试、独立打开、档案、返回 |

瓶中海洋的 ready 必须组合当前实例/文档/画布的证据：

- 当前仍选择 bottle-ocean 的现场，iframe 和文档仍归本次打开所有，文档为预期同源成品，排除 about:blank 和错误页。
- 当前文档的 __bottleOcean.ready === true；不能复用上一次文档留下的 API 或布尔值。
- #gl 是连接中的原 canvas，CSS 与像素尺寸有效，原 renderer 对应这个 canvas，实际图形上下文没有丢失，并有原首帧绘制依据。
- 原加载界面已结束；初始化错误标志和原错误文字均无错误。错误判断不能仅看错误遮罩是否可见。
- 当前文档没有被观察到图形丢失。暂停中的 simTime 不增长不构成失败，也不要求固定 FPS 才算就绪。

iframe load、bottle-ocean-ready 事件仅触发复核，不能单独决定 ready。事件可能早于父级监听，因此须同时读取当前文档；沿用低频观察兜底，建议加载/慢加载每 200ms、就绪后每 500ms，并在关闭时取消。

初始错误优先于旧 ready。图形丢失后，即使原 ready 仍为 true，或随后收到 contextrestored，也保持本次文档的 error，直到用户重试建立新文档或发生受识别的新文档加载。原页缺少新图形代就绪证明，不能直接清除故障重新宣布成功。

同一 iframe 正常重新加载时，应更换文档代号、取消旧文档监听、重新计时和识别；新文档可以重新达到 ready。加载回调携带作品、实例和文档归属，任何一项已过期都不写当前界面。12 秒慢载入不是永久错误，不自动循环重试。

验收：正常、慢、失败、故障后陈旧 ready、正常新文档和旧回调都有明确去向；用户在全部载入状态都可退出。

## 5. 创建、切换、重试与退出的生命周期

| 用户动作 | 当前独立网页 | 主站与后续行为 |
|---|---|---|
| 只浏览 Coding 卡片或档案 | 不创建 iframe | 封面/文字可加载；不运行原场景 |
| 首次进入瓶中海洋现场 | 等弹窗打开且挂载区有尺寸后创建一个实例 | 保存阅读与焦点，停止导览，停止被覆盖庭院的持续绘制 |
| 连续点击同一现场 | 复用当前正在使用的实例 | 不叠加 iframe、定时器或监听 |
| 现场切档案 | 卸载当前实例 | 仍在作品查看器，庭院继续被覆盖；阅读快照不重复覆盖 |
| 档案再回现场 | 新建文档，从原默认状态启动 | 不偷偷恢复上次波高、装饰或镜头 |
| 罗森与瓶中海洋切换 | 旧实例失效并卸载后才创建新实例 | 一个查看器最多一个独立作品 iframe；状态和标题跟随新身份 |
| 切到庭院现场 | 卸载独立网页 | 恢复既有庭院体验的画布归属与布局 |
| 慢/错误状态点重试 | 使旧实例失效，清理，再建新文档 | loading 重新开始，重试不叠加；连续重试仍最多一个实例 |
| 载入中立即返回 | 取消延迟创建和全部旧回调；已建 iframe 则移除 | 不得随后在背景出现网页或提示 |
| 关闭或转去其他媒体查看器 | 卸载、断开监听与引用 | 原查看器完成收尾，再交接下一个覆盖层或恢复阅读 |
| 普通浏览器切标签再返回 | 保留原实例，回来复核当前文档和画布 | 不自动 reset、重建或强制播放；后台行为沿用原页，实际 hidden 场景待补核 |
| 整个主站销毁 | 旧实例和延迟任务全部取消 | 既有 viewer、ResizeObserver 等所有者按原流程销毁 |

每次卸载都先使当前实例代号失效，然后取消待执行的创建 RAF、状态定时器、iframe/window/document/canvas 监听；释放确由本实例持有的指针锁/全屏，移除 iframe，清除父级保存的子文档、canvas 与 API 引用。销毁可重复调用，不产生异常。

“最多一个”指当前主站查看器的嵌入实例，不跨窗口关闭用户主动独立打开的网页。庭院停止持续绘制时可保留原上下文与状态；不把它描述为只剩一个 GPU 上下文或显存立即归零。

验收：每个动作都有旧实例去向、新实例条件、状态归属与收尾；隐藏原 iframe 或调用原暂停不能替代卸载。

## 6. 输入、焦点、阅读与导览

| 操作 | 归属与标准 |
|---|---|
| iframe 内滚轮/鼠标拖动/双指手势 | 交给原页面旋转、平移、缩放和编辑；主站阅读位置、石柱运镜与导览进度不随之推进 |
| 原 H / Space | 保留原 UI 隐藏和播放切换及原输入焦点保护，不映射为主站动作 |
| 原 Escape | iframe 有焦点时由原网页退出编辑；不转发给父级，不触发宿主关闭 |
| 宿主 Escape | 焦点在宿主工具栏/档案等规定区域时按既有 dialog 关闭规则处理，关闭后恢复阅读 |
| Tab / Shift+Tab | 能进入原网页并返回宿主按钮；不建立拦截所有按键的自制焦点陷阱；由后续真实浏览器验证跨文档顺序 |
| PNG 下载 | 保留原按钮与真实用户激活；按子文档画布 CSS 尺寸×min(DPR,2) 核查，不固定为 1920×1080，不包含 DOM 面板 |

首次打开时记录触发按钮、当前阅读位置/布局锚点、相机阅读进度和主站用户动效选择；复用 beginOverlay/closeOverlay 的现有所有者，不让现场/档案切换反复改写打开前的快照。

弹窗打开后先把焦点放在可用宿主按钮，不在延迟就绪时强行抢焦点进入 iframe。关闭后用 preventScroll 恢复原触发按钮；按钮已不存在或不可见/不可交互时，回到可用的当前作品选择或阅读控件。跨尺寸变化优先恢复阅读锚点，不能只恢复失效的旧 scrollY。

进入作品停止自动导览；返回后保留停止状态，等待用户主动继续。主站原动效若进入前暂停，退出后仍暂停；若进入前播放，解除覆盖后可按原逻辑继续。子页暂停与主站动效互不修改。

验收：每个快捷键、滚轮、退出焦点和阅读快照只有明确所有者；返回不会自动续播导览或跳到错误石柱位置。

以现有全视口独立网页查看器为基础规定：工具栏之外的可用区域全部交给 iframe，保留返回、现场/档案、独立打开和按需出现的重试。
