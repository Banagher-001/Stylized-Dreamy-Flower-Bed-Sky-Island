## 3. 现场进入、尺寸和页面配置

用户选择瓶中海洋并点击现场后，由现有查看器打开；等 dialog.showModal 完成、挂载区具有有效尺寸，再创建一个同源 iframe。浏览卡片或档案时只加载图片/文字，不预加载运行 HTML、不创建隐藏现场。

- iframe 使用 resolveProjectEntry('bottle-ocean') 的结果，独立打开仍使用同一入口。根路径与项目子路径均成立。
- iframe title 标明“瓶中海洋 · 完整交互网页”。延续当前同源、原脚本、下载及既有全屏能力配置，不向原页注入主站业务、样式或模拟控制。
- 查看器占满可用视口，iframe 填满工具栏和安全区以外的空间。宽高来自实际挂载区，不固定为 1920×1080，不用 transform 缩放整个页面。
- 工具栏保留现场/档案、独立打开、按需出现的重试和返回；窄屏允许换行，不能覆盖原控制台或把页面挤成不可操作区域。
- 窗口、字体或工具栏高度变化后，子文档通过真实尺寸变化走原 resize 流程；原控制台负责内部滚动，宿主档案负责档案滚动。

验收：用户直接看到原网页的真实载入与现场；就绪后完整交互区域可命中，没有残留封面或宿主遮罩挡住原 UI。

## 4. 状态与成功判据

项目、现场/档案、实例是否存在，与以下载入状态分别维护：

| 状态 | 条件 | 可用操作 |
|---|---|---|
| prepared | 尚未开始当前现场创建 | 档案、返回、独立打开 |
| loading | 当前尝试正在取得/初始化目标文档 | 档案、返回、独立打开；清楚的载入反馈 |
| slow | 从本次载入开始满 12 秒仍未明确成功或失败 | 继续等待、重试、独立打开、档案、返回 |
| ready | 当前文档、画布和原场景满足真实就绪条件 | 原网页全功能与宿主工具栏 |
| error | 明确加载/初始化失败、错误文档或图形丢失 | 重试、独立打开、档案、返回 |

瓶中海洋 ready 同时要求：

1. 当前仍为 bottle-ocean 的现场；iframe、实例代号和当前 Document 归本次尝试所有，地址是预期同源入口，排除 about:blank 和错误文档。
2. 当前子窗口的 __bottleOcean.ready === true，没有 __bottleError；#loader-error 的实际错误文字也没有报错，即使其父遮罩不可见也要读取。
3. #gl 是当前连接中的原 canvas，CSS 与像素尺寸有效；原 renderer.domElement 对应这个 canvas；通过原 renderer 读取的上下文没有丢失，已有首帧绘制依据。
4. 原 #loader 的计算 display 已为 none；没有当前文档已记录的图形故障。原模拟被用户暂停时仍可 ready，不要求 simTime 始终增长或固定 FPS。

iframe load 和 bottle-ocean-ready 事件仅触发复核，不单独宣布成功。事件可能早于监听，需要读取当前状态并低频轮询兜底；加载/慢载入约每 200ms、就绪约每 500ms，卸载时全部取消。只读取原 renderer，不额外创建 canvas 上下文来制造成功证据。

首次网络响应延迟也计入 12 秒。首次取得目标文档不能重新计时抹去已出现的 slow；后续真实文档重载则建立新的文档代号和计时。slow 可自然转 ready，只有明确失败才转 error，不自动循环重试。

同源文档不可访问、实际返回错误页面或 HTML 结构/身份明确不符时，显示适当失败反馈，保留退出和独立打开。原画面出错不能被旧 ready、封面或宿主加载状态掩盖。

验收：正常、慢、失败与重载有确定去向；反馈只属于当前现场，用户在所有状态均能离开。

## 5. 实例、文档和图形故障归属

项目身份相同不足以证明回调仍有效。每次打开/重试有实例代号，每个新 Document 有文档代号；事件还要匹配当前 iframe 和 canvas 对象。旧页面、旧定时器和旧图形事件不能写当前状态。

图形上下文丢失时立即使当前现场失效，宿主转 error。原网页可能仍保持 ready=true、__bottleError=null，甚至错误遮罩仍为 display:none；不能依赖这些陈旧信号恢复 ready。

收到 contextrestored 只记录图形事件。该原版没有新图形代的可靠就绪证明，因此本次文档保持 error，用户重试或真实新文档重新建立后才能再次判定 ready。故障发生早于监听时，以原上下文 isContextLost、初始化错误和原错误文字补充判断。

真实重载时解除旧 Document/canvas 监听与引用，再识别新文档。旧 canvas 的迟到事件不影响新文档；当前异常也不污染另一作品。原罗森继续使用其原专用判据，不能借瓶中海洋 API 代替罗森信号。

验收：初始化错误、图形丢失、恢复事件、重试和同 iframe 文档替换均可区分，旧状态不会复活。

## 6. 创建、切换、重试和退出规则

| 动作 | 必须执行的行为 |
|---|---|
| 首次进入瓶中海洋现场 | 停止导览、保存主站阅读/焦点，暂停被覆盖庭院的持续绘制，创建一个原页实例 |
| 重复点击同一现场 | 复用本次实例，不叠加 iframe、轮询或监听 |
| 现场 → 档案 | 先使旧实例失效并卸载；仍处于作品覆盖层，庭院不提前在背景恢复绘制 |
| 档案 → 现场 | 新建原文档，从原默认状态启动；不偷偷恢复上一次波高、装饰或相机 |
| 切换独立作品 | 旧实例卸载后再挂载新实例；当前查看器最多一个独立作品 iframe |
| 切到庭院现场 | 卸载独立网页，按原主站场景规则恢复体验 |
| slow/error 重试 | 作废并清理旧尝试，重新建立文档、代号和 loading；连续重试仍最多一个实例 |
| 载入中立即关闭/去档案 | 取消待创建 RAF、轮询与事件；旧响应晚到也不挂回网页 |
| 关闭/转其他媒体查看器 | 清理旧文档与宿主任务后，交还覆盖层所有者 |
| 普通浏览器标签切换 | 保留同一实例，返回时复核真实状态；不自动 reset、重建或强制播放 |
| 整个主站销毁 | dispose 当前控制器及其任务，重复调用不报错 |

卸载先使实例代号失效，再取消延迟创建、定时器和所有监听，释放确属该实例的指针锁/全屏，移除 iframe，清除父级保存的子文档、canvas、API 和闭包引用。不要直接调用原场景内部 dispose 来猜测其资源归属。

原暂停仍持续绘制，因此不能把暂停或隐藏 iframe 当作卸载。主庭院可以暂停绘制并保留原上下文和状态；不声称只剩一个 GPU 上下文或显存同步归零。用户另行独立打开的窗口归该窗口所有，主站退出不擅自关闭它。

验收：每个动作只有一个活动独立实例；退出后旧文档不持续执行，旧回调不会改变当前项目。

## 7. 原输入、控制台和下载保留

原 12 滑杆、22 按钮及其内部行为由原页面执行，宿主不重做简化控制台。真实输入后核对场景、相机、对象或文件效果，不仅核对控件数量。

| 输入 | 本步保留标准 |
|---|---|
| 原页滚轮、左旋、右移、触摸 | 操作原相机/场景，主站滚动和石柱运镜不推进 |
| H | 隐藏/恢复原 UI，原恢复按钮可用，不改主站 UI |
| Space | 原模拟暂停/继续，保留原输入框与按钮焦点处理；不切主站环境播放 |
| 原页 Escape | 退出原编辑模式；子页有焦点时宿主不关闭、不转发第二次按键 |
| 宿主 Escape / 返回 | 焦点在宿主规定区域时关闭查看器并恢复阅读；返回按钮始终可用 |
| Tab / Shift+Tab | 能在原页与宿主工具栏间正常移动，不增加捕获所有按键的自制陷阱 |
| 原截图按钮 | 通过真实点击产生浏览器 PNG 下载，保留原用户激活和文件名 |

PNG 按子文档 canvas 的 CSS 尺寸×min(DPR,2)核对，内容是 WebGL 场景而非 DOM 控制台；至少两种子文档尺寸/DPR 条件，不能用父页面视口或固定 1920×1080 作为全部期望。保留真实下载文件并检查画面，不能调用 captureScreenshot API 替代点击证据。

验收：原页能正常操作，宿主未吞掉手势、快捷键或下载；进入前后主站阅读进度和用户动效选择不受子页控制影响。

## 8. 阅读、导览和资源恢复

复用已有 beginOverlay/closeOverlay、covered、syncLoop 与阅读锚点捕获，不另建第二套阅读状态。首次进入保存触发按钮、当前阅读位置/布局锚点、相机阅读进度及主站原动效选择；现场/档案切换不反复改写该快照。

原页初始化完成时不抢走用户当前焦点。关闭后优先用 preventScroll 恢复有效触发按钮；按钮已不可用时回到可用作品索引或阅读控件。尺寸变化后按实际阅读锚点恢复，不只套用旧 scrollY。

进入作品停止自动导览，返回后保持停止，用户主动继续才开始。主站原来暂停则返回仍暂停，原来播放则按原逻辑恢复。子页播放/暂停独立，返回后由原主站控制器重新计时，避免一帧补算整个停留时间。

要有实际主庭院停止持续绘制和旧 iframe 已卸载的证据，不能只凭“暂停/已关闭”标签。测试保留旧帧引用时也要区分调试引用与正式容器持有，避免凭短时显存读数作资源泄漏/释放结论。

真实 hidden 路径在先前云端未验证。本步仅在确实观测到 hidden/visibilitychange 时测试对应返回；不能覆写这些属性或派发假事件冒充。条件不具备则保留限制，继续进行独立可做的核查，不改变原网页时钟。

验收：覆盖时庭院不持续绘制，关闭后恢复正确阅读和用户选择；导览不自行续播。
