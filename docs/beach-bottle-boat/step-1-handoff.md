# 第一步交接：供第二步细化使用

固定原版本的独立功能基线已建立。第二步尚未执行；其目标是明确作品隔离、状态观察和资源归属，随后才保存运行文件、添加 Coding 入口、接通现场并做内嵌对照。

原版事实与宿主应承担的责任：

| 项目 | 已取得的原版依据 | 第二步应规定的接口/边界 |
|---|---|---|
| 独立成品 | index.html 自包含，SHA256 941feb2ea6ddd3cc93aad5b0b92dbca52ee66a3e1098fee0dbf16f01ca63d1ef；完整世界、原 Three.js 0.180.0 | 单独 iframe 文档；不将其场景、CSS、全局对象或引擎合入主站；后续第三步再保存原文件和声明 |
| 项目身份 | 当前罗森使用自己的原信号；瓶中海洋是新的独立作品 | 为 bottle-ocean 单列身份和状态观察，不能套用只识别 LAWSON 的判断；庭院仍按当前逻辑运行 |
| 初始就绪 | __bottleOcean.ready、bottle-ocean-ready；加载器稍后才结束，canvas 为 #gl，getDiagnostics 可读 | 事件只当作当前文档的一项证据；组合 ready、无初始化错误、加载 UI 结束、真实可用 canvas；iframe load 不等于就绪 |
| 初始失败 | __bottleError、ready=false、loader-error；禁用 WebGL 的实际失败路径已记录 | 与慢加载分别表示；错误时保留独立打开和重试能力；旧实例回调不得改变新项目 |
| 运行中故障 | contextlost 时 ready 仍可能为 true，__bottleError 为空，错误遮罩不可见 | 观察当前 canvas 真实事件并使宿主状态失效；重试创建新文档，不复用旧 ready。不为本步观测默改原成品 |
| 模拟暂停 | 原暂停冻结模拟，仍更新相机并绘制 | 暂停与卸载分开；关闭/切作品/去档案必须释放旧文档和宿主监听、定时器；不能以原暂停替代释放 |
| 后台标签 | 本环境未取得 hidden=true 的有效试验 | 不能宣称后台节流已通过；后续集成要用能产生真实 visibilitychange 的条件补核，继续区分普通标签切换与退出现场 |
| 输入归属 | 原 H 控制原 UI；Space 播放；Escape 退出编辑；原输入框/按钮有保护 | iframe 内按键归原页；宿主关闭键只在规定的宿主焦点条件处理。滚轮/拖动不推进主庭院导览 |
| 用户下载 | 原按钮和真实键盘激活均产生 PNG，场景不含 DOM 面板，按 CSS×min(DPR,2) | iframe/容器必须保留下载手势与能力；以后按子文档尺寸复核，不硬编码 1920×1080 |
| 镜头/编辑 | 五镜头、原旋转平移缩放、拾取、石头/贝壳、撤销/恢复均有基线 | 不重造简化控制台；保留原惯性、射线、限制；原问题与新增回归分开 |
| 窄屏现场 | 390×844 和 844×390 实际触摸代表路径通过，竖屏原取景存在裁切 | 查看器尽量占满工具栏外的可用空间，允许原面板滚动；尺寸变化按当前子文档 canvas 而非父页面推断 |
| 资源与主站 | 主站和罗森本步没有运行/修改；95 项生产输入、46 个运行文件与八组封存受保护 | 后续保证最多一个活动作品；进入时停止被遮住庭院的持续绘制，退出恢复阅读锚点、焦点和用户播放选择；导览不自行续播 |

后续对照使用 [34 控件矩阵](feature-matrix.md)、[本轮验收](step-1-verification.md) 和 [原问题](original-issues.md)。连续波高样本在 evidence/physics 中；原样截图和真实下载可作为画面与导出参照，但比较时必须统一视口、DPR、质量、机位与输入前置状态。渲染后端和相位变化意味着不能简单作逐像素相等断言。

第二步只需形成可审查的状态表、生命周期、输入/资源归属和最小修改范围；是否实施以用户后续指示为准。本步没有添加入口、复制到 public、改主站产品源码、提交、上传或部署。
