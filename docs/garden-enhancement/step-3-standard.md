## 1．现状、目标与范围

现有水球名义半径0.26场景单位、中心高度1.37、上下漂浮振幅0.03、周期6秒；使用12×8分段球网格，已有轻微形变。材质以逐面法线控制蓝色分级、白色顶部/边缘及很弱的sheen，尚无本轮要求的明显连续曲面流纹。[第一步原速水球记录](../evidence/garden-enhancement-step-1/water-orb-recording.json)保留现状，不能将它标为新水纹演示。

目标分三层：球面有可辨的流动纹带；波峰经过时高光/明暗随之改变；小幅表面起伏配合既有轻悬浮。球体保持蓝青体积、低多边形气质和与庭院一致的光照，在默认像素画面也有水在流动的感觉。

主修改位置：`src/config/orb.ts`、`src/animation/orbMotion.ts`、`src/materials/createOrbMaterial.ts`、`src/scene/createLivelyFountainEffects.ts`。必要时新增局部球面采样帮助模块。若诊断/参数归属确需传递设置，可对喷泉工厂/场景及庭院初始化做少量接线，不改变导航、路线、阅读或环境播放合同。

保护第二步两份CSS和介绍羽化成果、其他柱子/正文、16段/12.3H及十站、池体几何/水位、池水基础反射/色板/流速、建筑植被与旧参考稿。水球形变联动的水束长度、飞滴出生点/落点、真实落水波纹允许相应变化，但仍使用原有系统和容量。不实施自动导览、云影或飞鸟，不更换封面/旧12秒视频来冒充新效果。

## 3．3.2：确定流动层次与试作参数

| 项目 | 初始方向与约束 |
| --- | --- |
| 体积色 | 沿用现有蓝青、冷蓝阴面及浅白高光体系，保持统一线性着色/sRGB输出 |
| 主流纹 | 近景先试2～3段宽度足够的弯曲纹带，随球面连续流动 |
| 次级变化 | 一层较细的扰动/短波纹，速度与主纹略错开，密度服从实际像素尺寸 |
| 节奏 | 主纹先试约5～9秒的可辨变化节奏，次级约3～5秒；由实际观感校准，不要求与6秒漂浮机械同步 |
| 白色高光 | 分布在波峰与受光边缘，保留蓝青主体；避免固定白帽、整帧跳白或持续覆盖流纹 |
| 几何起伏 | 总局部径向位移先试名义半径的2%～4%，包含原有波形，不能在原振幅上直接再叠加4% |
| 既有漂浮 | 名义半径/中心、0.03漂浮及6秒周期先保持，实际必要调整须记录原因与保护影响 |

O画面中的球在默认384像素采样下只有有限像素：要求能辨水体光泽与流动节奏，W和现场体验能辨主流纹；不要求远景展示与近景同样密集的细节。效果必须在原始尺寸查看，放大截图不能代替默认画面可见性。

通过条件：主流纹、波峰明暗和轮廓起伏能分别辨认，蓝青球体仍清楚、与原庭院协调。

## 4．3.3：建立连续球面采样和时间定义

流纹绑定球体局部表面位置或连续的球面方向，沿曲面经过正面、侧面和顶部；不只用逐面常量法线作为纹理坐标。可采用连续三维程序场，避免UV接缝和极点集中；若使用其他坐标方式必须实测处理接缝。

几何位移、材质变化和相位使用统一参数/单位。增加只读静态属性时在几何创建时一次分配并记录字节数，不每帧重新建立原始坐标。着色器保留原Three法线、光照、阴影和一次sRGB输出路径，避免重复色彩转换造成过曝/发灰。

主/次频率分开且数量有界，利用屏幕导数或等价过滤处理细纹在低分辨率下的混叠。远景减弱不可分辨的细节，仍保留宽主纹；球体停止时纹理不继续漂移，移动相机时图案仍附着在球面。

通过条件：跨网格面、接缝和极点连续，曲面流动与漂浮可独立辨认，没有屏幕贴片感、逐面闪色或细纹闪烁。

## 5．3.4：实现水纹、波峰与小幅形变

先实现可读的主流纹和跟随波峰的明暗，再加次级扰动，最后校准几何起伏。每一层应能单独诊断，组合后重新查看原始尺寸，不用增加其他水花或飘粒子掩盖球面效果不足。

优先复用12×8网格。确需改善轮廓时，可先在不增加球网格数量的前提下试到20×12，记录顶点、三角形及耗时增量；进一步细分以实际必要性和预算为依据，不提高默认像素分辨率或DPR来凑效果。

位置与法线/高光变化保持一致。当前逐面法线可随真实几何变化保留，较细的波峰法线需与表面参数对应。避免细长尖刺、形体塌陷和剧烈缩放。重新计算真实最大形变的boundingSphere/AABB，覆盖原比例变化；不能只继续沿用旧1.06包络而不验证。

更新球材质shader cache key及实例归属，避免旧球/诊断对照的程序相互串用。普通访客路径替换原球材质，不添加透明外壳、额外全屏处理或另一套球体来叠效果。

通过条件：形体、高光和波峰关系自然，几何包络正确；Shader在三引擎正常编译，不能用黑球、纯白块或静默旧效果当作新效果通过。

## 6．3.5：校准水束、飞滴与落水波纹

球面增强必须检查关联的真实几何关系：

1. 每帧以实际变形球体最低点确定水束上端，保持合理重叠；水束下端仍连接原石台出水位置，长度始终为正，没有悬空缝隙或穿出球体的长水柱。
2. 飞滴出生点按**出生时刻**的球面位置、形变和朝外方向计算，后续沿既有解析飞行轨迹，不使用当前帧球面代替出生状态。
3. 在出生及离球阶段用实际变形网格检查不穿球、不被后续波峰吞入；检查底座/池壁间距及真实接触水面的位置。
4. 波纹继续来自真实落水事件，时间和位置与飞滴一致；不预先产生波纹，也不因模式切换或时间跳转重复发射。

沿用32滴、8个落水波纹的固定容量，保留既有种子、总体发射节奏、重力和生命周期。形变引起的出生点/落点变化在本步允许范围，池水基础风格保持。

延用现有几何检查的严格口径：球底与石台间距至少0.08场景单位；飞滴不穿球（原工具约−1e−5的数值容差）、不穿底座、池壁留边至少0.05；解析接触水面误差沿用原工具1e−8量级。若计算改用不同精度，须说明数值依据，不能为消除真实穿插而放松断言。

通过条件：球面、供水、离球和落水形成连贯运动；池体不变，关联波纹变化有真实事件依据。

## 7．3.6：统一播放、暂停与生命周期

球面流纹、形变、水束、飞滴和落水波纹都由现有环境时间驱动。不得直接用`performance.now()`另跑纹理、独立定时器或无限RAF。相同时间的完整场景重建应得到相同结果。

必须检查：

- 暂停后相位、形体和水纹冻结；手动运镜可继续，投影变化不等于水纹还在自行播放。
- 恢复从暂停状态继续，不重置或补跑大段隐藏时间。
- 正常/像素切换保留同一场景、时间和物理状态；切回原模式、同一时间时结果可复核。
- 图片/档案覆盖、离屏、实际页面隐藏/恢复，继续服从原暂停与节能规则；现场体验使用唯一画布。
- 减少动态沿用现有暂停和稳定阅读选择；解除偏好不擅自恢复此前主动暂停。
- 图形丢失/恢复与dispose继续可用，不泄漏新属性、材质、缓存或事件。

通过条件：停止和继续准确，界面选择保持，没有第二套时钟或媒体/场景重建导致的跳变。

## 10．3.9：资源与性能预算

继续使用一个场景、一个画布、原喷泉组与固定水滴/波纹池。目标新增纹理0、render target0、全屏后处理pass0、颜色绘制调用0、球网格数量0；材质替换不叠加壳层。几何细分可能增加顶点/三角形/缓冲字节，必须单独记录，不能把几何体“个数未变”说成没有成本。
