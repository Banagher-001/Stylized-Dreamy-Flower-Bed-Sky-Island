## 实际实现

球面使用静态原始坐标`orbRest`逐片元归一化，在连续三维方向上计算弯曲波场。没有经纬UV、屏幕坐标纹理或逐面常量采样，因此纹带能够跨面、经过侧面和顶部。主波7.2秒、次波4.1秒，另有23秒的缓慢绕转；相位全部来自原有环境时间，在CPU分别约化后送入GPU，避免长时间运行后直接用大浮点秒数计算细纹。

材质将蓝青体积、流动浅色带与波峰高光组合，保留实际光照、阴影、深度和一次线性着色/sRGB输出。主高光由同一主波决定，旧的固定顶部白帽已去除；短波用屏幕导数衰减，避免在默认384像素画面中堆积不可读的细纹。近景可见弯曲纹带，开场小球保留较粗的水光节奏。Shader缓存键更新为`courtyard-living-orb-flow-v2`。

真实径向形变改为2.5%主波加0.9%次波，**合计上界3.4%**，取代旧波形。名义半径0.26、中心高度1.37、0.03悬浮振幅、6秒悬浮周期及原有比例变化保持。仍用12×8分段、117顶点、168三角形，没有细分或增加球体。逐面法线继续由Three根据实际变形面求导。包络按径向上界与比例上界计算为`1.034 × 1.012 = 1.046408`，并同时用于AABB及boundingSphere。

水束上端每帧跟随实际网格最低点，加原0.025重叠；下端仍连接石台。飞滴出生位置取出生瞬间的同一球面，离球方向改为波面梯度的实际外法线，再施加原非均匀比例的逆缩放。此后保持原解析抛物飞行、32滴固定池、种子、重力、总体发射节奏和落水方程。8个波纹槽仍只读取真实落水事件；形变引起的出生点、落点变化属于本步关联修改。

## 文件与预算

| 文件 | 本步作用 |
| --- | --- |
| `src/config/orb.ts` | 波形参数、总振幅与保守包络 |
| `src/animation/orbSurface.ts` | 新增连续球面波场、有界相位及外法线采样 |
| `src/animation/orbMotion.ts` | 出生瞬间的球面与离球法线；保留解析飞行 |
| `src/materials/createOrbMaterial.ts` | 曲面流纹、波峰高光及细纹过滤 |
| `src/scene/createLivelyFountainEffects.ts` | 复用球网格，绑定静态坐标、相位和既有生命周期 |

新增静态GPU顶点属性1404字节；原CPU原始坐标数组直接复用，没有再复制一份。新增球网格、贴图、render target、全屏处理和颜色绘制调用均为0。相位Vector4随原时间更新，不引入独立RAF、定时器或每帧数组/几何分配。场景原有像素处理、384采样和DPR上限2保持。

正常/像素切换、暂停、手动运镜、覆盖、离屏及现场体验仍由原控制器管理。没有新增普通访客工程开关，`orb=legacy`仍表示更早的旧喷泉，不冒充本步修改前的球；真正的修改前对照由第二步独立成品提供。

第二步两份CSS、所有素材、池体与基础池水材质、其他柱子、正文、16段/12.3H路线、十个阅读站与五个主导航保持原文件。自动导览、云影和飞鸟没有开始。
