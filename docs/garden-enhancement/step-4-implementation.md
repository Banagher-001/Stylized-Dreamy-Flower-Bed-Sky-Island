# 第四步实现记录：自动导览与手动接管

当前候选`garden-enhancement-step4-2b6d5479a1939f3e`，基线为第三步`garden-enhancement-step3-79dad8c41ee79a61`。功能、三引擎、视觉保护、当次性能、实际原速导览及手动接管已通过，H01～H16当前环境验收完成，实体设备边界单列。本步修改仅涉及两个新增文件及原初始化文件，未改动三维模型、材质、路线、素材或正文。

## 已实现行为

默认手动浏览。顶部阅读切换旁新增单一导览按钮，对应“开始导览／停止导览／继续导览／重新导览”。停止始终可见；受限时显示“导览暂不可用”及可访问说明。顶部布局保留原底部阅读空间；环境按钮按第一步合同明确标为“播放环境／暂停环境”。正常/像素设置保持。

开始时读取真实文档滚动位置，沿原16段/12.3H路线向前接续。当前完整阅读站留在原位置并获得全部停留；部分显现先向前到完整阅读点；已经离开的段落不倒退。十站依次经过，上下滚动、导航和作品仍使用原系统。结尾到达S99后停止，明确重播才返回开场，不跨刷新自动运行。

停留采用本轮最新最低值：O4秒；A为10/14/14秒，B为12/10/10/8秒，C为10/12/12秒，水潭8秒，终章6秒。长正文按实际当前文章中文与英文词数延长。相机稳定、标题/正文/媒体完整且图片成功解码后，经过两个实际完整渲染帧才开始截止计时。失败图片沿用原错误占位，准备超8秒则暂停。图片load/error只唤醒当前到站检查，不启动已停止的导览。

导览只推进原生滚动，再由原相机采样和插值完成运镜。移动复用原渲染循环；阅读且环境暂停时只保留一个可取消的截止唤醒，不持续绘制。开启不改变环境播放选择，暂停环境仍能运镜，停止导览不改水球/草花的播放状态。真实隐藏、覆盖和离屏继续遵守原节能规则。

wheel、触摸、原生滚动条、浏览键/Tab、正文选择、章节和作品操作交还控制，不preventDefault、不锁滚动、不抢焦点。设置类画面/环境按钮不打断。初次在静止阅读站开启也会记录滚动所有权锚点；未知来源的位置偏移会让出控制。停止清理截止计时，以代次和句柄同时拒绝过期回调。

查看器关闭、页面返回前台、布局/缩放恢复、解除减少动态或图形恢复均不自动续播。稳定阅读保留原十个DOM文章节点和原文字；恢复沉浸后仍等明确开始。现场体验使用原唯一画布，原作品焦点、位置和视频释放保持。

## 实施中查明并修正的问题

确定性取消测试发现，已排队的旧计时回调可能在检查代次前清掉新句柄；现改为先核对代次、活动状态及实际句柄。首次直接从阅读站开始时可能没有写过自动滚动，现于明确开始时初始化所有权锚点，覆盖滚动条及辅助浏览。暂停环境时没有连续GL循环，现用真实图片load/error和decode完成唤醒当前到站，且明确拒绝解码失败后的重复微任务自旋。

中间候选及原始诊断保存在本步目录的`pre-scroll-init-fix/`、`pre-image-wake-fix/`和诊断JSON内，未冒充最终候选。原生键盘滚动/触摸惯性允许自然结束后再检查“无自动推进”，不为测试抑制浏览器输入。加载故障测试等待DOM/布局而非网络空闲，避免把故意挂起的资源误当页面未启动。原生滚动条测试采用真实窗口内1366×768视口，避免窗口右边缘裁切影响实际拖动。
