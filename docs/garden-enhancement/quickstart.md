# sakan 庭院网页：下载后怎样运行

只想看网页，下载文件名含`site`的成品包。要继续修改，下载含`source`的源码包。含`evidence`的是验收附件，不是网页入口。请先完整解压ZIP，再运行里面的文件。

## Windows查看成品

1. 安装Node.js，建议官网的LTS24 Windows安装程序：<https://nodejs.org/>。本次使用24.22.1验证；最低要求22.12。
2. 解压成品包，双击`START-PREVIEW.cmd`。
3. 浏览器会打开本地网页。保留启动窗口；结束时在窗口按Ctrl+C。

成品预览不需要`npm install`。中文或含空格的目录可用。4173端口有人使用时会自动尝试下一个端口，以启动窗口显示的地址为准。若浏览器没有自动打开，把窗口中的地址复制进去。

直接双击`index.html`的file://方式不受支持；这里的双击入口是启动本地HTTP预览的CMD脚本。显示的127.0.0.1或localhost地址只能在本机访问，把它发给朋友不能作为公开网址。公开访问需要将静态文件部署到网站托管服务。

## Windows修改源码

解压源码包，双击`START-DEV.cmd`。第一次会安装锁定的依赖，可能需要网络；随后在启动窗口显示的开发地址打开网页。修改`src`后页面会更新。

也可在源码目录的PowerShell运行：

```powershell
npm.cmd ci
npm.cmd run dev
```

使用`npm.cmd`可避开此前遇到的npm.ps1执行策略问题，不需要修改系统执行策略。npm最低版本10。

生成最终成品：

```powershell
npm.cmd run build
node scripts/preview-site.mjs
```

重新构建后重启预览窗口。源码包里的`START-PREVIEW.cmd`需要先有构建生成的`dist`目录；日常修改使用`START-DEV.cmd`。

## macOS或Linux

安装符合版本的Node后，在源码目录运行`npm ci`、`npm run dev`；生成成品运行`npm run build`。成品包在其解压目录运行`node scripts/preview-site.mjs`，不需要安装npm依赖。停止服务使用Ctrl+C。

## 页面怎么操作

- 向下滚动或触摸拖动，沿三根柱子浏览；右侧章节按钮可直接前往对应位置。
- “开始导览／停止导览／继续导览”控制镜头；真实滚轮、触摸、键盘滚动或选字会交回人工控制。
- “播放环境／暂停环境”控制水体、云影、飞鸟等，与导览独立。
- “正常画面／像素画面”切换风格；“稳定阅读”提供完整正文，窄屏或系统减少动态时也可使用。
- 图片、档案和现场体验关闭后返回阅读。项目档案中的12秒无声片段标为早期习作；第二柱图像仍标为网页设计样片。

## 常见问题

“找不到node”：重新安装Node LTS24，关闭旧终端后重新双击启动脚本。

“缺少index.html”：确认打开的是完整解压后的成品包，或源码已经成功构建；不要只复制HTML一个文件。

“安装依赖失败”：保留错误信息，确认网络可访问npm依赖源后重试`npm.cmd ci`。成品包本地预览不需要安装这些依赖。

“图形场景不可用”：使用稳定阅读查看内容；更新浏览器并检查WebGL支持后再试。

窗口显示端口冲突：默认入口会选择其他空闲端口；手动指定端口时可以换一个，例如`node scripts/preview-site.mjs --port 4188`。启动工具不会关闭已有服务。

Windows CMD本身的双击及自动打开浏览器需要实体Windows复核；本次Linux已实际验证共享Node入口、中文/空格目录、端口处理和完整HTTP资源，CMD脚本做静态检查，未把Linux运行标为Windows实测。
