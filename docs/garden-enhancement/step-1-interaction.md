# 自动导览与环境播放合同

这是第四步及相关环境动效的实施合同，当前页面尚未增加导览按钮。第一步完成的是规则、实际正文和路线基线；参数从本轮规范开始，后续细化时按实际画面确认。

## 两类控制与默认状态

自动导览控制原生滚动进度和相机浏览。环境播放控制水球、水纹、水滴、草花、树影，以及后续云影和飞鸟。默认保持手动浏览；环境播放沿用原设置和系统减少动态偏好。

建议独立导览按钮位于现有底部控件附近，普通访客只看到状态对应的中文。现有环境按钮改用“播放环境／暂停环境”，与导览区分。正常/像素按钮保持；按钮最小44×44CSS px、键盘可达、有明确焦点与可访问状态。

| 内部状态（仅规范用） | 按钮 | 行为 |
| --- | --- | --- |
| manual | 开始导览 | 用户明确点击才开始，从当前实际位置继续原路线 |
| moving / reading | 停止导览 | 包含移摄与阅读停留；可随时停止 |
| paused | 继续导览 | 用户主动停止或手动接管后保留当前阅读位置 |
| blocked | 导览暂不可用，并提供简短原因 | 稳定阅读、系统减少动态、隐藏、作品层打开或图形不可用等，不强行切换布局或恢复相机 |
| finished | 重新导览 | 到达结尾后停止；明确点击才回开场并重新开始 |

单一导览按钮不同时挤入开始、暂停、继续、重播四个入口。结束不默认循环、不自动回开场。停止不是重置位置；窗口刷新沿用当前页面既有开场规则，不新增跨刷新自动启动或追赶。

从未主动开始过导览时，打开/关闭作品、隐藏/恢复等保持manual，按钮仍为“开始导览”；只有已开始过的导览停止后才提供“继续导览”。临时blocked状态需保留原先的手动/暂停/结束身份，不把一次查看作品误当作已同意导览。系统仍匹配减少动态时不提供自动运镜，解除后也需明确操作；手动阅读和现有环境明确播放能力保持。

## 输入与控制权

| 事件 | 导览处理 | 环境/位置处理 |
| --- | --- | --- |
| 原生wheel、触摸拖动、滚动条拖动 | 立即停止追加自动推进 | 原生输入继续；视角不回弹到旧自动目标 |
| 用于滚动的键盘操作 | 停止并交还控制 | Home/End/Page/方向键/空格保留原生语义；输入控件和组合键不误拦截 |
| 点击章节、回看、跳过正文 | 先停止，再执行所选目标 | 保留原导航、稳定阅读和焦点合同 |
| 在正文开始选择/复制 | 停止 | 原正文节点/选择保持，不阻止默认选择或复制 |
| 打开完整图片、档案或现场体验 | 先停止，再记录作品层返回点 | 关闭回原内容和有效焦点；导览不自动恢复 |
| 悬停、单纯移动鼠标 | 不打断 | 不使停留计时无故重置 |
| 点击导览按钮 | 只执行对应导览状态变化 | 不强制开启或停止环境 |
| 点击正常/像素按钮 | 保留导览，若实际导致布局模式切换则停止 | 保留当前位置与主动模式 |
| 点击环境播放按钮 | 保留导览 | 仅环境时间/动作暂停或继续，自动镜头按原选择执行 |
| 切到稳定阅读/发生容量不足 | 停止，进入不可用状态 | 稳定阅读由人手动阅读；不自动滚正文或强制沉浸 |
| 系统变为减少动态 | 停止，不自动恢复 | 服从原暂停/稳定阅读；解除偏好后仍等明确操作 |
| 页面实际隐藏 | 停止并保存当前状态 | 环境/媒体服从现有隐藏合同；回来无时间追赶 |
| 方向/布局视口/有效缩放发生变化 | 停止，保持语义阅读锚点 | 布局稳定后由用户明确继续，避免误跳站 |
| 图形初始化失败或上下文丢失 | 停止/不可用 | 保留稳定阅读及原失败退路；恢复不自动开始 |

自动驱动的scroll事件、布局恢复事件和明确导航与真实手动输入必须区分。自动生成的scroll不能马上把自己判成手动接管；也不能通过preventDefault抢走用户输入。人工操作优先，不通过拦截浏览器滚动来维持导览。

停止处理要清理后续推进任务及过期回调；异步恢复/作品关闭不得重新拉起已被用户停止的导览。点击环境或画面控件属于设置操作，不把所有pointerdown都无差别作为接管；正文选择、导航、作品操作等按上表处理。

移动浏览器栏引起的visualViewport事件按实际布局/容量是否变化处理，不能把每一次可视高度通知都当作用户打断。真实方向、布局宽度、有效缩放或阅读容量改变则按表停止并保留锚点。

## 当前位置与续播

统一使用当前原生滚动位置、现有路线H以及已显示相机姿态。启动、停止和手动接管需要校准这些状态，不单独维护与页面脱节的另一条相机时间线。既有相机插值与文字显隐仍按路线进行。

继续时从当前实际位置向前，跳过已经经过的章节；若当前在完整阅读站，重新给予该站完整停留。若当前在转场中，连续接上剩余转场；若在文字尚未完整显现的阅读段，先缓慢到该站完整阅读点，再开始完整停留。到达结尾后只提供明确重播。

手动反向滚动后，从新的位置继续；不回到停止时的旧站。重新导览的回开场也是明确用户动作，需要可打断，不在页面隐藏后积累大量待执行位置。

## 环境同步与绘制

水纹、球体、水滴、草花、云影和飞鸟共用环境时间。暂停冻结它们的位置/姿态；恢复不补跑隐藏时间、不跳过多个周期。镜头导览状态和停留计时独立于环境播放选择，因此暂停环境时仍可导览。

接入现有绘制调度和唯一相机；不能为每个功能增设无限RAF。镜头在移动时按需绘制，停留且环境暂停时避免重复绘制同一画面，可使用可取消的停留调度唤醒后续移摄。隐藏、覆盖和离屏保持现有节能合同，异步回调使用有效性检查避免复活旧任务。

## 第四步与最终综合验收场景

从开场及A2/B2/C2/水潭等中途位置开始；每站完整文字出现后才计时；停留与移摄期间分别停止；滚轮正反、触摸、键盘、拖滚动条、选字、导航接管；查看器打开/关闭；切画面/环境；稳定阅读/缩放/方向变化；减少动态与实际隐藏；图形失败/恢复；结束及可打断重播。每项同时记录当前真实滚动位置、显示相机与有效阅读站，防止只验证按钮文字。
