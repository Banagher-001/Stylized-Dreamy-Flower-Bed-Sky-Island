# 第二步执行标准：修复「关于我」背景的完整羽化

状态：**已按用户“开始执行”及“没完成就继续执行”的指示完成本步。** 本文保留执行标准；实际结果见[实现](step-2-implementation.md)、[验收](step-2-verification.md)与本步summary。第一步签收文件和旧交付包保持，第三步尚未执行。

前置：[第一步设计规范](step-1-design.md)、[基线验收](step-1-verification.md)。本步只处理第一柱A1身份、A2经历、A3创作方向的背景与正文分层，不实施水球、导览、云影或飞鸟。

## 1．问题依据与最终目标

第一步已在1440×900/DPR1和390×844/DPR2、正常/像素四组条件下复现。当前`.pillar-reading::before`使用`#223b33`底和含模糊滤镜的SVG遮罩；外缘alpha最大值为左25、右43、上23、下28（满值255），最明显一侧约16.86%。伪元素的box-shadow和filter本身为none，模糊在SVG内部。

证据：[当前边缘近看](../evidence/garden-enhancement-step-1/about-edge-detail.png)、[实际测量](../evidence/garden-enhancement-step-1/about-edge-measurement.json)。该数值说明遮罩未完整收至透明，不等于最终页面各像素都具有相同不透明度；修复必须同时解决实际画面的暗沿、四角与被截断的过渡。

最终应呈现一层与庭院融合的深绿雾幕：中心支撑浅色文字，向四周连续淡出，外缘自然消失；文字清晰、可选择，显隐仍具有原来的魔法感。只把最外一行像素清零不算完成，完整羽化带和四角也须自然。

## 2．本步范围与保护项

优先调整`src/tour/tour.css`中第一柱背景伪元素。只有实际需要独立背景尺寸/缓存时才调整`src/tour/createPillarReader.ts`；稳定阅读覆盖规则需要配合时，限定修改`src/tour/readingLayout.css`。必要的新本地遮罩资源可以独立命名，不覆盖旧图像或视频。

保护：

- A1/A2/A3原文字、字体层级、可访问名称、正文节点、选择复制及焦点语义。
- `sampleMagic`的原进度、标题/正文显隐和字形装饰；文字原有的显隐遮罩继续保留，新背景羽化不施加到文字层。完整阅读时正文保持完整可见。
- 原生滚动、相机、16段/12.3H、十站及五入口。先保持面板外盒和现有锚点定位，避免为背景修复重新安排镜头。
- 第二/三柱、作品查看器、稳定阅读、减少动态、图形失败阅读及旧参考稿。
- 第一阶段证据、已有源码基线和10份release文件；不重写旧证明来替代本步证据。

不修改全局色板、水球/池水、动画时钟、渲染分辨率或依赖版本。本步新增WebGL资源预算为0。

## 3．2.1：复核并建立本步修改前记录

核对第一步封印与当前工作区，识别用户后加修改并保留。记录本步源文件、dist及既有交付包摘要，建立`docs/evidence/garden-enhancement-step-2/`。当前应用仍匹配第一步时，可复用其独立基线；有变化则保存正确的新修改前对照，不盲用旧截图。

保存A1/A2/A3完整阅读和显隐阶段的代表画面，采用相同H、环境时间、画幅、DPR、模式和字体条件。第一步51张图与资源/性能记录作为明确引用，不换成本步新测计数。

通过条件：修改前后有同条件对照；基线可恢复；用户新内容、旧归档和第一步证据不会被覆盖。

## 4．2.2：分离背景、正文与空间锚点

沿用独立背景伪元素或等价装饰层，背景不参与正文测量、选择、焦点和点击。装饰不进入读屏内容，不拦截滚轮/触摸或扩大可点击区域。

背景颜色与二维透明度统一计算，避免多片半透明色块叠加使四角或接缝额外变黑。羽化只作用于背景，不对整个面板加blur、mask或opacity而连带降低文字清晰度。

先保留原面板宽高、正文位置和锚点。若确认不可见文章撑大背景，允许为背景建立独立尺寸；须记录原因，缓存尺寸，并验证三段切换。不能通过删除长文、压缩字号、修改路线或让正文溢出来缩小背景。

通过条件：背景与文字可分别核对；正文仍是原来三份DOM内容，空间定位和输入语义保持。

## 5．2.3：重建完整羽化

优先采用随实际尺寸自适应的背景与渐变遮罩。若保留SVG，需处理真实宽高比例、滤镜范围、透明留白和缩放，不能只沿用固定420×240图形放大后就判定通过。

| 项目 | 初始设计范围与约束 |
| --- | --- |
| 背景色 | 保持原深绿`#223b33`及现有色彩体系 |
| 中心强度 | 完整阅读时先试0.82～0.92不透明度，依据最终合成对比度校准 |
| 桌面羽化宽度 | 20～36CSS px，建议从24px起试 |
| 手机羽化宽度 | 16～24CSS px，建议从18px起试 |
| 文字安全区 | 可见字形处于稳定深色区，与明显羽化区留约8CSS px余量；不足时先调整背景范围/羽化宽度 |
| 外缘 | 最外至少1CSS px为透明安全带，实际alpha为0；设备像素采样最多允许1/255的舍入误差 |
| 四角 | 与四边连续衔接，不出现拼接缝、深色堆叠或更黑的角 |

过渡曲线应平顺，不出现突变或额外一圈暗带。背景外扩时，完整羽化边界应留在实际可见范围内，不让视口、底栏或父元素裁切代替淡出；不能遮盖导航和其他控件。必要调整需同时检查手机边缘与左右布局。

不加新的黑色描边或外围阴影。遮罩无意失效时仍应有可读背景，不遗留失效滤镜或让正文消失；具体兼容方式在三引擎实际结果中说明。

通过条件：完整页看不到割裂的外框，放大观察四边四角没有截断和脏圈，外缘数值与完整羽化带的视觉结果同时通过。

## 6．2.4：校准三段显隐和往返

背景继续跟随现有`--veil-opacity`及原阅读阶段。允许独立校准背景的最大强度，不改变正文、标题和字形的时间关系，也不新增独立动画时钟。

每站至少检查显现、完整阅读、离开及前后未激活状态；代表归一化进度可采用约0.18、0.55、0.93，并以实际阶段为准。A1/A2/A3分别检查正向和反向滚动、停在过渡中间、快速跨站再返回。

背景不能突然闪成矩形，也不能在正文隐藏后留下悬空绿块。三段高度不同、字体加载或视口改变时，背景尺寸变化不能把相机或滚动位置拖动。减少动态时沿用现有稳定阅读和暂停语义，不额外持续漂动雾幕。

通过条件：三段显隐自然、可逆，中途停住时画面稳定，没有背景残留或布局跳动。

## 7．2.5：核对文字、选择与稳定阅读

完整阅读时，标题/正文像第一步一样清晰，字体、字号、行距和内容保持。正文对比度至少4.5:1，按最终合成背景或真实最不利底色检查，不能只比较原始深绿色值。

测试鼠标选择、触摸选择、复制、键盘焦点与导航；原有文字节点不重建，不通过透明覆盖层阻止选择。切换稳定阅读后，三段均为完整正文，不出现第二份重叠背景、无意义留白、截字、横向溢出或重复ID。返回沉浸时保留阅读锚点和原有暂停选择。

通过条件：背景修复不削弱文字阅读及现有无障碍合同，稳定阅读/图形失败退路继续可用。

## 8．2.6：实际尺寸与透明度测量

必须保留完整正式页面截图，并在实际背景尺寸、DPR和样式下检查外缘、四角与羽化带。第一步420×240固有SVG读数只作旧版参考，不能把它当作新遮罩在所有尺寸下的最终读数。

可在独立测试态隔离真实背景层，采集RGBA/透明度：保持背景本身的样式、结构、尺寸和遮罩，仅隔离下方场景及文字以便读alpha。测试报告标明隔离条件，同时提供实际页面的未处理截图；不二次羽化截图，不裁掉边缘，不为测量临时更换遮罩或添加透明边框来制造通过。

同时检查边缘到中心的渐变分布，防止“只有最后一根透明线，但内部仍是一圈硬暗框”。正文区域另核对最终合成对比度。CSS遮罩方案与SVG方案可采用相应测量方式，不为了复用旧测量脚本而反向限制产品实现。

通过条件：方法、尺寸、DPR、坐标和源版本可追溯，数字与实际完整画面一致。

## 10．2.8：资源、构建与真实性

本步WebGL几何、纹理、程序和绘制pass新增为0；CSS合成成本单独观察，不将“WebGL资源未变”误称为浏览器绘制成本为0。尺寸、遮罩或本地资源按变化缓存，避免每帧布局读取、反复编码SVG/分配Canvas、反复写相同样式或新增无限RAF。

若涉及滚动/布局热路径或出现实际性能疑点，在当次相同环境下独立重测基线与候选各30次原生wheel，p95恶化超过10%需定位处理。第一步190.6ms只代表它记录的环境，不跨不同运行条件强行比较。软件图形不当作真机FPS。

运行严格类型检查和生产构建，打开实际产物核对背景及正文。新增本地资源时核对根路径/子目录URL及真实MIME，资源随站提供，不增加CDN、后端或npm依赖。未改动的历史合同可用源码摘要与原证明明确继承，不把旧215组或第一步51图写成本步新跑结果。
