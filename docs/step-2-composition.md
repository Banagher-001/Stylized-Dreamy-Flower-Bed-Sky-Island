# 第二步：构图、比例与固定镜头

> 本文保留第二步的构图验收。第三步沿用同一镜头与布局，更新后的光影说明见 [第三步光影记录](step-3-lighting.md)。

## 执行范围

根据用户确认的第二步标准，替换第一步验证方块，用简单几何体建立八边形喷泉、三根石柱、左侧矮墙和右侧石板路。只确定镜头、比例、位置、遮挡与留白。本阶段保持第一步色板、基础灯光与像素采样机制，未增加依赖。

完成后停在第二步验收点。第三步才统一调整光影与配色，第四步完善石头造型，第五步加入植被，第六步制作水面动画，第七步确定最终像素尺度。

## 构图参照

只以方形场景画布为参照，不计算网页边距、标题和按钮。左上为 `(0,0)`，右下为 `(1,1)`。参照对话中的庭院截图，以喷泉为中心，三根柱子形成外围节奏；左墙与右路延伸出画面，保留上方与左下方的草地留白。

目标与实测位置：

| 对象 | 初始目标锚点 | 实测投影锚点 |
| --- | --- | --- |
| 喷泉 | `(0.51, 0.52)` | `(0.5102, 0.5259)` |
| 左上石柱 | `(0.37, 0.28)` | `(0.3701, 0.2796)` |
| 右侧石柱 | `(0.90, 0.54)` | `(0.8996, 0.5401)` |
| 下方石柱 | `(0.63, 0.93)` | `(0.6302, 0.9298)` |

锚点为各模型组在地面上的原点，柱脚有实际面积，因此边界会超出原点。实测喷泉整体横向占比 **48.26%**，符合 45%～50% 的目标。

三根柱子的主要轮廓和喷泉整体都在画面内。左墙和右路作为延伸结构允许触边与出框。未通过手机专用物体位置或镜头来改变构图。

## 固定镜头

配置位于 `src/config/scene.ts`：

| 参数 | 当前值 |
| --- | --- |
| 相机类型 | OrthographicCamera |
| position | `[4.5, 23, 16]` |
| target | `[0, 0.45, 0]` |
| viewHeight | `11.3` |
| near / far | `0.1 / 100` |

提高俯视角使池内水面可见；选择较小的侧向方位角，使柱头的地面投影接近参考图中的倾斜方形。可见范围用于让喷泉宽度接近画面一半，并容纳三根柱子的上下边界。相机不旋转、不绑定轨道控制；尺寸变化只更新投影与渲染分辨率。

## 模型与世界坐标

配置位于 `src/config/layout.ts`，Y 轴向上，单位为场景单位。每组原点位于地面，内部结构使用底部高度定位。

| 模型组 | 位置 `[x,y,z]` | Y 轴旋转 |
| --- | --- | --- |
| fountain | `[0.12,0,0]` | `0.12` 弧度 |
| columnUpperLeft | `[-2.34,0,-2.9]` | `0` |
| columnRight | `[4.41,0,-1.0]` | `0` |
| columnLower | `[2.96,0,5.09]` | `0` |
| wallLeft | `[-4.25,0,2.25]` | `-0.5` 弧度 |
| pathRight | `[5.33,0,1.38]` | `0` |

喷泉：

- 八边形底座半径 2.76，高 0.12。
- 池沿外半径 2.65、内半径 2.28，从底座上方再升高 0.46，顶部高度 0.58。
- 池沿使用带真实内孔的挤出几何体，内部墙面可见。
- 水面为不透明、静止的八边形平面，高度 0.32，低于池沿。
- 中央台座由底脚、柱体和台面组成，顶部高度 0.96；底脚位于水面下，柱体与水面相交，避免浮空。

三根柱子复用相同尺寸：

- 底座：1.04 × 0.18 × 1.08。
- 柱身：0.72 × 3.05 × 0.78。
- 柱头：1.02 × 0.24 × 1.04。
- 总高：3.47。尺寸顺序均为宽 × 高 × 深。

左墙由底座、墙体、压顶和端部块体组成，墙身长度 4.1。右路为两排、每排四块石板，共八块；每块 0.63 × 0.09 × 0.52，中心间距为 0.74 / 0.63，保留草地缝隙。

## 结构与资源管理

`createBlockout.ts` 创建六个具名对象组；`createScene.ts` 负责地面、基础灯光、相机和生命周期。

当前整个场景共 28 个网格，复用 5 个几何体与 4 个材质。重复方块共用单位 BoxGeometry，通过缩放和位置确定尺寸。所有生成几何体、材质均由所属模块清理，热更新时移除旧组，保留单画布。

页面沿用第一步布局和控件，只更新场景说明与无障碍文本。依赖清单、锁文件、色板和页面 CSS 保持不变。

## 遮挡与边缘检查

- 逐顶点投影确认喷泉与三根柱子的轮廓全部位于画布内。
- 通过相机射线确认中央台座顶部首先命中台座自身。
- 在水面周围抽查八个点，射线首先命中水面，确认池沿真实内孔和外部物体没有遮住这些点。
- 查看正常、像素与手机截图，主要结构可辨，没有发现意外穿插或深度闪烁。
- 底部柱子的基础投影有一部分延伸出画布；柱体本身完整。阴影长度、颜色与构图将在第三步统一调整。

## 当前差异与后续方向

与参考图相比，当前石柱和石板规整，草地为纯色，缺少树影、小花、石头破损与水面反光。这些属于后续阶段。第二步主要建立空间关系，并未宣称最终风格已经完成。

验收重点：喷泉大小与镜头角度、三根柱子的分布、矮墙和道路对留白的影响。对应 [第二步验收报告](step-2-verification.md)。
