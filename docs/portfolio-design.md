# sakan 个人作品集

本轮将原有庭院网页扩展为张辰翰的个人作品集，保留已有三维场景作为动态封面。姓名、化名、经历和方向均按本次提供的信息撰写：sakan（萨坎），现于枫叶互动专注 AI 动画，此前在游族网络工作，熟悉主流 AI 图像/视频工具并使用 Vibe Coding。没有添加未提供的任职年限、职级、客户或业绩。

## 页面设计

1. **封面**：左侧以大尺寸 `sakan.` 字标与「让想象，动起来」建立个人识别，右侧完整保留正方形庭院。镜头、构图与材质保持。正常/像素模式和播放/暂停仍可操作。
2. **关于我**：深绿整块版面承接庭院树影，使用米白文字、草绿标记和淡紫像素点。展示本名、化名、简介、当前/此前经历和三类能力；化名来源以小字补充。
3. **作品策展**：宽幅概念主视觉作为开场，下面以横幅交互场景和竖幅材质研究错位编排。作品进入视口时轻微上移显现，悬停时放大画面并强调入口。减少动态时关闭这些过渡。
4. **项目档案**：点击作品后打开大幅画面与项目说明，展示视觉关键词、分镜或无声影片。使用浏览器原生 dialog，提供 Escape、焦点限制与返回原入口，关闭时暂停视频。
5. **浏览方式**：顶部锚点导航、当前章节提示、分类筛选及返回顶部均可用。手机上改为纵向阅读，保留完整封面画面与至少 44 CSS 像素的主要控制目标。

两张新图在卡片、详情及作品区说明中标为「概念样片」，没有冒充已交付的个人/公司项目。网页为未来真实 AI 动画保留视频与分镜字段，目前没有生成或杜撰个人动画成片。没有虚构联系方式、外链或合作入口。

图像保留原始构图，转换成 WebP 供网页使用，总计约 285kB；原始 PNG 留在云环境 `/workspace/generated_images/`。应用只依赖 `src/assets/` 中的版本。图像懒加载，视频 `preload="none"`，打开详情后由用户主动播放，没有自动播放声音。

## 后续更换内容

主要编辑 [portfolio.ts](../src/content/portfolio.ts)，无需改动三维场景。

| 字段 | 内容 |
| --- | --- |
| `brand`、`name`、`alias` | 个人识别、本名及化名 |
| `cover` | 封面标题、介绍与画面题注 |
| `about.paragraphs`、`facts` | 简介与当前/此前经历 |
| `about.capabilities`、`aliasNote` | 能力标签与化名来源 |
| `projects` | 作品顺序、名称、说明、分类、视觉与关键词 |
| `project.kind` | `visual` 归入影像与视觉，`interactive` 归入交互实验 |
| `project.concept`、`badge` | 真实内容状态与显式标注；替换成真实项目后再对应修改 |
| `project.video` | 真实视频资源与题注，可选 |
| `project.frames` | 分镜图片与题注，可选 |
| `project.link` | 项目外链，可选；仅接受 http/https/mailto |
| `contactLinks` | 真实联系方式，可选；目前为空 |

将真实图片或 MP4 放入 `src/assets/`，像现有资源一样通过 import 引入，Vite 会处理打包路径和缓存哈希。新增视频保持原生 controls、playsinline 与按需加载；有对白时应同时提供字幕与内容说明。两张概念图可直接替换为真实动画海报，详情中填入对应影片和分镜。

布局/交互在 [createPortfolio.ts](../src/portfolio/createPortfolio.ts) 与 [styles.css](../src/styles.css)，场景与页面连接在 [main.ts](../src/main.ts)。

## 场景与阅读性能

通过真实 IntersectionObserver 检测封面是否离屏；离屏或打开项目档案时停止渲染，返回时重置时间基准，保留手动暂停选择。没有创建第二个 WebGL 场景或给每张卡片复制渲染器。

WebKit 在新布局中可能在暂停切换模式后呈现上一帧，已将按需提交改为可合并的两帧预算；预算耗尽后停止，不运行持续的暂停循环。镜头、场景几何、材质、色板、分布、动态公式和像素取样没有改变。

本轮验证与截图见 [验证记录](portfolio-verification.md)。当前修改保存在云环境草稿中，未发布、部署、提交或推送。
