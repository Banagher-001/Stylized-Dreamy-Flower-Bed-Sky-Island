# 第 1 步设计审查

本步完成的是可实施的设计文件。用户已授权第一步文件落地；本记录不代替用户对文案和分镜的视觉评审，也不把未来镜头列为已运行通过。

| 编号 | 设计标准 | 本步证据与结论 |
| --- | --- | --- |
| D01 | 路线完整 | 全景 → 左上柱 → 右侧柱 → 前下柱 → 水潭 → 全景，设计覆盖完整 |
| D02 | 十个阅读位置明确 | A1～A3、B1～B4、C1～C3，均列出柱对象、高度、文案或待补状态、呈现方式与素材引用 |
| D03 | 滚动分段连续 | 16 段从 0H 连续到 12.3H；每段有距离、镜头意图、文字状态与交接规则 |
| D04 | 模型约束与运镜边界明确 | 十个高度位于现有柱身 Y=0.18～3.23 内；未来相机坐标、碰撞与遮挡仍待原型 |
| D05 | 魔法浅字的规则明确 | 深柱浅字、四阶段显隐、稳定阅读区、反向恢复和正文清晰度目标已记录 |
| D06 | 异常操作与导航行为明确 | 快滚、倒滚、窗口变化、章节跳转、影片返回和减少动态均有约定 |
| D07 | 内容真实性明确 | 用户提供的身份经历、已有真实场景、生成样片、缺失资料分开列明 |
| D08 | 可交接且范围受控 | 第二步只做基础运镜原型的交接边界已写明；已有应用与交付文件以摘要核对保护 |

本次自动核对结果位于 [verification.json](../evidence/scroll-garden-step-1/verification.json)，包含滚动预算、导航目标、站点关联、实际模型尺寸、资源路径和已有文件摘要。该核对是设计一致性审查，不是浏览器运镜、性能或画面验收。

## 后续仍需验证

- 第 2 步：镜头实际坐标、连续曲线、速度收敛、碰撞与遮挡；当前 0.2 秒为目标值。
- 第 3 步：第一根柱子的向下阅读、正文布局和段落交界连续性。
- 第 4 步：深柱浅字的实际对比度、清晰字形与魔法光效；当前 4.5:1 为目标值。
- 第 6 步：真实 AI 动画、海报、分镜、职责和更多项目。
- 第 11 步：真实设备、触摸、窗口变化、减少动态与性能。

## 可在审阅中调整

本轮文案为基于已有事实的草案；阅读高度和 12.3H 是原型初值。若更改段数、素材安排或滚动距离，应同步主分镜、JSON、CSV 和路线图，不能只改其中一份。

第一步停在设计交付点。网页保持现状，后续先细化第二步标准，按用户明确指示推进。没有发布、部署、提交或推送。
