## 4. 文字与柱子的空间关系

柱面承载站点编号和简短识别标题，正文在对应高度的柱旁展开。正文位置由当前世界锚点投影到舞台，再作阅读区域约束；不随浏览器文档向上滚出固定舞台。

- 桌面沿用柱子偏左、正文向右展开的构图。与柱面保留明确联系，临时锚点可作为校准标记；正文背景有稳定的深色承托，避免草地和阴影影响阅读。
- 编号锚点随相机/投影更新。正文只在当前站可见，旧段离开时轻微向上退出，新段从下方轻微进入；位移控制在约 8～12 CSS px。
- 主阅读区中锚点、字号、行距和正文亮度稳定。禁止按时间抖动正文、逐字强制播放或周期闪烁。
- 文字采用独立清晰的页面层，保持中文与英文阅读质量；场景继续使用现有像素管线。最终符印、文字粒子和字缘光由第 4 步设计。
- 文本不得覆盖当前柱身的主要识别部位，也不得被控制条、章节导航或其他面板遮住。窄屏允许调整正文相对锚点的排布，不硬套桌面横向展开。

排版目标：桌面正文 16～18 CSS px，手机正文至少 16 CSS px，行高约 1.55～1.75；正文阅读宽度根据视口控制在约 18～26 个汉字。完整阅读态的正文与其实际承托背景对比度目标至少 4.5:1，执行时记录测量条件。

正文自然换行，不使用内部滚动区。当前三段真实短文必须完整显示；另用明确标注的约 160～220 字长度测试样本验证容量，测试文本不作为个人经历发布。容纳不下时先调整展开区与留白，不能靠无限缩小字号或截断正文通过。超出原型可读容量的长内容在后续内容阶段拆站，同时更新滚动预算；本步报告容量边界，不悄悄增加第四站或改动 12.3H。

## 5. 显隐与状态规则

每站段内进度记为 u，全部状态从同一个显示进度计算：

| 段内进度 u | 正文状态 |
| --- | --- |
| 0～15% | 隐藏，接近阅读位置 |
| 15～30% | 使用连续曲线从透明到完整可读 |
| 30～80% | 不透明、稳定阅读；该站相机保持 |
| 80～100% | 使用连续曲线退出，到 100% 完全隐藏 |

不同站点的正文不同时处于完整阅读状态。旧段退出、新段显现之间留出明确的空间交接；前后站点切换不能出现旧正文突然换成新正文。

站点 ID 可以在 2.1H、2.9H 处变化，但此时正文已完全隐藏。可见编号与其正文一起显隐；调试焦点跟随连续插值的关注点，不能因切换站点 ID 而瞬移到下一高度。

相机、站点编号、正文、透明度和位移全部共用显示进度，避免镜头进入 A2 而页面仍显示 A1。快速滚动直接求当前位置，不排队补播经过的段落。

停滚后短暂收敛到实际文档位置并保持；停在半透明位置就保留该位置，继续滚动才推进。向上滚动在同一位置恢复相同的相机与文字状态，环境时间无须倒放。环境暂停时阅读机制继续工作；全部停稳后无持续绘制。

只有当前正文进入可访问阅读内容，隐藏段落不响应点击/聚焦。使用语义化标题和段落；滚动不抢夺焦点，屏幕阅读器提示不逐帧播报。保留现有减少动态偏好处理，完整静态章节适配仍在第 11 步。

## 6. 窗口与输入合同

- 滚轮、触控板、键盘、触摸和临时站点定位共同控制实际文档滚动；不另建滚轮次数计数器。
- 调整窗口或切换横竖屏时保留「当前段 + 段内比例」，重新计算滚动距离与投影；保留暂停选择和画面模式。
- 第一柱导航仍到 A1 的完整阅读区。第二、第三柱和水潭定位继续可用。
- 正常画面／像素预览切换不重置站点、缩放、透明度或环境时间。
- 标签页恢复、图形上下文恢复后，镜头与正文保持同一进度，不闪回柱顶或重复播放显现。
