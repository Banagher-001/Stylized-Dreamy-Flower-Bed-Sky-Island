# 第8步实现：中央水潭

按[第八步标准](step-8-standard.md)完善水潭。原型继续在既有预览地址后加 `?tour=prototype` 进入。默认参考作品集保持原样；`pool=legacy` 为开发对照入口，可独立恢复原型原水潭外观，不新增产品菜单。

## 池沿与水面

本步使用局部材质完成，**没有新增或修改任何原池体几何**。水潭中心[0.12,0,0]、旋转0.12、外/内半径2.65/2.28、基座半径2.76、水位0.32、池沿顶0.58和石台顶0.96保持。八段压顶、原缺口、真实孔洞和连续内壁保留。

13个水潭石构件独立绑定专用石材，表面层次为暖浅压顶、冷青灰侧壁、窄分界、内壁/石台水线湿痕与低饱和接地色。两处原缺口附近有少量灰绿风化。其他建筑仍使用原材质，三柱、墙、路径、植物、灯光和阴影几何不变。

水面独立绑定不透明程序化材质。浅岸色#B4DAD9、主体#BED4DF、少量中蓝#95BECF和深蓝#245B80形成层次；主反射为左侧、远岸和一小段近岸三组有方向的形状，边缘稳定破碎，中央保留安静水色。实际建筑阴影继续压低水色和高光。

局部坐标图案不会随相机滑动，利用像素覆盖估计让细节在远景减弱；正常和像素模式共享实际场景与原渲染管线。没有新增反射相机、抓屏纹理、透明叠层、动态灯、Bloom或全屏pass。

## 动效与第九步接口

主流动速度0.035、背景波速0.36、背景波强0.15、实际落点波强0.42，泡沫宽度起点0.015～0.04。保留原32水滴、8落点、0.65秒事件寿命和0.30扩散速度；只改变水面上事件的宽度、分段与视觉强弱。

所有动效仍使用现有环境时钟。播放/暂停、后台隐藏、项目档案、现场体验、改尺寸与上下文恢复合同沿用第七步。减少动态默认暂停，显式播放仍可用；没有第二时钟或持续空转的新RAF。

水球、水柱和水滴实现/全局参数文件完全保留。7个固定时间的水团/水柱矩阵、水滴实例矩阵、jet材质分支和impact事件与旧版完全一致。第九步仍需单独执行，其[详细标准](step-9-standard.md)只作设计，不包含水球代码修改。

## 接入与所有权

- `src/config/fountain.ts`：独立水潭颜色与运动参数，旧waterConfig不改。
- `createRefinedWaterMaterial.ts`与`createFountainStoneMaterial.ts`：独立水面/石材分支，明确缓存键。
- `createFountainAppearance.ts`：14个网格的可逆材质绑定；释放时还原原材质并销毁专用材质。
- `createScene.ts`：新增显式外观参数，默认legacy；原型选择refined，对照参数选择legacy；装饰构建失败可保留旧外观。
- `startTourPrototype.ts`：启用新外观并记录诊断状态；原交互不变。
- `route.ts`只更新水潭段过时说明，相机、曲线和预算保持。
- `experimentContent.ts`更新当前封面和实际水潭功能说明，三站短文和全部旧素材保留。

当前封面为新文件[courtyard-water-cover.webp](../../src/assets/courtyard-water-cover.webp)，真实O画布、时间2、像素模式、1440×793。第七步封面与原12秒片段/采样帧未覆盖；档案继续明确标记早期固定视角视频。
