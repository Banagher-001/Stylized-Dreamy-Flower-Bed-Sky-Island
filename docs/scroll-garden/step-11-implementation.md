# 第11步实现：手机与阅读适配

本步按[执行标准](step-11-standard.md)实施。当前实现提供沉浸浏览与稳定阅读，复用原三柱正文、作品和唯一庭院画布；逐项结果见[验收记录](step-11-verification.md)。第十二步尚未执行，本步不发布、部署、Git提交、推送或重新打包release。

## 进入与选择

在已有预览地址后加 `?tour=prototype`。常规界面右上角增加「稳定阅读／沉浸浏览」；`debug=1`仍为显式工程检查入口。默认根地址继续展示此前参考作品集。

初始图形可用、系统未要求减少动态且十站真实内容都放得下时，使用沉浸浏览。容量不足、减少动态或图形不可用时使用稳定阅读。空间恢复、旋转回竖屏、减少动态关闭或图形恢复，都不自动让相机飞回柱子；访客主动选择沉浸浏览后再恢复运镜。

容量使用实际字体、正文、图片、按钮、控件与投影锚点测量，覆盖A1～A3、B1～B4、C1～C3的完整阅读状态，不靠UA或一个宽度断点决定。正文/关注区须符合原 `fits`，实际边界余量至少16CSSpx，有影像的媒体区域至少64px。测量在字体与视口稳定后进行，120ms合并再跨帧确认；不逐帧测量整篇文章。稳定版恢复沉浸也须通过容量判定。测量不触发图片加载；沉浸版继续在接近对应章节时加载作品，稳定版才为已展开内容加载图片。

## 两种布局

沉浸浏览保持16段、12.3H、十个阅读点、五入口、11.45～11.55H水潭稳定区及结尾回看。原生文档滚动仍是相机与正文的共同输入；环境暂停后仍可运镜，反滚复现。

稳定阅读把原有十个article自然展开为连续文档：开场 → 关于我三站 → AI影像四站 → 交互实验三站 → 水潭 → 结尾。没有复制另一套介绍、作品或ID。正文保持深青绿石面、浅金标题、浅白绿字与章节符号。作品切片按画幅重排，完整图像仍可打开查看；来源标签保留。

唯一场景画布放入开场庭院封面，使用原O姿态；现场体验临时复用它。稳定版正文滚动不连续移动相机。画面与动效控件位于封面旁，页面底部有独立完整结尾与回看入口；结尾至少一屏，也让水潭可以准确定位而不被浏览器夹到页底。稳定版长度随文字展开，不强制使用12.3H。

正文使用DOM，不进入像素后处理。正常正文手机至少16px、桌面沿用18px；重要文字使用rem响应文字放大。主要操作14px起、点击区域至少44×44px，操作组留出8px间距。大字、短横屏与长文在文档流中继续展开，保留浏览器缩放与双指缩放。

## 位置、字体与窗口变化

沉浸版记录未舍入的H、原生scrollY、段与局部进度；稳定版记录内容块ID、块内比例、文档位置和当时布局。没有在稳定版更换阅读块时，恢复原段/局部进度；读到另一站后返回该站既有完整阅读点。查看器保存原浏览方式及锚点，关闭时按当前有效布局恢复。

位置保护同时检查窗口、稳定视口探针、字体大小，以及原内容块的文档顶点和高度。浏览器可以先重排/派发滚动、后更新resize信息；这类滚动不覆盖旧阅读锚点。完成重排后再恢复位置和章节状态。字体放大时也保留正在看的内容，不以整页百分比代替阅读进度。

稳定视口探针和字体探针均受观察。窗口/字体事件合并处理，读取与写入不在ResizeObserver回调中递归执行。仅可见区域变化且布局未变时不反复scrollTo。顶部、左右与底部操作区计入CSS安全区。未修改viewport元信息，保留原页面缩放能力。

## 减少动态与可访问阅读

系统开启减少动态时默认稳定阅读、环境暂停，关闭光尘和连续运镜。播放环境与选择沉浸分别控制；关闭系统偏好不自动开播。原动画控制器增加仅原型启用的保留暂停选项，默认参考页的行为保持。

稳定版有连续标题、正文、图片替代文字与来源说明；「跳到阅读内容」会进入稳定阅读并定位第一段。非当前沉浸段继续inert；稳定版十站全部可读。切回沉浸会恢复章节标题的可访问状态。滚动不重建正文文本节点，也不逐帧播报进度；保留文本选择、原生键盘滚动和可见焦点。

## 查看器与失败处理

第二柱图片/媒体层与第三柱项目层适配短屏和大字。关闭按钮可到达；不足以同时容纳图像与说明时，查看层自然滚动。项目档案按实际布局使用原档案区或外层壳滚动，新打开从档案开头开始。

背景由原生dialog与文档滚动锁管理，移除现场体验对wheel/touchmove的统一拦截，保留内部平移、双指缩放与视频手势。现场体验只有原画布；暂停时滚动查看层会请求有限的必要取景重绘。

关闭、ESC、标签切换、失败或重试继续释放已离开的媒体。关闭返回原内容块与有效触发焦点，并保留最新主动正常/像素、环境播放/暂停选择。查看器内偏好/布局变化先保留查看器所有权，关闭后再应用稳定阅读。

图形初始化失败或上下文丢失时，三柱十站、水潭及结语均可阅读，章节导航、静态图片和项目档案可用。仅图形相关控件不可用，现场体验说明原因。图形恢复后仍停在稳定阅读，由访客显式恢复运镜。

## 绘制与资源

继续使用唯一场景、画布、渲染器与环境时钟，DPR上限2，像素设计分辨率默认384。没有新增几何、纹理、后处理pass、依赖或水体动画。

稳定封面离屏、档案/媒体覆盖或页面真实隐藏时暂停实际绘制；保留用户播放意图，返回不补跑隐藏时间。相同缓冲尺寸与DPR不重复分配，切模式仍更新显示与有限静帧；上下文恢复会使尺寸缓存重新失效。观察器、监听、计时器与有限RAF都有释放路径。

## 修改范围与内容边界

新增 `createReadingLayout.ts`、`readerFlow.ts` 与 `readingLayout.css`。原型入口、三个reader、项目查看器、展示状态及共享动画/渲染的必要生命周期衔接相应调整。原 `tour.css`、`film.css`、`experiment.css` 保持；响应样式单独覆盖。

路线与基础姿态、场景模型、三柱、水潭、水球、灯光、植物、魔法材质/粒子、原素材和依赖保持。张辰翰/sakan、枫叶互动AI动画、此前游族网络等事实保持；未补造影片、客户、职责、奖项或联系方式。AI画面继续标为网页设计样片，庭院12秒旧视频继续保留早期版本说明。

运行与证据记录仅覆盖工具实际支持的范围。GTK WebKit不等于iOS Safari；真实设备、系统浏览器栏/刘海、系统大字、实际读屏与物理触控板仍需另行复核。
