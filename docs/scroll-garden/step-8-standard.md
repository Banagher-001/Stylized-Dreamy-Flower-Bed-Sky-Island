## 1. 本步完成什么

目标画面是：**暖石池沿有厚度，浅蓝水面有深浅，深蓝反射有组织，白色水纹轻而清楚。** 全景里认得出水潭，靠近时能读出石沿、内壁、水面与中央台座的关系；水球周围有适合下一步发挥的安静背景。

主要手段为水潭局部的材质分区、程序化图案和必要的少量几何细化。沿用现有光照与像素管线，先做好正常画面的形体，再核对像素画面的概括与稳定性。

| 第8步实施 | 继续保留的边界 |
| --- | --- |
| 八边形池沿、内壁、基座的视觉层次 | 水潭中心、旋转、外轮廓与水位不变 |
| 浅深水色、深蓝反射形状、细碎高光与岸边泡沫 | 三柱、墙、石板、草花分布、主光/补光、全局色板不变 |
| 同源水面流动与实际落点波纹的视觉调校 | 现有水球/水柱几何、位置、形变、发射与水滴轨迹不变；第9步再改 |
| 中央石台的石色、接水和贴地关系 | 石台尺寸、顶高及出水接口保持 |
| 原型各镜头、现场体验、新封面/当前项目图的适配 | 三章文字、站位、滚动预算和项目层行为保持 |
| 三目标尺寸、暂停/恢复、资源与回归验收 | 整体导航/收束第10步；完整手机/横屏/200%文字第11步 |

只在 `?tour=prototype` 的场景中显式启用水潭新外观，并自然用于该场景的现场体验。默认参考作品集沿用旧外观；公共场景/材质工厂不能因默认参数或共享对象被修改而改变参考稿。

## 2. 8.1：保存第七步基线并完成水潭诊断

当前已经具备：8段实体池沿、连续内壁、程序化蓝白水色、真实阴影、水滴落点事件、岸边泡沫、32槽水滴和8槽落点波纹。水滴/水团由同一环境时间更新，三柱与项目层已具备暂停恢复机制。因此本步是局部美术完善，不重新搭建水系统。

从已有W画面可见：深蓝反射较分散且偏圆团，水面主色较平；池沿有实体厚度，但内壁、水线与石台接水关系可以更清楚。执行时用新基线复核这些判断，不能把旧静帧当作当前运行的全部状态。

**通过条件：**基线可以复查，问题落实到池沿、内壁、水面、台座四个区域；分清现有能力、本步修改和第9步水球范围。

## 4. 8.3：池沿从一圈浅石变成可读的石构件

按照「压顶受光面 → 窄倒角/接缝 → 侧壁背光面 → 基座接地」组织层次：

- 压顶保留暖象牙石色；大平面安静，少量面色差帮助分块，不增加遍布全池的碎斑。
- 8段接缝保持连续、细窄；连续池壁封住水域，缝隙不会直接透出草地。
- 冷青灰侧面与浅色顶面形成厚度，局部倒角只负责转折，不形成整圈刺眼亮线。
- 两处现有缺口继续作为不对称风化特征；少量灰绿旧痕集中在接缝/缺口附近，保留主要受光石面。
- 基座靠地处用低饱和青灰绿加强接触，不扩大原建筑投影，不新增草花或藤蔓批次。

当前石材工厂由多种建筑共享。新石色/水线效果必须给水潭对应网格独立绑定或显式选择专用分支，不能原地修改共享材质、共享顶点颜色或全局stoneConfig影响三柱、墙、石板。

**通过条件：**全景能读出池沿厚度，W近景看得出压顶与内壁；风化细节服从大形，其他建筑不变色、不改变轮廓。

## 5. 8.4：内壁、水位与中央石台建立接水关系

保留0.26的露出内壁，让水面嵌在池中。内壁靠水处加入窄而不规则的冷色湿痕，上方更接近干燥石色；以水位与池体局部坐标确定位置，镜头移动时不滑动。

水面边缘使用克制的深浅变化说明靠岸和深浅关系。水仍可采用不透明的风格化着色，不要求透过水面看见实际池底；不能只增加透明度导致草地、池底和石台排序错乱。

中央石台只调石色与接水层次：台顶偏暖，侧面偏冷，水线附近略深。0.9底脚、0.64台身、0.82台帽尺寸和顶高0.96保留，出水口与水柱连接不动。水球投影背景保持相对干净。

**通过条件：**水位明确，石台看起来从水中立起；近景没有浮在水上的整张贴片、贯穿石台的高光或水线抖动；水滴仍有原来的几何避让空间。

## 6. 8.5：重整水色与深蓝反射图案

沿用现有水色作为锚点：浅蓝灰#BED4DF、冷蓝阴影#7FA3BF、深蓝#245B80、冷白#F2FAFC。改动集中在水潭专属参数和混色比例，正常/像素输出继续使用同一颜色空间。

| 层次 | 视觉目标 | 调校与判定 |
| --- | --- | --- |
| 基础水色 | 保持大块安静的浅蓝灰，有浅中深层次 | 使用少量清楚的色阶与局部深浅，避免满面细噪 |
| 主要深蓝反射 | 形成有方向的1～3组主要形状 | 以左侧/远岸为重心，拉长、打断圆团；其余小块服从主形 |
| 反射边缘 | 有细碎、略阶梯化的轮廓 | 由稳定局部坐标产生；保留大轮廓，小尺度细节随距离减弱 |
| 亮部 | 少量断续冷白短线与碎点 | 有聚散与留白，中心石台和未来水球周围保持可识别背景 |
| 实际建筑阴影 | 继续压低水色与亮部 | 新图案接受现有遮挡/阴影，不用高光把阴影区域重新点亮 |

固定W/O样本先以深蓝占有效可见水域约12%～28%作为构图调校起点，计算时排除石台及真实遮挡。它是辅助指标，最终以主形、留白和三尺寸可读性共同判定；如调整范围，记录样本与理由，不把单个比例当作视觉完成证明。

此处是艺术化反射图案，不宣称实时镜面反射。优先复用当前局部坐标与程序化噪声；不增加实时反射相机或抓屏纹理。实际阴影、深度测试和不透明水面继续正确工作。

**通过条件：**暂停后也能看出清楚的蓝白构成；正常画面形状有组织，像素画面没有变成互不相干的圆斑、黑洞或密集杂点；三柱阅读时可见的水潭背景不过度抢眼。

## 7. 8.6：水面流动、泡沫与落点波纹保持同一节奏

水面按现有单一环境时间缓慢流动。调校起点：主图案flowSpeed约0.025～0.045（当前0.055）、背景短弧waveSpeed约0.30～0.45（当前0.45）；最终值需结合实际8～12秒片段记录。8秒内能观察到变化，主要反射不频繁整块翻换。

岸边泡沫呈断续窄边，可从世界宽度0.015～0.04开始，优先让W镜头读出细边，全景减弱高频细节。可见白边先控制在可见岸线约四分之一以内，避免把整圈水域描成同亮白框。

保留已有32槽水滴、8槽落点事件、0.65秒波纹生命周期和0.30扩散速度。只调水面上波纹的视觉宽度、分段、衰减与强度；强度可从现有0.58的约60%～80%开始评估。落点来自真实水滴解析轨迹，不生成与落水无关的随机冲击。

短弧优先保持不完整的细碎形态；少量高光有渐强渐弱，避免整片同步闪白。图案固定在水潭局部空间，可通过像素覆盖/导数进行细节淡出，镜头远近与正常/像素切换时保持尺度关系。噪声种子稳定，不按帧重掷随机数。

本步不改水球/水柱的形状、基础半径0.18、脉动0.025、发射高度1.18、运动公式或发射相位。新增水潭外观可以单独关闭回到第七步，供精确对照。

**通过条件：**连续播放8～12秒有缓慢流动和真实落点回应；暂停时完全固定，倒滚不要求水波倒放；相同环境时间能复现，主反射不随相机游走，亮点没有明显整面闪烁。

## 9. 8.8：暂停、隐藏、减少动态与恢复合同

| 场景 | 必须保持的行为 |
| --- | --- |
| 停止滚动、环境仍播放 | 镜头停稳，水面按环境时间继续轻动 |
| 手动暂停环境 | 水面、现有水滴/水球/草花一同定格，滚轮与章节导航继续可用 |
| 打开只读影像或项目档案 | 叙事位置保留，背景时钟与绘制暂停；媒体按原规则工作 |
| 现场体验 | 新水潭随最新明确播放选择运行，背后叙事冻结 |
| 关闭查看层/项目层 | 停止已关闭媒体，恢复站点/比例和相应设置，不重置水相位 |
| 真正切到后台 | 不推进时间、不持续绘制；返回无大幅时间跳跃，视频保持暂停 |
| 减少动态 | 沿用默认静止、直接定位和光尘抑制；明确播放操作仍可用，不增加额外水面装饰运动 |
| 改变窗口/模式 | 保留站点/比例、用户选择与环境时间；细节按投影尺度适配 |
| 上下文丢失/恢复 | 保留位置、项目页签和关闭入口；恢复水材质/资源，不跳回开场或新增场景 |
| 美化不能启用 | 能独立退回原水潭外观；无WebGL时保留现有DOM/项目档案/参考入口退路 |

所有新效果使用已有环境时间与on-demand绘制机制。暂停后不能因新shader动画、额外RAF、setInterval或独立粒子时钟持续绘制。

**通过条件：**每项有真实操作证据；标签隐藏用真正的页面可见性变化验证，不能用伪造document.hidden事件代替。故障记录和正常结果分开。

## 10. 8.9：实现隔离与资源/性能预算

通过可选外观参数或独立水潭模块，仅给滚动原型启用新外观，默认工厂行为保持旧版。surface与jet两个水材质分支明确隔离；球/水柱/水滴共享的jet分支不因水面调色被连带修改。shader缓存键区分新旧/表面类型，不能复用错误的已编译程序。

新配置集中维护，几何与材质各有明确所有者。仅为水潭绑定必要副本；替换/销毁时恢复或释放，不dispose其他建筑仍在使用的共享几何/材质。普通模式和像素模式复用同一场景，不新增renderer、canvas、环境贴图、反射渲染目标或应用依赖。

| 项 | 预算 |
| --- | --- |
| 新增GPU几何 | 优先0，最多2；优先修改/复用现有池体与程序化分区 |
| 新增GPU纹理/额外渲染目标 | 0 / 0；DOM新封面另计，不假装没有媒体内存成本 |
| 新增活动模式程序/两模式程序缓存 | 最多2 / 4；相对同历史的新鲜第七步基线计算 |
| 同镜头新增draw calls | 最多2；不加反射、折射或额外全屏后处理pass |
| 水滴/落点事件容量 | 保持32 / 8；不叠加新的水面粒子系统 |
| 三柱光尘 | 原槽位72桌面/36手机；仅一柱活跃，稳定8/4、减少动态0 |

第七步完整预热58几何/6纹理/10程序、两模式缓存18仅为历史参考；执行时重新测量，不能照抄这些数字作本步结果。资源测试需访问全路径并按相同pixel/native/pixel历史预热。

执行前后在同视口、固定时间、同水潭路线各保留30次真实wheel停止样本，采样期间不并行浏览器/录制、不截图。p95上升超过约10%先排查shader、布局和重复绘制，必要时用隔离的前一步源码交替复测，保留首测、全部原始样本与峰值，不能删样本或只选最好一轮。水面持续播放的帧时间另记为云环境诊断，不把滚轮停稳值当作硬件FPS。

做至少10轮「三柱阅读→水潭→现场体验→档案→返回」，预热后DOM/GPU/媒体常驻数量不增长。暂停/后台停止非必要绘制，上下文恢复后资源缓存重新稳定。

**通过条件：**增量预算、循环稳定性与性能调查有本步证据；新外观默认隔离正确，三柱/地面/植物/灯光/旧jet参数、实例和依赖受摘要保护。
