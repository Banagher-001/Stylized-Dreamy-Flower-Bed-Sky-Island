# 第 3 步实现与使用

第一柱已接入上、中、下三个阅读站。当前是阅读机制原型：基础显隐和文字承托已实现，正式魔法文字、深色石材和完整个人介绍编排仍在后续步骤。

## 进入与操作

在当前网页地址后加 `?tour=prototype`，已有参数时用 `&tour=prototype`。默认参考作品集继续保留。

- 滚轮、触控板、键盘或触摸控制浏览。第一柱上部阅读后继续向下，旧段退出，镜头下降，下一段再出现；向上滚动反向恢复。
- “01 关于我”仍定位 1.74H，即 A1 的完整阅读区。“镜头数据”内提供 A1／A2／A3 调试定位，分别为 1.74／2.54／3.34H。
- 暂停只控制环境时间，滚动阅读仍然可用。停止滚动后不自动换段，也不强制将半透明正文补播完。
- `?tour=prototype&waterTime=2` 固定环境时间，方便对照相机和文字；正常／像素模式切换保留阅读进度。
- “返回参考稿”离开原型入口。本步没有将原型发布成默认首页或公网网站。

## 路线和站点

总预算仍为 12.3H，保留第一步 16 段。第一柱为 1.3～3.7H，第二、第三柱继续保持首站。下表为画幅偏移前的基础相机参数；取景高度 3.6、锚点横向 34%。

| 站点 | 相机位置 | 注视点 | 完整阅读区 H |
| --- | --- | --- | --- |
| A1 | `[-1.14,6.95,6.1]` | `[-2.34,2.75,-2.9]` | 1.54～1.94 |
| A2 | `[-1.14,6.00,6.1]` | `[-2.34,1.80,-2.9]` | 2.34～2.74 |
| A3 | `[-1.14,5.05,6.1]` | `[-2.34,0.85,-2.9]` | 3.14～3.54 |

两次下降窗口为 1.94～2.22H、2.74～3.02H。摄像机与注视点一起下降，保持相对向量 `[1.2,4.2,9]`，首尾速度归零。读完 A3 后，T12 直接从柱底姿态出发，经过重新校准的控制点前往原 B1，正反方向都无须跳回柱顶。

每段前 15% 隐藏，15～30% 显现，30～80% 稳定阅读，80～100% 退出。正文、编号与相机来自统一显示进度；站点编号变化时正文已隐藏，调试焦点沿连续关注点移动。

## 文字与布局

正文使用已经确认的姓名、公司和能力信息，未加入日期、职位、项目成绩或联系方式。文字为语义化 DOM，与场景像素采样分开；通过柱身锚点投影定位，并以临时深色承托提供稳定对比度。连接线与编号是校准标记，尚未实现符印、粒子或发光字体。

桌面正文 18px，窄屏 16px。桌面在柱旁展开，1000px 以下改为焦点下方阅读，正文与导航各留空间。三个段落共用稳定的最大排版高度，切换不会使阅读框因文字长短上下跳动。非当前段落通过可见性、`aria-hidden` 与 `inert` 隐藏；滚动不抢夺焦点。

阅读面板观察视口、舞台、标题和自身尺寸变化，并重新投影。布局中的 `fits` 同时检查可用区域和柱面焦点是否保留，用于原型容量评审；不通过缩小正文或截断文字强行容纳。

200 字长度样本只由测试临时注入，已标注“长度测试，不作为个人介绍”，不在应用内容中。它在 1440×900 下可容纳，390×844 下会占用柱面焦点，因此不通过该窄屏构图约束。当前三段真实短文均可完整阅读。更长正文需在后续内容阶段拆站并同步调整预算，不能将这次三站原型当作任意长度内容已适配。模拟横竖切换能保留进度；狭矮横屏的完整阅读构图仍待第 11 步。

## 文件结构

| 文件 | 用途 |
| --- | --- |
| [reading.ts](../../src/tour/reading.ts) | 三站文字、范围、显隐与下降高度的确定性采样 |
| [route.ts](../../src/tour/route.ts) | 第一柱相机与 A3→T12；其他关键姿态保留 |
| [createPillarReader.ts](../../src/tour/createPillarReader.ts) | 清晰正文、投影、尺寸观察与隐藏语义 |
