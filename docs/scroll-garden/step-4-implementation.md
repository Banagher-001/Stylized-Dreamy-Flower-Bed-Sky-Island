# 第 4 步实现与使用

第一柱已接入深色石身、三处贴面符印、分层魔法显隐和柔边阅读承托。它是第一柱的视觉样板，沿用现有三段验证文字；正式关于我编排、其他两柱内容、水潭与水球仍按后续阶段实施。

## 进入与操作

在当前网页地址后加 `?tour=prototype`，已有参数时用 `&tour=prototype`。默认参考作品集保留。

- 滚动进入第一柱，符印点亮，标题先出现，正文随后凝聚；继续滚动时正文先退出，镜头沿柱下降，下一处符印接替。
- “01 关于我”定位 A1 完整阅读区；“镜头数据”内 A1/A2/A3 仍可分别定位三站，并显示实际文字、光尘和资源状态。
- 停滚保持当前凝聚/消散状态，不自动补播。倒滚反向恢复，章节与镜头预算仍为 16 段、12.3H。
- 暂停环境冻结光尘、水体和草花，滚动阅读继续可用。减少动态时光尘不显示，符印保持稳定；完整手机静态章节视图仍待第 11 步。
- `?tour=prototype&waterTime=2` 固定共享环境时间，便于对照；正常/像素模式切换保留站点。
- “返回参考稿”离开原型。本步没有把原型发布成默认首页或公网网站。

## 深色石材

原型显式给第一柱石身的 4 个石块和 3 条接缝分配独立石材实例，复用原有明暗、倒角、缺口和细微色差。柱顶、底座、其他两柱、水潭、地砖、灯光和全局色板保持。

| 参数 | 当前值 |
| --- | --- |
| 石身受光/背光 | `#405B55` / `#263E3A` |
| 石块上缘 | `#A4B398` |
| 接缝背光 | `#1B302D` |
| 标题 / 正文 | `#FFF1CD` / `#EDF4E6` |
| 符印细光 | `#C4DFDB`、`#DCCB9D` |
| 少量光点点缀 | `#CDBFE4` |
| 字行承托 | `#223B33`，局部柔边遮罩 |

石材输入经现有光照计算；表中颜色不是最终每个屏幕像素的固定值。石材工厂新增可选颜色参数，默认调用仍沿用原色，不改共享材质或补光参数。

## 贴面与文字

符印为断环、短刻度、竖向铭线与 01 编号。三处分别依附 `columnUpperLeft-block-3`、`block-2`、`block-1`，整个方形图形在石块正面保留至少 0.05 世界单位的边界余量，离面偏移 0.008。局部锚点校准后固定；改变画幅仅重新投影。

柱面图形保留深度测试、不写深度、不投新阴影。当前站点的暗纹随滚动被唤醒，只绘制当前符印，减少重复绘制；单独中文阅读层保持清晰，未放进低分辨率场景采样。第一柱原调试圆圈/白底标签已由符印替换，其他两柱仍保留首站原型标记。

正文仍为桌面 18px、手机 16px；标题 27px/22px。标题有小范围近光，正文无模糊。雾影使用局部静态 SVG 遮罩，字行内保留稳定深色核心，外沿柔化。细光引线终止在承托外侧，避免和羽化边缘交叠；其坐标按 CSS 像素稳定取整。

## 滚动显示状态

| 段内进度 | 状态 |
| --- | --- |
| 0～15% | 符印逐渐点亮，正文隐藏 |
| 15～22% | 标题凝聚 |
| 20～30% | 正文凝聚；30% 前完成 |
| 30～80% | 字体、亮度、承托与相机稳定；仅光尘随共享时间轻移 |
| 80～96% | 正文先消隐，光点向下引导 |
| 96～100% | 标题与符印继续淡出，段末停止绘制 |

三个完整阅读区和两次下降窗口与第三步一致。标题、正文、符印和光尘分别采样；实际透明度记录在原型数据中。正文实际不可见时，从可访问内容中隐藏；其他站点使用 `aria-hidden`/`inert`，滚动不抢焦点。

## 资源与恢复

符印和光尘共享着色代码及兼容的顶点属性，按原有颜色管线输出。资源为一个符印图集、一个共享面片和一个共享点池几何；未新增应用依赖、全屏 Bloom 或灯光。

桌面启动时预分配 24 个光点槽位，手机启动时 12 个。稳定阅读显示 8/4 个；桌面窗口缩小后只启用 12 个槽位，复用已有缓存。初始位置有固定种子，更新使用已有环境时间与帧循环，不逐帧分配新对象或另起计时器。阅读区内不变的文字样式使用缓存，保留实际进度与分层状态更新。

图形恢复路径补齐 Points 和着色器图集纹理的旧 GPU 资源释放，保留 CPU 图形数据以供恢复。装饰不能创建时，深色石身与正文仍可用，并有可访问提示和参考稿入口；无 WebGL 时使用原有可读错误提示。
