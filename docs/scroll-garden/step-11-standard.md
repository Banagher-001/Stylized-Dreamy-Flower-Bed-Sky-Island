## 1. 本步目标与范围

让同一座庭院在手机上保持设计感：空间足够时，手指滑动仍直接控制运镜，镜头靠近三柱、沿柱下降，浅色魔法文字依次出现；空间不足、文字放大或访客希望减少动态时，提供完整、稳定、自然滚动的章节阅读。

优先级是：**内容完整可读 → 输入与返回可靠 → 保留庭院视觉 → 在合适空间保留连续运镜。** 不靠缩小文字、截断段落、强迫横屏或关闭页面缩放解决容量问题。

| 本步负责 | 保护边界与后续事项 |
| --- | --- |
| 手机竖屏、短横屏、平板与窗口变化；安全区和浏览器栏变化 | 三柱位置、场景几何、灯光、植物、石材、水潭及水球美术保持 |
| 沉浸浏览与稳定阅读、200%文字、减少动态、键盘与语义阅读 | 十个阅读站、真实介绍、作品来源标识及未提供素材的状态保持 |
| 触摸、章节导航、媒体层与现场体验在小屏的布局和返回 | 桌面16段/12.3H、原相机路径与站点、唯一场景/画布/环境时钟保持 |
| 本步同条件性能、资源与跨引擎回归，明确实机证据范围 | 最终发布选择、真实作品接入、最终交付归档属于后续授权范围 |

默认参考作品集继续保留；滚动庭院仍通过 `?tour=prototype` 进入，调试仍须 `debug=1`。若确需修改共用viewport元信息，必须回归默认参考页面；不得改变入口或把本步当作整站上线。

## 2. 11.1：冻结第十步，列出真实适配缺口

实施前保存独立可运行的第十步源码与构建摘要，记录当前十站、开场、水潭、结尾、两类查看层、正常/像素模式的截图、实际画布尺寸和输入状态。所有新证据写入 `docs/evidence/scroll-garden-step-11/`，不覆盖历史记录。

已确认的起点：阅读面板主要为fixed布局；窄屏切为上下排布，以100svh探针建立滚动预算；窗口变化保存当前显示H。390×844已有基础可用证据，但短横屏、200%文字和完整稳定章节阅读尚未验收。当前减少动态会暂停默认环境并取消相机缓动，滚动仍改变相机；这还不是本步承诺的稳定阅读。

现有图形失败退路主要保留第三柱案例，第一、第二柱的完整替代阅读需要补齐。既有实验项目档案与第二柱媒体查看器都有自己的返回合同，本步必须一并保留。

保护数据：桌面16段/12.3H；A1/A2/A3为1.74、2.54、3.34H，B1～B4为4.95、5.95、6.84、7.64H，C1～C3为9.14、10.05、10.83H；全景0H、水潭11.5H、W稳定区11.45～11.55H、结尾11.8～12.3H。它们是叙事位置，不是秒数或手势次数。

第十步58份几何、6份纹理、单模式12程序/双模式22缓存，以及软件环境受控p95为历史参考。实施时必须重新测量，记录引擎、版本、画布、DPR、模式、动效状态和采样条件，不直接复制旧数字。

**通过条件：**基线可独立打开；保护文件、阅读点和缺口清单明确；桌面、手机、横屏、文字放大分别留有实施前记录。

## 3. 11.2：建立两种浏览方式和明确的切换规则

| 方式 | 页面与相机行为 | 适用情况 |
| --- | --- | --- |
| 沉浸浏览 | 保留同一条原生文档滚动→H→相机/正文的路径；停滚定格，反滚复现 | 正文、当前柱面关注区和必要控件都能完整容纳 |
| 稳定阅读 | 同一批正文按开场、A1～A3、B1～B4、C1～C3、水潭、结尾自然排入文档；滚动正文不连续推动相机 | 放大文字、短横屏、容量不足、减少动态或访客主动选择 |

稳定阅读不另造一套介绍或作品数据，不重复挂载十份可访问副本、不重复ID。原阅读节点优先保留；重排后仍是同一套内容、按钮、来源说明与项目层。稳定版文档长度随真实内容变化，不强塞进12.3H；12.3H仍是沉浸版的路线合同。

稳定版保留一处同场景的庭院封面，使用原O姿态；正文以深色石面、浅金标题、浅白绿文字、柱号/符印和章节细线组织，不变成无差别作品卡片。单一画布在封面或现场体验中复用，正文滚动不触发相机飞行。封面离屏时暂停实际绘制，保留用户环境播放选择；返回可见区域按既有时钟规则恢复。减少动态默认静止。

初次进入的选择优先级：

1. 图形不可用：完整稳定阅读；现场体验提供明确不可用说明，档案与其他正文仍能读。
2. 系统减少动态：默认稳定阅读、环境暂停。
3. 按当前真实内容测得沉浸布局不足：稳定阅读。
4. 以上均不触发：默认沉浸浏览；始终提供可发现的「稳定阅读」入口。

手动选择在当前会话与查看层开关中保留。系统偏好新开启减少动态时立即退出连续运镜；关闭偏好、图形恢复、浏览器栏收起或手机转回竖屏，不自动把访客送回沉浸模式。空间足够时显示「沉浸浏览」入口，由访客选择；不足时给简短可理解的原因，不让按钮带人进入已知不可读状态。

**容量判定：**在字体与实际内容完成布局后，测量十站完整亮度时的正文、作品、动作区、必需全局UI和柱面关注区；不以当前透明度为0、空内容、UA或单一宽度断点代替测量。触发源包括字体/文字尺寸变化、稳定窗口变化及控件换行；不逐帧检查每个字或重新构建DOM。ResizeObserver先合并测量、后写布局，防止读写循环。

短暂视口抖动不反复换模式：布局不足应由连续稳定测量确认；实施记录稳定判据。自动转入稳定阅读后不自动转回；再次允许进入沉浸时，各受约束边界须有至少16CSSpx的剩余空间。系统减少动态与真实图形失败不等待容量防抖。

**通过条件：**两种方式入口清楚；所有自动与手动切换均能解释原因；十次临界尺寸往返不反复闪切，不丢内容，不增加场景或播放时钟。

## 4. 11.3：校准竖屏构图与魔法文字

手机沉浸版仍要让人看出「正在读哪根柱、柱上哪一段」。先压缩纯装饰间距、整理全局工具，再调整正文与柱面关注区的排布。开场品牌和结尾回看靠边安排，中央水球/池沿保留主体空间。章节变化时的字与符印仍由同一显示H求值，停滚不继续补播正文。

窄屏可以调整UI安全区和正交投影的取景偏移/宽高约束，必须是当前H、真实画布宽高和布局参数的确定函数；不得改世界布局、桌面相机位置/注视点/路线，或靠累积手势偏移镜头。先保留原取景；确有必要的手机取景差异逐项记录，正反滚一致，并检查原实体安全余量。无法兼顾完整正文和关注区时，使用稳定阅读。

- 正文正常大小至少16CSSpx，行高1.6～1.8；桌面沿用现有18px层级。重要图注、错误与来源说明同样能读，不降为装饰小字。
- 主要操作标签首轮至少14px；章节标签12～14px，编号等非必要装饰可更小，但不承担唯一操作说明。
- 实际字符与承托背景对比度至少4.5:1；魔法光晕不作为对比度依据。正文保持稳定亮度，不随水球呼吸闪烁。
- 正文使用清晰DOM文字，不进入像素后处理。像素感继续来自原场景管线；浅金/浅白绿字与深青绿石面关系保留。
- 长标题、混合中英文与按钮允许换行；图片保持比例与完整内容，不拉伸，不用裁切去掉作品来源或必要信息。

**通过条件：**目标竖屏逐一核对十站、开场、水潭与结尾；每站正文完整，当前柱的关注区不被字/按钮盖住；放不下的画幅明确进入稳定阅读，不通过缩字号把 `fits=false` 改写为通过。

## 5. 11.4：短横屏、200%文字与长内容

320px宽屏、667×375与844×390短横屏、系统大字和200%文字放大优先完整阅读；必要时使用稳定版，不强制旋转手机。稳定版正文在正常文档流中展开，十站全部可顺序到达；作品入口与结语不因段落变高而移出可访问范围。

保留浏览器缩放与双指缩放：viewport不增加 `maximum-scale=1`、`user-scalable=no` 等限制。分别验证仅文字放大200%和页面缩放200%；CSS放大模拟只作为布局证据，不能冒充浏览器原生文字放大或真机系统大字。

不得使用正文line-clamp、省略核心事实、固定高度裁切、transform缩小全文、整页overflow隐藏或新增正文内滚动小窗。普通正文只由页面滚动承载；作品档案和原生媒体控制区可以保留其有明确边界的独立滚动/拖动。

另用明确标记的200字中文临时样本验证容量退路：只在测试时注入，不提交为个人介绍，不改真实文案缩短来凑通过。真实介绍、公司、工作方向、样片标记和项目说明全部保留。

**通过条件：**大字与长文能从首字读到末字、访问全部动作，无页面非预期横向滚动；不因场景仍可见就把正文溢出记为通过。

## 6. 11.5：处理安全区、浏览器栏与窗口变化

顶部、底部与左右的交互边界计入 `env(safe-area-inset-*)` 和真实控件尺寸。仅在确有需要时增加 `viewport-fit=cover`，并一并完成默认参考稿回归。正常尺寸下操作区至少距内容视口边缘16CSSpx，额外叠加适用安全区。

实施校准：保留原沉浸手机顶内边距14px并计入安全区，侧边16px；稳定版顶部取16px与安全区较大者。该处按实际版式校准，区别于初拟全向16px；操作完整落在安全区、44px目标与正文可达的验收保持，见验收记录。

区分「稳定的路线高度」与「当前可见的操作边界」：继续以稳定视口基准维护沉浸路线；可见视口变化只校准控件与遮挡，不在地址栏每一帧伸缩时重写12.3H或scrollTo。可按能力使用svh/dvh与VisualViewport；无该API时有innerHeight等退路，不用UA识别设备。

字体加载、工具换行、横竖切换或真实布局变化时，先保存语义位置，再更新布局；一次批量修正，不递归触发scroll/resize。仅调整可见边界不能重置相机、当前段、环境时间、播放选择或作品层。没有表单也不新增键盘弹出流程。

**通过条件：**顶/底/横向安全区中无必要操作；模拟视口变化和实际可获得的浏览器栏变化后，关闭按钮与正文仍可见；不出现页面来回拉扯、重复scrollTo或连续ResizeObserver循环。

## 7. 11.6：保留位置、选择与输入习惯

沉浸版保存「段ID＋段内比例」，以及未舍入的显示H、真实scrollY和当时布局信息；稳定版保存「阅读站/内容块ID＋块内位置」。不以七位小数的dataset H反推原像素位置，也不把稳定版整页滚动百分比硬换算为12.3H。

| 切换情形 | 位置恢复规则 |
| --- | --- |
| 沉浸→稳定 | 当前阅读站对齐当前文字块；开场/结尾对应原区域；T01/T12/T23分别落向A1/B1/C1，T3W对应水潭 |
| 稳定→沉浸，未改变阅读锚点 | 恢复之前保存的原段与局部进度，不统一回到章节首站 |
| 稳定版已读到另一段或主动导航 | 对应A/B/C站回到其既有完整阅读点；水潭11.5、开场0、结尾原完整状态 |
| 沉浸内横竖切换 | 保留原段/局部进度，按新布局换算文档位置 |
| 查看器打开期间布局/偏好变化 | 先保持查看器所有权；关闭后用最新有效布局恢复原语义锚点，不抢回后台滚动 |

稳定版的手动章节入口和回看入口保持与沉浸版相同含义；水潭入口到水潭章节，结尾回到开场和回看影像仍可用。章节激活状态由当前可见内容推导，进度在实际结尾才到100%。

触摸竖向滑动使用浏览器原生滚动/惯性；双指缩放、文本长按选择/复制、媒体拖动保留。不得用touchmove/wheel全局preventDefault、原始delta计数、滚动吸附、定时播放或待补镜头队列驱动剧情。正文滚动不重建文本节点；选择范围不随进度刷新消失。模式重排优先保留节点和选择端点，必要时按有效文本端点恢复，避免隐藏被选择内容。

点击/触摸目标至少44×44CSSpx；相邻主要目标首轮间距≥8px。窄屏控件可换行或归入可发现的控制区，但当前章、阅读方式和返回路径保持清楚。Tab/Shift+Tab顺序符合视觉顺序；Home/End/PageUp/PageDown使用原生行为；不捕获全局字母键或方向键。只有明确的标签组和弹窗使用其局部按键语义。

**通过条件：**正反滑动、快速滑动、导航、十次模式/方向往返无章节重置；同布局恢复原scrollY误差≤1CSSpx，跨布局保留语义站与可恢复局部进度。文本选择不被日常滚动更新清空；焦点不落到隐藏/inert节点，返回不无故跳到页首。

## 8. 11.7：真正实现减少动态与完整语义阅读

通过系统媒体查询响应 `prefers-reduced-motion: reduce`，不是用调试按钮伪造系统偏好。默认进入稳定阅读，环境暂停，正文直接稳定显示，关闭光尘漂移、散射、自动柔滑滚动与连续滚动运镜。水潭、水球仍保留冻结时的有效画面，不换素材或另建静态模型。

「播放动效」只明确恢复环境动画，不暗中恢复滚动运镜。用户只有在容量允许且明确选择「沉浸浏览」后才重新开启连续运镜；该选择与环境播放选择分开。系统偏好关闭后不自动开播、不突然飞向柱子。运行中偏好变化也保留阅读锚点；弹窗内变化按上一节的所有权规则处理。

稳定版提供连续且唯一的标题/正文结构及「跳到内容」入口；三章和十站的层级、作品图像替代文字、来源说明、按钮名称完整。沉浸版非当前内容不进入焦点序列，可通过清晰入口使用完整稳定阅读；纯装饰符印与画布说明不重复播报长文。

导航当前项、阅读模式、环境开关与项目标签有准确状态。滚动中不逐帧aria-live播报百分比；只对主动切换、图形/媒体失败与恢复提供简短状态。焦点轮廓清楚、不会被固定控件压住；未选择字体或特定色彩模式也能识别必要控件。

**通过条件：**初始减少动态、运行中开启/关闭、手动播放环境、手动进入沉浸分别测试；稳定版滚动时相机姿态不连续变化。键盘完成全部入口和返回；DOM/可访问树只有一套核心正文，隐藏按钮不会被Tab访问。自动语义检查与真实读屏试验分列，不能互相冒充。

## 9. 11.8：适配作品查看、现场体验与图形失败

第二柱媒体查看器与第三柱「现场体验/项目档案」分别覆盖竖屏、短横屏、大字和安全区。关闭/返回操作至少44×44、始终可到达；标题、标签与必要控件允许换行，不把档案内容挤成无法滚动的小洞。档案正常纵向滚动，视频保留原生控制，不拦截其手势。

现场体验继续复用唯一画布、渲染器与环境时钟。按实际留给画布的宽高取景；空间不足时显示简洁可操作的布局，允许转到档案，不让控件盖住全部场景。不开启第二个WebGL画布，不以自动播放视频代替交互体验。

打开查看层前保存所在方式、阅读锚点、焦点和布局；打开期间后台叙事不随手势漂移。关闭/ESC、标签切换、视频失败/重试、可见性变化、方向变化与异常清理均覆盖。关闭已离开的媒体须pause、移除src并释放解码；恢复原阅读位置和有效触发焦点，并保留最新主动正常/像素、播放/暂停选择。

图形初始化失败、上下文丢失或恢复较慢时，完整A/B/C与水潭/结语都能稳定阅读，已有静态图片/档案按实际可用情况访问；不能只剩第三柱或无期限转圈。图形失败不阻断文字导航，失效的现场体验入口有解释；恢复后不强行切模式、跳位置或恢复用户已暂停的动效。媒体失败有明确状态与重试，源版本标签继续保留。

**通过条件：**两类查看器在三类困难布局均可打开、阅读、关闭和返回；至少十次媒体/项目开关无重复视频、后台音频、焦点丢失、滚动锁残留或资源持续增长。真实系统隐藏与实际可触发的图形失败/恢复保留证据。

## 10. 11.9：控制手机渲染与布局开销

沿用渲染器DPR上限2，像素设计分辨率默认384、显式对照档320/448；文字保持DOM清晰。DPR3设备按上限分配实际缓冲，不能因为画布CSS变窄而仍分配桌面尺寸；尺寸重复未变时避免反复resize或重建目标。正常/像素选择保留，不暗中把正常模式改成像素模式。

本步不新增图形几何、纹理、后处理pass或第二套渲染循环；水球半径/悬浮/形变、32飞滴与8落水容量、池体与材质均保持。布局只在实际变化时测量与写入，不在每帧重排所有文章，不靠降低场景细节或删光效伪造手机性能通过。

关闭查看层、切换模式、窗口变化后允许有限的必要重绘；环境暂停且滚动/布局稳定后无持续GL绘制，真实页面隐藏后停止。稳定版封面离屏或档案覆盖时不持续渲染不可见场景；返回不补跑隐藏期间的动画。新增监听器、观察器、定时器与有限RAF均有释放路径，不产生第二个剧情/环境时钟。

性能要分别测「相同沉浸路径的前后比较」与「稳定阅读的布局/输入开销」，不拿两种不同轨迹的帧耗时证明优化。前后至少沿用五条路线、每条六次原生输入的30次同条件采样，正常/像素预热顺序一致；测量时不并行录屏、截图或运行另一浏览器。记录全部样本与p95/max；同条件p95恶化超过10%需查因修正或明确列为未通过，不挑最好一轮。仅因新增改动或异常原因进行必要复测，并记录原因。

**通过条件：**预热后GPU计数和DOM/媒体实例在十次循环后无持续增长；DPR与画布尺寸符合策略，新增图形资源数为0；暂停稳态至少250～400ms观测窗内零GL绘制。软件渲染结果只作受控诊断，不写成手机实测FPS或60fps承诺。

桌面纯场景前后对照覆盖O、十站、W、结尾和五段移动区的代表姿态，双模式/两尺寸；相同画布、精确相机与同一环境时间要求逐像素一致，不用全屏遮罩或放宽通道阈值掩盖差异。手机若新增投影适配，则单列明确的取景差异和几何/正文安全区证据；底层场景同条件对照仍应保持。默认参考稿双模式无回退。

**通过条件：**每条矩阵明确引擎、视口、DPR、方式、系统偏好、输入类型、实际结果与证据；实测/模拟/未测分类准确。完成现有必要回归、严格类型检查与生产构建，不弱化原内容、返回或暂停测试来凑通过。
