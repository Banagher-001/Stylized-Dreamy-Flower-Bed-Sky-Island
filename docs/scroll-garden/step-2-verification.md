| P04 空间安全 | 3 种实际舞台比例，各 1001 个采样点；保守建筑包围盒加 0.1 单位余量，未发现相机进入；相机最低 Y=6.95。全景主要对象边界均在画面内 |
| P05 输入一致 | 实际滚轮、倒滚、Home/End、快速位置变化与定位共用实际文档进度。Firefox 的 900 输入产生约 642px 位移，映射保持正确 |

| P08 暂停与恢复 | 环境固定 2 秒仍可滚动运镜，播放后环境时间独立推进；暂停并停稳后绘制计数停止；上下文恢复保留相机与实际画面 |
| P09 既有场景保护 | 五个实例批次的矩阵／颜色摘要与修改前相同；默认参考稿正常、像素画布在同环境下均逐像素一致 |
| P10 资源稳定 | Chromium 10 轮、每轮 5 个位置；Firefox/WebKit 各 2 轮；同模式同视口的几何、纹理、程序及采样目标分配不增长 |

几何检查验证相机位置与保守建筑范围、三个停留姿态的柱身射线及全景边界；它不是所有视线、每个像素或无限长运行的证明。关键截图与实际操作实录作为补充。

200ms 是本步原型目标。Chromium 峰值 209.3ms 略高，原样保留；这些值由浏览器观测画面状态，包括该帧处理时间，并非物理设备输入到显示的延迟。真实硬件手感仍需实际设备评审，没有把云软件渲染结果当作硬件帧率通过。

## 浏览器与检查范围

- Chromium 155.0.8059.79：13 组集成检查通过，包含默认参考稿两模式精确对照；正常流程零警告／异常／HTTP 失败。
- Firefox 153.0：12 组通过，保留 4 条已知 PCF／故意丢失上下文诊断，未识别问题为 0；不声称零警告。
- Linux GTK WebKit 26.5：12 组通过，正常流程零警告／异常／HTTP 失败；不是 Apple 设备上的 Safari 实测。
- 全部运行于 Linux 云端软件图形环境。手机为模拟；实际触摸拖动由 Chromium 输入模拟验证，其他两引擎验证模拟手机定位点击。
- 无 WebGL 时有可读提示、8 个图形控制禁用、无残留画布，仍可返回参考稿阅读个人介绍。
- 严格 TypeScript 与 Vite 生产构建通过；依赖和锁文件未改。本步没有重复安装依赖或重跑旧十分钟场景测试。

最后补查同一转场内的提示更新：11.3H「回到中央水潭」、11.65H「重新看见庭院」、12.3H「回到庭院」，以及反向返回，共 5 个位置通过。该补查针对最后的提示刷新修正；三引擎的 37 组功能检查计数保持原值。最终五张 Chromium 关键截图及滚轮实录在此修正后重新保存。

基础减少动态处理会跳过相机缓动并暂停默认环境；最终章节静态浏览模式与完整手机构图仍属第 11 步。
