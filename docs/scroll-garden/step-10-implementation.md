按[第十步标准](step-10-standard.md)组织完整浏览：庭院开场 → 三柱阅读 → 水潭停留 → 全景结尾 → 自主回看。原预览地址后加 `?tour=prototype` 进入正常浏览；`debug=1` 显式显示调试入口。默认参考作品集保持，尚未切换站点入口或发布。

## 路线与水潭停留

保持16段、12.3H总长，以及A三站、B四站、C三站的全部原区间、下降曲线和固定姿态。T01、A3→B1、B4→C1的既有空间曲线经完整检查后保留；C3之后在原T3W内部增加稳定水潭区：

| 区间 | 实际行为 |
| --- | --- |
| 11.1～11.45H | 从C3底部沿原空间曲线到W |
| 11.45～11.55H | 相机/目标/取景高度保持W |
| 11.55～11.8H | 沿原WIDE空间曲线拉回O |
| 11.8～12.3H及末端停留 | 保持O，独立显示结尾 |

水潭导航11.5H位于稳定区中央。H是原生文档滚动对应的距离，稳定区不拦截输入、不吸附、不计时。环境处于播放状态时继续运动，手动暂停时球/水束/水面随原环境时间固定。

O/W及十个阅读相机保持；五条移动曲线每尺寸1001样本，共15015点。相机与静态实体保守包围最小距离2.90098，连接左右值最大差1.22092e-5；未舍入数据的一阶导数左右最大差0.00055024单位/H。101个水潭区样本姿态完全一致，78组基线固定姿态比较通过。具体输入与原始结果见[几何连续性](../evidence/scroll-garden-step-10/geometry-continuity.json)。

## 开场、阅读与结尾

开场沿用原庭院构图，边缘显示“SAKAN / 张辰翰”“让想象，动起来。”“AI动画 · 视觉创作 · 交互实验”和滚动提示。0～0.35H完整，0.35～0.5H随滚动退场。

十个阅读站的个人经历、作品结构和正文显隐保持。全局标题在阅读期间缩为简短章节标识，完整正文继续位于石柱旁。章间用01↔02、02↔03说明空间连接；水潭与开场不再误显示第一柱。所有主界面显隐由当前显示H计算，反向和直接定位均不依赖播放历史。

结尾在11.8～11.95H进入，此后完整保持。显示“sakan · 张辰翰”及创作方向，提供“回到开场→0H”“回看影像→4.95H”。只有完整可见且图形可用时按钮才启用；隐藏时退出Tab序列。末端不自动循环，也不重启环境时间或播放媒体。没有新增虚构联系方式。

新标题使用原字体和纸白/深绿配色，避开中央水球。导航用一组细线与编号组织五入口，12px主标签、至少44×44CSSpx触达，小尺寸分行；三柱原有浅色魔法字/暗底与材质保持。

## 导航、进度与焦点

五入口仍为0、1.74、4.95、9.14、11.5H。常驻导航、结尾回看和调试站点共用一次原生scrollTo与既有镜头短收敛，快速连点由最后一次操作决定。没有增加自动长距离巡游、滚动键拦截、URL章节历史或第二套滚动计数。

导航当前项按同一显示H确定，不因高亮变化触发滚动。滚动不抢正文焦点；常驻按钮激活后保留焦点，结尾按钮跳转后焦点移到常驻目标导航。原Home/End/方向键/翻页键与媒体/弹窗键盘语义保持。

进度、章节和相机同步。百分比中途向下取整，镜头收敛且文档到末端后才显示100%；到顶为0%。进度条有章节和值说明，礼貌状态区只播报明确导航/模式/播放等操作，不逐帧朗读。

正常浏览隐藏工程段号、镜头数据、预留框、STEP标题和参考稿审阅入口。显式debug保留它们与十个站点按钮；图形中断/不可用时正常浏览也显示返回参考版本，恢复完成后还原正常界面。既有文字/档案退路与项目关闭入口保持。
