## 1. 目标、范围与当前问题

把完整浏览组织为：**庭院开场 → 三柱逐段阅读 → 中央水潭停留 → 全景结尾 → 自主回看**。滚轮直接控制运镜，导航方便跳到完整阅读站，访客能认清当前位置并知道怎样继续。

制定本标准时，源码中确认的收尾项：全景/水潭的章节抬头仍回落到“第一根石柱”，开场与结尾共用“本步仅验证运镜”说明，常规界面仍展示工程段号与调试入口，S99尚无独立结尾操作。这些问题已在本步实现中处理，原标准问题说明保留作验收依据。

| 本步负责 | 保持与后续边界 |
| --- | --- |

| 开场身份、章节状态、五入口导航、进度与结尾回看 | 第八步水潭、第九步水球及其时钟/轨迹/材质 |

## 3. 10.2：梳理五段运镜，给水潭稳定停留区

| 路线 | 画面顺序 | 重点检查 |
| --- | --- | --- |
| T01：O→A1 | 识别庭院 → 靠近第一柱 → 稳定上部阅读 | 开场字先退让，柱顶和第一段不过早抢入 |
| T12：A3→B1 | 第一柱下部退出 → 拉开/抬起 → 到第二柱上部 | 从真实A3离开，转场中不跳回第一柱顶 |
| T23：B4→C1 | 第二柱下部退出 → 建立前景柱方位 → 到第三柱上部 | 从B4出发，保持稳定上下方向与庭院空间关系 |
| T3W：C3→W | 第三柱下部退出 → 水球重新进入中心 | 从C3离柱，不穿柱、池沿或台座 |
| WIDE：W→O | 水潭完整停留后拉开 → 回到原全景 | 水球先可看清，结束时精确接回O |

首轮把T3W内部0.7H安排为三个子阶段：**11.1～11.45离柱到W，11.45～11.55稳定W，11.55～11.8由W拉回O**。水潭入口11.5位于稳定区中央。稳定区只保持相机；播放状态下水球和环境继续运行。它仍属于原T3W，不增加第17段；0.10H是滚动区间，不是定时停留。

这组内部划分需双模式实看；如进入/退出变得仓促，优先调空间控制点与稳定区宽度，在11.1～11.8内校准并记录最终值，保留11.5落在稳定区、两端C3/O和总预算。不得用滚动吸附或自动停滚制造停留。

相机位置、目标、取景高度共同连续；使用固定世界上方向，不增加滚转。每条移动曲线首尾平滑衔接，连接静止站点处速度趋近0。相机、正文和导航统一使用同一个当前显示H，快速输入直接求当前状态，不排队补拍沿途镜头。

**通过条件：**五条移动曲线各至少1001个样本；所有段边界、阅读下降边界和新水潭子边界检查左右值。以H±1e-6采样，位置/目标/取景高度差应在1e-4场景单位以内；使用未舍入的路线数据、差分步长1e-5检查左右一阶导数，首轮差值目标≤1e-3单位/H，连接静止段处趋近0，另配正向/反向实录。相机与实体表面安全余量首轮按≥0.12检查；固定阅读视线不被其他柱/池沿挡住，过程无整屏实体遮挡、穿模、翻转、无来源缩放或裁切跳变。

## 4. 10.3：统一文字、符印与跨章交接

三柱保持“符印/标题显现 → 正文完整阅读 → 旧字退去 → 镜头沿柱下降 → 下一段显现”。已有约30%～80%的完整阅读区和各自离开相位保持，不把不同模块强行改成同一排版。

- 十个完整阅读站的正文、作品/按钮与来源标签保持；有动作的内容只在原可用阅读状态下进入点击和Tab序列。
- 相邻段在下降期间完成显隐交接，同一H只有一个主要正文处于完整阅读状态。旧正文退场与新正文进入可以相接，不能两段正文同亮叠放。
- 跨柱时正文隐藏，章节提示只承担方位说明；接近下一柱后由既有符印与标题接管。保留柱面的浅色魔法字与稳定暗底。
- 全局说明在完整阅读时缩为简短章节标识，给柱面正文与作品让出视觉空间；实际字符背景对比度保持≥4.5:1、正文不小于现有16px底线。
- 主叙事文字的显隐依据H计算；停滚定格，反滚复现。不用延迟队列逐字补播，也不让正文跟着水球呼吸闪烁。

**通过条件：**十站逐一完整阅读；所有交界检查显隐、点击、inert/aria-hidden与反向复现，正文/标题/作品不互相遮挡，主要内容不被全局UI压住。

## 6. 10.5：明确导航、进度与键盘规则

章节入口保留五项，点击后使用一次原生滚动定位进入表中固定H，落到完整阅读状态；沿用即时原生定位与既有镜头短收敛，不新增自动长距离飞行。主动点选可快速跳章，手动滚动继续沿同一实际进度连续运镜。

普通点击、快速连点、键盘激活与结尾回看共用一个导航入口。最后一次明确操作生效；无排队、回弹或到站后第二次跳转。画面模式与手动播放/暂停选择保持。点击“水潭”在W稳定区，不滑过后立即拉远。

导航一次仅有一个 `aria-current=location`，当前态不只靠微弱颜色差表达；键盘焦点清楚。常驻导航被点击后保留焦点，滚动不自动focus正文。Tab/Shift+Tab顺序不跳进隐藏内容，Home/End/PageUp/PageDown与方向键在页面上沿用浏览器原生行为；按钮、视频和弹窗的既有键盘语义保持。

进度依据当前显示H/12.3计算，与镜头同步；正文阅读进度与环境播放时间分开。镜头收敛到末端、且距实际文档底部≤1CSSpx时显示100%，到顶显示0%，中途不因百分数取整提前宣称完成。`aria-live`只反馈明确导航/状态操作，不逐帧播报百分比或工程段号。

本步保持现有URL、刷新和历史行为，不新增章节深链接、自动续读或每段pushState。正常/像素等已有查询参数更新合同保持，参考版本入口继续有效。

**通过条件：**五入口与结尾两入口在正向、反向、跨章和连续操作中到达目标；停稳H误差≤0.003（记录原生像素取整），模式/环境选择与焦点正确，无滚动劫持及历史记录污染。

## 8. 10.7：完成水潭到结尾的收束与回看

访客到W时先能看清完整蓝色球心、水束与水面关系；离开稳定区后，镜头拉回原O。到11.8H进入S99，保持原全景直到12.3H及后续停留。

结尾使用独立、简短的品牌与回看区域，候选为“sakan · 张辰翰”及“AI动画 · 视觉创作 · 交互实验”。保留两个明确动作：**回到开场→0H；回看影像→4.95H**。当前没有真实联系方式，结尾不显示空联系方式或无效合作按钮。

结尾显隐首轮在11.8～11.95H完成，此后保持；两按钮只在完整可见时启用，离开结尾后隐藏并退出Tab序列。滚到末端不自动回0，不重启环境时间，不强制播放或打开作品。S00/S99相机相同、文字与H不同，不能因“全景”导航高亮而误触发回到开场。

回看在同一页面与同一场景中完成，保留当前正常/像素和播放/暂停选择，水球不重新随机生成或重置时间。明确激活结尾按钮后，由于原按钮会隐藏，焦点落到常驻目标章节导航；进入结尾本身不抢焦点。

**通过条件：**结尾能长期停留；上下滚动可逆；两动作目标准确；至少10轮“结尾→回到开场→章节→再到结尾”没有额外canvas/video、重复监听或状态重置。

## 10. 10.9：隔离、资源、性能与回归

预期变更集中于原型路线、入口状态、全局UI/样式及少量独立展示/导航辅助。入口、导航展示与执行动作分离；按需注册监听，销毁时撤销监听/观察器/待处理帧。正文数据、媒体来源和水体效果模块保持。

| 预算 | 要求 |
| --- | --- |
| 新GPU几何、纹理、渲染目标、全屏pass、灯光 | 全部0 |
| 新程序/固定姿态draw calls | 0；同模式、同时间、同镜头与完整预热历史比较 |
| 场景与时钟 | 唯一场景/canvas/renderer与原环境时间；不新增独立相机播放循环 |
| 新UI与监听 | 定量、单份；10轮媒体/回看后DOM、canvas、video和GPU缓存不持续增长 |
| 第九步保护 | 球/水束/水滴/波纹实现与配置、池体材质/几何、水位/灯光/植被、旧素材/证据/release保持 |

转场镜头不同允许看到不同物体，draw calls不在不同取景之间机械比较；O/W及十个阅读姿态相同条件下应保持场景像素和资源结果。DOM新增开场/结尾与导航的预期变化单列，不能整屏遮罩后声称没有回归。
