## 4. 5.3：A2 中部——现在与此前的经历轴

主标题采用「现在与此前」。正文采用一条短竖线串联两条记录，使用可阅读的文本结构，不增加两个独立卡片或编造带年份的履历表。

| 顺序 | 标签 | 公司 | 已知工作内容 |
| --- | --- | --- | --- |
| 1 | 现在 / NOW | 枫叶互动 | AI 动画制作 |
| 2 | 此前 / BEFORE | 游族网络 | 不补充未知职责 |

「现在」使用较明确的淡金节点；「此前」使用较轻的水蓝节点。两条公司的正文对比度均须合格，不能用降低旧经历文字透明度表达层级。时间线、节点是装饰，屏幕阅读顺序为现在→公司→工作内容→此前→公司。

当前经历在上、此前经历在下，标签与公司靠近。移动端保持这一顺序，不增加横向滑动。两条记录在同一正文显隐组中出现，满阅读区同步完整可见；不添加进入后自动切换的履历轮播。

## 6. 5.5：统一视觉层级与容量

三站共享现有柱色、符印、字色、局部柔边承托和细光引线。通过姓名、经历轴、方向图形成差异；不复制三个完全同构的大段落，也不另加背景图、全屏滤镜、光源或持续漂动的正文。

| 项目 | 起始设定与硬性要求 |
| --- | --- |
| 色彩 | 沿用第四步：标题 `#FFF1CD`、正文 `#EDF4E6`、承托 `#223B33`，淡金/水蓝只作少量强调 |
| 正文与公司名 | 桌面 18px、手机至少 16px；行高约 1.65～1.7 |
| A1 标题 | 桌面 36～40px、手机 28～30px，布局不合格时先收回该范围上限 |
| A2/A3 标题 | 沿用桌面约 27px、手机约 22px |
| 化名注脚 | 桌面/手机至少 16px，依靠间距和位置建立次要层级 |
| 章标/小标签 | 作为辅助信息，中文和公司名不借此缩小到微型字 |
| 承托宽度 | 初始沿用桌面 420px；390px 手机为 358px，即左右各 16px |

| 容量 | 每站全部公开文案以约 90 个字符内为初始编辑预算，含标题、标签和注脚；按实际换行和字面校准 |
| 内部滚动 | 正文无独立滚动条；触摸、滚轮继续操作文档运镜 |

共用阅读承托根据三站实际排版预留稳定空间。当前实现将三个 article 放在同一网格单元，新增结构后要确认被隐藏站点不会造成多余高度；只在内容、字体或窗口改变时重新测量，不按滚动进度持续改高度。

桌面正文在柱旁；手机在符印下方。柔边必须算在阅读层占用内。手机左右至少 16px，阅读层与顶部信息、底部章节导航至少留 16px；符印的实际可见范围与引线保持通畅。现有 `anchorClear`、`fits` 应根据实际布局判断，不为通过检查而放宽定义。

容量不足时先去除重复解释、压缩纯装饰间距或改用更短的已知事实表达；真名、化名、当前公司、AI 动画、此前公司和三个方向都要保留。目标竖屏仍放不下则修正本步局部版式并记录，不以缩小正文、裁切、折叠核心事实或把失败挪到第 11 步来结束。

第四步的 200 字手机压力样本与狭矮横屏限制继续保留；本步验收的是上述真实短内容。200% 文字缩放等完整适配仍需第 11 步处理，有问题应记录，不能写成已通过。

**通过条件：**1440×900、1366×768 和模拟 390×844 下三站实际文字完整，雾影覆盖全部文字，对比度≥4.5:1，没有遮住符印、导航或产生横向溢出。字体回退后也能阅读。

## 8. 5.7：内容组织、可访问性与实现约束

执行时将正式第一柱内容集中到一个轻量内容模块，记录真实信息来源；与阅读坐标、时间段分开。实际采用 [aboutContent.ts](../../src/tour/aboutContent.ts)，维护位置见实现说明。

沿用现有三个语义 article、阅读承托和引线，只在其中加入身份、经历与方向结构；不为每段创建新的画布或三套叠加阅读面板。保留原站点 ID 与数值，路由采样无需为新文案另起一套。

正文为真实 DOM 文本，可选择、复制。经历用有序文本结构，方向使用语义列表；装饰节点与线条设为辅助技术忽略。只有当前可见站点可访问，正文尚未出现或已经退出时，新增的姓名行、注脚和记录也要同步隐藏。不要用隐藏的整份重复简介弥补语义。

滚动切换不抢焦点、不逐字播报；沿用当前状态提示。字号、字体替换、窗口变化会触发测量并重新定位，稳定阅读不反复读写布局。模式切换、标签页隐藏和上下文恢复应保留当前站及段内比例。

本步按 DOM 内容与局部样式改动实施，**不新增几何、纹理、着色程序或应用依赖**。保留第四步光尘池、一个共享时钟、单模式与两模式缓存上限；其他柱、场景物体和已校准的贴面锚点保持。

**通过条件：**内容后续能在一处维护；复制文字语序正确；无隐藏站点的可聚焦元素或重复朗读；重复进出三站后节点与 GPU 资源不增长。
