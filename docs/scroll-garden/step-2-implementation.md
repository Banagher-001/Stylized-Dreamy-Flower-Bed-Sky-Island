# 第 2 步实现与使用

滚轮运镜原型已实现，默认页面继续保留此前个人作品集。当前原型不包含沿柱下降阅读、正式正文、魔法文字或新水球。

## 进入与操作

运行项目后，在当前网页地址后加 `?tour=prototype`。已有其他参数时用 `&tour=prototype`。

- `?tour=prototype`：环境按原有偏好播放，滚动控制镜头。
- `?tour=prototype&waterTime=2`：环境固定为 2 秒，便于比较镜头；滚动仍可使用。
- `?tour=prototype&render=native`：直接正常画面；默认是 384 长边像素模式。

使用滚轮、触控板、浏览器键盘滚动或手机滑动推进。右侧按钮直接定位全景、三柱首站或水潭；暂停按钮只控制环境时间。右下“镜头数据”可查看当前位置、注视点、取景高度和资源状态。

“返回参考稿”会离开原型入口。原型不自动成为默认首页，也没有发布公网地址。

## 当前路线配置

配置位于 [route.ts](../../src/tour/route.ts)。以下为水平构图偏移前的基础值；实际相机位置会根据舞台纵横比平移，读取界面中的“镜头数据”可查看实际结果。

| 构图 | 基础位置 | 基础注视点 | 取景高度 | 目标横向占比 |
| --- | --- | --- | --- | --- |
| O 全景 | `[4.5,23,16]` | `[0,0.45,0]` | 11.3 | 50% |
| A 关于我 | `[-1.14,6.95,6.1]` | `[-2.34,2.75,-2.9]` | 3.6 | 34% |
| B AI 影像 | `[5.61,7,8]` | `[4.41,2.8,-1]` | 3.8 | 28% |
| C 交互实验 | `[4.16,6.95,14.09]` | `[2.96,2.75,5.09]` | 3.6 | 34% |
| W 水潭 | `[2.32,11.15,7.5]` | `[0.12,0.65,0]` | 6.2 | 50% |

转场使用带中间控制点的连续曲线，首尾平滑接入停留姿态，固定相机上方向。三个章节目前都停在首站；转场也从对应首站起步，避免从尚未实现的柱底姿态突然跳出。

运行分段与第一步保持一致，水潭转场细分为 11.1～11.5H 的回访和 11.5～11.8H 的拉回。结尾回到原基础姿态，不自动循环。

## 实现结构

| 文件 | 作用 |
| --- | --- |
| [main.ts](../../src/main.ts) | 根据 `tour=prototype` 延迟加载独立入口 |
| [startPortfolio.ts](../../src/portfolio/startPortfolio.ts) | 从原 main 保留的参考稿逻辑，仅调整模块相对路径 |
| [route.ts](../../src/tour/route.ts) | 独立的进度采样、关键构图、路径与纵横比处理 |
| [startTourPrototype.ts](../../src/tour/startTourPrototype.ts) | 固定舞台、原生滚动、统一显示进度、控制与恢复 |
| [tour.css](../../src/tour/tour.css) | 仅原型入口加载的样式与控制层布局 |
| [createScene.ts](../../src/scene/createScene.ts) | 新增动态取景高度；默认仍为 11.3，缩放后调整窗口不会回到初始全景 |

植物仍在原基准相机下生成，后续只移动相机，不重新排布植物。渲染器、像素管线、时钟、石材、灯光、水体、环境公式及媒体未改动。

滚动输入以实际文档位置为准，仅对统一显示过程作很短的平滑，不排队播放动画。环境时间独立推进；环境暂停时，只有镜头未稳定才临时开启更新，稳定后保留既有有限重绘预算并停止。窗口变化保留当前显示进度，再重算滚动范围和构图。

舞台高度扣除实际控制条高度，关键目标不会藏到下方控制条后。手机本步仅提供基础画幅和触摸可用性，正式手机运镜与减少动态章节视图在第 11 步继续校准。
