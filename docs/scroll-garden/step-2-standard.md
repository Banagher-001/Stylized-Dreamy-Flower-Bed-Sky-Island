# 第 2 步执行标准：滚轮运镜原型

用户已明确要求执行第二步。本步建立独立运镜原型，默认个人作品集保留。范围依据第一步的 16 段、12.3H 分镜和本轮确认的第二步标准。

## 范围

- 使用同一座庭院与一个渲染器，完成全景 O、第一柱 A、第二柱 B、第三柱 C、水潭 W 与全景返回。
- 全屏舞台固定在视口，页面实际滚动驱动相机；控制条占用独立空间，避免挡住前方柱脚。
- 章节阅读区暂时固定在各柱首站。A2/A3、B2/B3/B4、C2/C3 的进度保留，竖向阅读仍在后续阶段。
- 编号、进度、定位按钮和阅读区域线框仅为原型控制，不代表最终界面。
- 建筑、草花、灯光、材质、色板和水体公式保持；魔法文字、第 3 步沿柱下降和第 8、9 步水体升级不进入本步。

## 路线

| 区间 H | 行为 |
| --- | --- |
| 0～0.5 | 全景 O |
| 0.5～1.3 | 靠近 A |
| 1.3～3.7 | 第一柱首站 A，阅读区预留 |
| 3.7～4.4 | 拉开抬起并转向 B |
| 4.4～8.0 | 第二柱首站 B，影像区预留 |
| 8.0～8.7 | 转向 C |
| 8.7～11.1 | 第三柱首站 C，阅读区预留 |
| 11.1～11.5 | 回访水潭 W |
| 11.5～11.8 | W 扩大取景回到 O |
| 11.8～12.3 | 全景收束 O |

12.3H 是原型滚动预算，原始 wheel 增量不是章节计数。浏览器设置可以使同样的滚轮输入产生不同页面位移；相机始终依据实际文档位置。

| 编号 | 标准 |

| P03 | 段落和控制点交界连续，正反向恢复相同姿态 |
| P04 | 路径采样检查相机进入建筑/地面的情况，配合关键截图检查画面 |

| P08 | 环境暂停时仍可运镜，全部稳定后停止持续绘制 |
