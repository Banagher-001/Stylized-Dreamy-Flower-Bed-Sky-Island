# 第6步实现与使用：第二柱AI影像

第二柱的**设计示意版与查看/播放器机制**已实现：四个阅读高度、02贴面符印、主海报、同图切片、横竖双页、章末收束，以及完整图片查看与关闭恢复。真实个人AI动画、制作分镜、本人职责和真实目录仍待提供，未标为接入完成。

标准见[第六步执行标准](step-6-standard.md)，结果与限制见[验收记录](step-6-verification.md)。当前停在第六步用户审阅点，第七步未开始。

## 进入与操作

当前预览地址加 `?tour=prototype`，已有参数时用 `&tour=prototype`。默认参考作品集保留。

- 滚动经过第一柱，沿水潭外围靠近第二柱，再从上到下依次观看四站。
- 「02 AI影像」定位B1满阅读区；既有「镜头数据」内新增B1～B4定位，A1～A3保留。
- 点击画面右下角查看入口或画面本身，打开完整图；图片附近及查看层都有「网页设计样片／非个人实际项目」标识。
- 查看期间背景暂停且滚动锁定；关闭按钮/ESC返回原站点及段内进度，焦点回到原入口。原先播放环境时返回后继续，原先暂停时保持。
- 正常/像素模式、向上倒滚、环境播放/暂停和返回参考稿继续可用。
- `?tour=prototype&waterTime=2` 固定共享环境时间，便于对照，不代表必须观看的时长。

媒体在接近第二章时加载，优先当前及下一站。图片框预留尺寸，加载后不顶动文字或镜头；载入/失败提示适配手机小切片。主海报和双页采用contain保留比例；B2局部明确标注，点击仍查看原图。

正文与作品图片采用清晰DOM层，庭院保留原像素管线。标题桌面27px/手机22px，正文、图名和样片标识18/16px。框线、标题、画面和说明由同一滚动进度采样；完整阅读区稳定，不自动轮播、不新增动画时钟。

## 查看与播放器机制

原生dialog承载单一图片或video。打开保存叙事进度和手动环境选择，暂停背景时钟/绘制；关闭按新可视尺寸恢复原站点，不使用旧scrollY。切换、快速关闭重开、加载失败与12秒慢加载提示都有清理路径；关闭移除视频来源并停止解码，隐藏标签会暂停影片，返回后由用户再次播放。

当前作品数据没有真实影片，第二柱只提供完整图片查看。播放器使用同一组件在[隔离测试页](../../tests/scroll-garden/media-fixture.html)验证，素材为12秒无声庭院演示，并明确标为测试夹具；它不在第二柱作品数据中，不是个人AI动画正片，不随原型加载。

真实素材接入时需补齐实际项目、影片/外部地址、对应画面、职责与目录，并按真实资料调整和复验。当前两个示意源共用设计样片标识，不应仅改来源状态就宣称真实作品编排完成。
