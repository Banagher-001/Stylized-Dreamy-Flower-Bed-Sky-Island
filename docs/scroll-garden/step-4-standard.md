# 第 4 步执行标准：深色柱面与浅色魔法文字样板

状态：**用户已明确授权并执行第四步，当前停在本步验收点。** 以下保留执行前确定的标准，实际实现与取舍见 [使用说明](step-4-implementation.md)，结果与限制见 [验收记录](step-4-verification.md)。

本步承接 [第一步视觉方向](step-1-storyboard.md)、[第三步阅读机制](step-3-implementation.md)和[第三步验收限制](step-3-verification.md)。以下颜色、尺寸和效果预算为执行前确定的设计目标，不以本标准替代实际验收证据。

## 1. 本步目标与范围

视觉方向为「古老石刻被唤醒」：墨青灰石身、暖浅石色柱顶、象牙白文字、少量淡金与水蓝细光。魔法感通过柱面符印、字缘光、凝聚与消散顺序建立，完整正文保持清晰稳定。

先以第一柱 A1 建立样板，再将同一套视觉规则应用到现有 A2/A3，检验沿柱下降时的连续性。三段验证文字保持，完整关于我编排仍属第 5 步。第二、第三柱的材质与内容在各自后续阶段套用，不在本步全部完成。

| 本步实施 | 保留的后续范围 |
| --- | --- |
| 第一柱石身深色材质、接缝与受光层次 | 第二、第三柱的正式章节呈现 |
| 柱面符印、浅色标题与正文、柔边阅读承托 | 第 5 步完整个人介绍编排 |
| 滚动控制的唤醒、凝聚、稳定阅读、消散 | 第 6、7 步正式影像和交互作品内容 |
| 有上限的少量光尘、暂停与减少动态兼容 | 第 8、9 步水潭、水球升级 |
| 三站及目标画幅回归 | 第 11 步狭矮横屏和完整手机章节视图 |

继续使用 `?tour=prototype`。16 段、12.3H、三个阅读高度、完整阅读区间和 A3→T12 镜头保持第三步规则。默认参考作品集保留。

## 2. 4.1：锁定基线并隔离第一柱材质

执行前保存第三步源码、镜头配置、固定环境时间画面、GPU/DOM 计数和同脚本收敛观测，作为本步对照。

已核对的实现约束：

- [createBlockout.ts](../../src/scene/createBlockout.ts) 中柱子、水潭边石、地砖等共用石材实例；[createArtMaterial.ts](../../src/materials/createArtMaterial.ts) 用定制明暗公式处理石材，不能直接改共享材质来完成第一柱着色。
- [createScene.ts](../../src/scene/createScene.ts) 的补光也引用全局石色。因此全局色板、灯光和曝光保持，深色通过第一柱专用材质参数实现。
- 复用现有石材定制着色逻辑，显式建立独立色彩实例与 uniform 值。若采用材质复制，需确认 onBeforeCompile、自定义缓存键及 uniform 所有权完整保留；不能假定普通 clone 自动保留所有定制行为。
- 新外观只由原型入口启用，只绑定 `columnUpperLeft-shaft` 下的石块与接缝。柱顶、底座以及其他建筑继续使用原材质。

**阶段通过条件：**第一柱石身已深，倒角、缺口、接缝和明暗仍可辨认；柱顶与底座保留暖浅石色。其他对象的原材质引用/参数、原几何与物体位置不变，默认参考页保持原画面。

## 3. 4.2：确定色彩与文字层级

以下为 sRGB 候选起点；石材经过现有光照后不会直接等同于输入色值。执行时结合正常/像素画面校准，并记录最终参数。

| 层级 | 候选颜色 | 呈现要求 |
| --- | --- | --- |
| 石身受光面 | `#405B55` | 深青灰中带少量墨绿，保留面与面之间的差别 |
| 石身背光面 | `#263E3A` | 有色相与纹理的暗面 |
| 凹缝 | `#1B302D` | 比石身更深，体现层叠结构 |
| 柱顶/底座 | 沿用原暖浅石色 | 保留与草地、水潭的场景联系 |
| 主标题 | `#FFF1CD` | 象牙白带少量暖金，字面清楚 |
| 正文 | `#EDF4E6` | 稳定的浅白绿，完整阅读态不闪烁 |
| 符印与细光 | `#C4DFDB`、`#DCCB9D` | 水蓝与淡金，亮度低于文字焦点 |
| 少量点缀 | `#CDBFE4` | 淡紫只用于极少光点 |
| 正文背后承托 | `#223B33` 附近 | 字行下有稳定深色核心，边缘向背景消隐 |

桌面标题约 26～30 CSS px，手机约 22～24px；正文沿用桌面 18px、手机至少 16px，行高约 1.65～1.7。使用现有中英文字体堆栈与中文回退，标题和正文保持可选择的语义文本。

标题可有小范围柔光，初始模糊半径约 4～8px，手机减至约 3～5px。正文保持锐利，发光不代替字面固有色，也不改变行距、字宽或段落布局。

**阶段通过条件：**完整阅读态正文与标题相对于实际合成底色的对比度至少 4.5:1；羽化位于字行之外。需要在亮草地、水面、石身和阴影等可见背景条件下核对，不能只报告独立色块的比值。

## 4. 4.3：建立柱面符印和实际贴面锚点

样板符印采用统一的「细线断环 + 短刻线 + 竖向铭线」图形。柱面保留章节编号 01，三站通过少量刻度区别阅读位置。A1/A2/A3 等调试信息留在现有数据面板中，当前圆圈焦点与白底标签在第一柱由符印替换。

符印建议桌面投影约 56～80px，手机约 36～48px。世界层图形的主笔画在默认像素采样后至少保留约 1 个采样像素，避免近景断线；全景细节不足时淡出细刻线，保留低对比暗纹，不制造闪烁。

已验证的关注点与表面命中：

| 站点 | 原相机关注 Y | 第三步射线首先命中的石块 |
| --- | --- | --- |
| A1 | 2.75 | `columnUpperLeft-block-3` |
| A2 | 1.80 | `columnUpperLeft-block-2` |
| A3 | 0.85 | `columnUpperLeft-block-1` |

关注 Y 位于柱轴线，不等于正面刻字中心。当前相机有俯角，A3 的正面命中甚至处于另一块石头；不能直接复制轴线坐标把符印放进缝隙或石头内部。

贴面校准依次执行：确定目标正面 → 取得命中石块局部平面 → 为整个符印预留倒角/缝隙内边距 → 保存局部锚点。必要时在同一石块正面内部小幅调整符印中心，相机关注点与路线保持。

锚点校准后依附石块局部坐标。改变窗口只更新投影，不让符印在石面上滑动。世界层符印保留深度测试，离石面仅使用消除重叠所需的小偏移；不投射新阴影，不新增点光源。应在靠近、阅读、下降与跨柱离开时检查侧视、遮挡和接缝。

**阶段通过条件：**符印确实依附石面，不穿模、不悬空跨缝，视角变化时遮挡正确；三站符印与编号沿柱依次下降，镜头参数与第三步一致。

## 5. 4.4：将阅读框改为从石面延展的文字

保留「柱面识别层 + 清晰阅读层」：符印和编号依附石面，标题与正文在附近展开，并由短而轻的光引线保持空间联系。阅读文字继续独立于 384 长边的场景采样，维持中文清晰度。

当前矩形阅读框的实边、整块方形阴影与调试连接线，需要替换为边缘柔和、略有不规则轮廓的深色雾影承托。字行下的深色核心要完整覆盖正文，外围约 16～24px 渐隐；手机适当缩减。承托轮廓在稳定阅读时保持静止。

羽化与光晕须计入排版占用范围，优先在现有容器边界内实现，避免新增视觉外扩挡住导航、柱面焦点或页脚。正文展开后仍自然换行、没有内部滚动，三站的共用排版高度保持稳定。

完整阅读态：符印与字面稳定，正文无模糊或亮度呼吸。少量光尘只在符印/字缘附近的留白处活动，不从正文中间穿过。

**阶段通过条件：**一眼能看出文字与这根柱子相连；完整文字可读，第三步的生硬矩形边界已被柔边承托替换。1440×900、1366×768 与 390×844 下三段短文均完整显示，效果外沿不占用必要控制空间。

## 6. 4.5：在既有滚动段内细化魔法显隐

保持第三步的 0/15/30/80/100% 总分段边界，细化 15～30% 内的标题与正文先后顺序。所有数值都是段内滚动比例，不能换成强制播放秒数。

| 段内进度 u | 符印与装饰 | 标题和正文 |
| --- | --- | --- |
| 0～15% | 当前符印由暗纹逐渐点亮，短线被描出 | 正文隐藏；镜头完成接近本站 |
| 15～22% | 符印建立与标题起点的联系 | 标题先凝聚；正文从约 20% 开始显现 |
| 20～30% | 少量边缘光点收束 | 正文通过透明度与轻微柔边遮罩凝聚，30% 前全部完成 |
| 30～80% | 轮廓和亮度保持；仅光尘可随环境时间轻移 | 标题和正文完整可读，所有滚动视觉参数保持常量 |
| 80～96% | 少量点光向下引导；镜头按原窗口下降 | 正文逐渐消隐，标题稍后退出 |
| 96～100% | 活跃光和尾迹归零；石面暗纹可保留 | 所有旧正文和标题完成退出 |

A1/A2/A3 的完整阅读区仍为 **1.54～1.94H、2.34～2.74H、3.14～3.54H**；两次下降仍为 **1.94～2.22H、2.74～3.02H**。T12 从柱底连续出发不变。

新增独立的符印、标题、正文与光尘显示状态，明确它们的实际透明度/遮罩完成度。第三步的组透明度不再足以代表每一层的可见程度；本步测试需检查新显示状态，不能照搬旧「所有层在 22.5% 都为半透明」的断言。

每层由统一显示进度确定，装饰漂移只复用已有环境时间。向上滚动在同一 H、同一环境时间恢复相同画面；快速跳转直接显示当前状态。停在凝聚或消散中途就保持该状态，不能等待定时动画自动补播。相邻两段不能同时处于完整阅读状态。

**阶段通过条件：**符印先唤醒、标题先于正文、完整阅读稳定、退出有明确顺序；正反向、快速定位与停滚中途均成立，不改变已有阅读和运镜预算。

## 7. 4.6：限制光尘与发光成本

优先使用局部字缘光、共享符印图形和少量批量光点。继续使用现有像素管线、一个可见场景画布和同一动画循环，维持原有色彩输出转换。

| 项目 | 初始实现预算 |
| --- | --- |
| 光尘总池 | 桌面最多 24，手机最多 12，固定种子与复用槽位 |
| 稳定阅读可见光点 | 桌面不超过 8，手机不超过 4，集中在文字外留白与符印附近 |
| 新增 Three.js 几何 | 不超过 3 个共享几何资源 |
| 新增 Three.js 纹理 | 不超过 2 张，包括符印图集 |
| 新增 GPU 程序 | 预热后不超过 3 个，需用实际计数核对 |
| 发光方式 | 局部表现；本步不加入全屏 Bloom、额外离屏后处理或新场景光源 |
| 更新方式 | 复用已有帧更新与环境时间，不另建持续 RAF/定时器 |

光尘的初始位置与变化可复现；不逐帧随机重建粒子、材质或纹理。暂停环境后光尘冻结，但滚动仍可推进显隐；环境暂停且滚动停稳后应停止持续 GL 绘制。减少动态时去掉漂移/散射与装饰运动，保留稳定符印和直接可读文字；完整静态章节视图仍在第 11 步。

第三步 Chromium 记录为 p95 189.9ms、峰值 259.1ms，已经存在峰值超目标的限制。执行本步时用相同脚本与画幅保存修改前后样本，继续以约 200ms 收敛为原型目标；若 p95 相对同环境基线明显恶化（预算约 +10%），先降低装饰成本并复验。峰值和未达目标情况原样记录，软件图形结果不作为硬件帧率验收。

**阶段通过条件：**资源在预算内，10 轮阅读往返后同模式、同视口计数不增长；文字节点数量稳定，暂停无持续绘制。效果关闭/降级时阅读与导航仍可用。

## 9. 4.8：交付并停在第四步

执行完成后交付：

1. 第一柱 A1 的完整魔法文字样板，以及 A2/A3 的一致应用。
2. 最终材质/配色/文字/光尘参数与实际贴面锚点。
3. 第三步→第四步的同机位前后对比；暗纹、唤醒、完整阅读、消散的关键画面；正常/像素和手机画幅对照。
4. 真实滚轮正反向操作实录，固定环境时间对照与环境播放演示分开标注。
5. 验收结果、性能/资源记录、保留限制及文件改动清单。

预计修改原型外观与阅读模块；必要时给石材工厂增加保持默认行为的可选参数。魔法样式参数集中管理，贴面符印和光尘有明确 dispose，避免把装饰逻辑散入水体或植物模块。不新增应用依赖，不改原建筑几何/布局、灯光、色板或媒体内容。

完成后停在第四步验收点。第五步先细化第一柱「关于我」的正式内容与编排标准，再按用户明确指示实施。本步不发布、部署、Git 提交、推送或覆盖历史交付归档。
