## 发现与处理

- 320 档会损失部分小花、细草与接缝，448 档边缘更细；综合桌面和手机选 384。保留三档对照入口供视觉复核。
- 轻微色阶没有提供足够的视觉改善，因此默认关闭。颜色、阴影与水的明暗继续由前六步材质负责。
- 真实上下文恢复后画面正常，但最终销毁时发现旧 GPU 代的删除警告。现于上下文丢失期间清理旧目标、几何、材质、实例和阴影 GPU 资源回调；保留 CPU 数据，恢复后重新上传。连续两次恢复及最终释放均无警告。未修改依赖或屏蔽控制台输出。

## 验证范围与后续

- 无头 CDP 在保持窗口尺寸时改变实际 DPR，不产生原生媒体查询 `change` 事件。运行中 DPR 监听路径使用实际 DPR 值配合 `MediaQueryList` 事件夹具验证；不同 DPR 新建浏览器上下文则直接验证实际输出。真实跨屏事件仍待真实环境检查。
- 页面隐藏同样通过 `document.hidden` 与 `visibilitychange` 夹具验证；没有声称完成真实标签切换检查。
- 半浮点备用路径在同一软件 GPU 上强制使用 sRGB8 验证，不代表已覆盖所有移动 GPU。
- MP4 是 60 帧、12 fps 编码、680×680、5 秒、H.264/yuv420p 的固定时间采样演示。它验证设计运动及采样稳定性，不是硬件 FPS 测试。
- 真实手机、Safari/Firefox、跨屏与硬件性能保留到第九步；环境植物动画仍在第八步，本轮不推进。
