# 第八步：环境微动与动效整合

在当前第七步草稿上增加草花轻摆、树影微动和整场景动效控制。固定镜头、布局、石头、光照、植物分布与水体运动沿用；默认仍为 384 设计采样、最近邻输出、原色。水保持主要动势。

## 执行标准与顺序

| 顺序 | 工作 | 执行与验收要求 |
| --- | --- | --- |
| 8.1 | 保存第七步基线 | 同一窗口、时间 2 秒，记录正常/像素画面、源码摘要、全部网格与植物实例数据；关闭环境动效能精确恢复 |
| 8.2 | 统一时间 | 环境接入现有场景时间，不增加独立动画循环；同时间、同种子姿态一致 |
| 8.3 | 草叶轻摆 | 根部固定、上部逐渐弯曲；位置相位形成局部关联，风强缓慢变化 |
| 8.4 | 花朵联动 | 花头跟随花茎端点与切线，根、植株高度和相位在不同实例批次间一致 |
| 8.5 | 石缝短草 | 使用更低角度，检查最大正负摆幅及完整活动范围，保持石板避让 |
| 8.6 | 树影微动 | 维持大块轮廓和固定叶片结构，缓慢扰动边缘及已有透光孔；地面和植物共享世界坐标取样 |
| 8.7 | 飘花对照 | 固定容量、低速、深度遮挡和安全通道；比较桌面与手机，按视觉收益决定是否默认保留 |
| 8.8 | 统一控制 | 播放、暂停、减少动态和隐藏恢复覆盖全部动效，更新无障碍说明 |
| 8.9 | 整合验证 | 复验像素尺度、响应式、运动复现、GPU 资源、上下文恢复、生产产物，记录证据后停在验收点 |

## 最终参数

| 项目 | 数值与含义 |
| --- | --- |
| 独立动效种子 | `82026`；不消耗植物分布种子 `52026` 的随机序列 |
| 风向 | `[1, 0.32]` 归一化，世界 X/Z 方向 |
| 普通草叶最大弯曲角 | 8°，指叶尖切线转角 |
| 花茎/花头最大弯曲角 | 6°，花头沿茎端切线转动 |
| 石缝短草最大弯曲角 | 2.5° |
| 基础风周期 | 5.8 秒和 4.4 秒，权重 0.78 / 0.22 |
| 缓慢风强周期 | 16 秒；角度始终受上述最大值约束 |
| 树影周期 | 10.5 秒和 12 秒，与 16 秒风强共同调制 |
| 树影扰动距离 | 0.045 场景单位；在 384 网格下约为 1.53 个源像素的世界距离 |
| 已有透光孔变化 | 阴影遮罩强度最多 2.5%，保留原孔洞和叶片随机结构 |
| 植物包围范围 | 原包围盒各向扩展 0.02，包围球半径增加 0.02；初始化一次 |
| 飘花默认 | 关闭；保留独立对照入口 |
| 飘花对照配置 | 容量 8，周期 11 秒，活动期 6 秒，水平漂移每轴不超过 0.16，高度 0.65→0.07 |

最大角度下的茎端水平位移：普通草约 **0.00976**，花茎约 **0.00778**，石缝短草约 **0.00275** 场景单位，均在执行标准的上限内。像素边缘跨采样格时可离散改变；相同时间重复渲染保持同一结果。

## 草花实现

植物分布、颜色、原始位置/法线和实例矩阵保持。四个植物实例批次仍为草簇、花茎、四瓣花头、五瓣花头。

每个实例初始化两组静态属性：

- `windRoot`：同一株植物的根位置。
- `windShape`：植株高度、最大转角、位置相位、是否为刚性花头。

每帧只更新共享环境时间，顶点着色器按圆弧中心线变形。根部不移动，上部沿圆弧弯曲；花头作为整体跟随茎端切线。法线使用弯曲变换的逆转置同步处理，实际阴影和树影都从变形后的位置取样。

小角度的圆弧与旋转计算使用适合当前角度范围的多项式形式，避免接近静止时 `1-cos(angle)` 相减丢失精度。CPU 解析参考与实际 GPU 顶点输出进行了交叉验证。

植物仍接收建筑阴影，保持不投射细碎动态阴影。根部与实例缓冲不因播放、窗口尺寸或观看方式重新生成。

## 树影实现

沿用现有三片世界坐标树影遮罩。边缘的距离场受平滑、低频风场影响，内部大色块与叶片哈希结构保持固定。已有透光孔只有少量连续遮蔽变化，不逐帧生成随机孔洞。

建筑方向光与实际阴影图保持。树影艺术遮罩继续只作用于地面和植物，石头与水面沿用实际建筑投影。

GPU 遮罩探针在 0～24 秒的 25 个时间点检查覆盖面积，并比较相同世界位置的地面/植物取样。具体结果见验收报告及原始数据。

## 飘花取舍

完成了桌面和 DPR 2 手机的同时间开启/关闭试作对照。在默认 384 采样下，新增花瓣多数只占少量像素，与原有零星花色相近，空间感收益有限，因此默认关闭。

对照功能使用一个实例化批次，启动时为每条运动通道预留水平漂移与花瓣宽度，避让喷泉、柱子、矮墙和石板。实例数量固定，活动矩阵复用，闲置槽位重置，返回同一时间能复现完整缓冲。正常深度测试使花瓣接受建筑遮挡。

## 时间与交互

- 水、草花、树影及启用后的飘花共享场景时间和现有动画循环。
- 播放/暂停按钮控制整场景，无障碍提示同步更新为“场景动效”。
- 减少动态默认静止，允许主动播放；手动暂停在偏好变化后保留。
- 隐藏事件停止绘制和时间推进；恢复时重置帧间时间基准。
- 兼容 `waterTime=2`，该参数现在固定整场景时间并暂停；点击播放后继续。
- 相同时间可直接重建姿态，无需从零播放到该时刻。

| 应用参数 | 对照用途 |
| --- | --- |
| `?waterTime=2` | 默认环境微动在 2 秒的暂停姿态 |
| `?waterTime=2&render=native` | 同时间正常画面 |
| `?waterTime=2&env=off` | 关闭新增环境动效，精确恢复第七步，保留原喷泉状态 |
| `?waterTime=2&wind=off` | 关闭植物轻摆以检查树影 |
| `?waterTime=2&canopy=off` | 关闭新增树影变化以检查草花；原静态树影保留 |
| `?waterTime=2&petals=on` | 开启飘花对照 |

`env=off` 优先关闭全部新增环境项。无效选项回到默认行为。页面没有增加开发滑块或对照开关。
