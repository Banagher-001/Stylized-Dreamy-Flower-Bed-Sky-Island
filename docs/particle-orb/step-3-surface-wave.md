# 第三步　粒子水球表面起伏

在本地庭院预览地址后加 `?orb=particles&orbMotion=wave`，点击「水潭」看近景。加上 `&waterTime=2.600099999999999` 可停在对照帧。静态对照使用 `?orb=particles&waterTime=2.600099999999999`。 [第二步静态基准](step-2-static-sphere.md)

## 实拍

在 Chromium 155 用正交机位、1440 × 900 视口、DPR 1 和 384 × 211 像素采样拍摄。三张近景用同一机位。下表的秒数可直接用于 `waterTime`。

| 机位与时刻 | 观察位置 | 截图 |
| --- | --- | --- |
| 全景 · 2.600099999999999 秒 | 水球仍读成一个完整的青蓝色球体。 | [全景原图](evidence/step-3/overview.png) |
| 水潭 · 2.600099999999999 秒 | 上缘较同秒静态参考向上约 4 CSS px，约一个采样像素。 | [鼓起](evidence/step-3/water-rise.png) · [同秒静态](evidence/step-2/water.png) |
| 水潭 · 3.5 秒 | 右上弧面开始回收，右下弧面向外推出。 | [推进](evidence/step-3/water-travel.png) |
| 水潭 · 4.5 秒 | 上缘回到静态参考的高度，右缘比鼓起帧向内约 7 CSS px。 | [回落](evidence/step-3/water-recede.png) |

近景录像取自庭院实际播放，从水潭画面中央裁出 448 × 336 区域，按真实时间保留 **8.08 秒**，包含两个主波周期。 [水潭实录 MP4](evidence/step-3/water-motion.mp4)

## 位移与石台连接

顶点着色器用球心出发的三维径向和场景相位算位移，再将点投影到画面。主波振幅为 `0.032` 个场景单位、周期为 `4` 秒，次波为 `0.008`、`2.6` 秒。内部点使用球壳四分之一的位移。保留球底的一小圈为水柱连接面，往上逐渐增加位移权重。

从当前渲染程序读取 GPU 计算的粒子坐标，采样中球壳与内部的最大位移分别约为 `0.0400` 和 `0.0099` 个场景单位。最低粒子中心到石台顶面的间距为 `0.1841`，与水柱顶端有 `0.025` 个场景单位的重叠。实测水球由一次绘制提交 708 个点。覆盖范围通过同帧显隐对比提取。 [顶点着色器](../../src/scene/createParticleOrb.ts) · [参数](../../src/config/orb.ts) · [GPU 和画面实测](evidence/step-3/measurements.json)

## 播放验证

构建及 TypeScript 检查通过。Chromium 软件渲染验证了「暂停环境」与「播放环境」、全景和水潭之间切换、正常与像素画面切换，以及固定时间重开。相同时间在两个画面模式中产生相同的三维位移。重开后同机位画布逐像素一致。默认入口和静态粒子入口的两张基准画布也逐像素对齐。 [验证读数](evidence/step-3/measurements.json)
