# 第五步　水珠脱落与涟漪

本地庭院预览地址加 `?orb=particles&orbMotion=wave&orbFlow=on&orbDrops=on`，点击「水潭」查看。每 **4 秒**，水纹走到左下时引出一颗主水珠，随后约 **0.52 秒**跟一颗较小的水珠，两颗的落点略微错开。 [8.12 秒水潭实录](evidence/step-5/water-motion.mp4)

## 球面、石台与水面

两颗水珠取左下球壳的实际粒子为锚点，分别用 **0.16 秒**和 **0.14 秒**贴球长大。将粒子位移公式的 CPU 结果与 GPU 渲染坐标比较，实测误差小于 `0.000001` 个场景单位。脱落从长成时的同一位置起算，近景里主水珠约占 **1–2 个采样像素**。用稍圆的水珠轮廓，方便在像素模式里跟住第二颗。 [球面采样与出水逻辑](../../src/animation/particleOrbDrops.ts)

用石台的实尺寸计算侧向速度。在覆盖两套波形相位的 28 条实测轨迹中，两颗都先完全越过石台，再到达与石台中心相距 **0.88–0.90** 个场景单位的水面。下落时间约 **0.79 秒**，经过石台顶面高度时的最小外侧净距约 **0.0204** 个场景单位。

首次触水时，水珠的下缘进入池面，现有水面着色器收到该次触水的同一组坐标。涟漪寿命为 **0.65 秒**。水潭截图差分中，主涟漪的可见宽度随年龄从 0.09 秒的 19 CSS px 扩到 0.28 秒的 34 CSS px，圆心落在同一个触水点。 [轨迹、接触与水面读数](evidence/step-5/measurements.json)
