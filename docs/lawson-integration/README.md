# 罗森便利店接入个人网站

目标：把私有仓库 `Banagher-001/luosen-asset` 的罗森便利店场景，作为当前花园个人网站第三根石柱「03 / 交互实验」中的重点 Coding 作品。C2 采用罗森与庭院习作共享展位、切换单件作品的方案；完整场景由作品入口进入。

本轮按七步进行：

1. 罗森场景的运行核查与接入资产整理。
2. 确定展位设计、封面、文案和桌面/手机布局。
3. 建立双作品展位，默认罗森并保留庭院习作。
4. 接入同站独立场景页面和全屏作品体验层。
5. 完成滚轮、键盘、漫游、导览和运行资源的交接。
6. 完善作品档案、触摸与小屏，以及图形不可用时的展示。
7. 整体回归、验收和交付。

当前仅执行第一步。网站的展位、运镜、导览和作品查看器保持基线版本。
