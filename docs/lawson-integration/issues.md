## 环境限制

- 云环境没有 `/dev/dri` 硬件 GPU。SwiftShader 能加载原场景，但持续绘制很慢，导致昼夜等待超时与相机飞行耗时增加。
- 后续通过独立 Xvfb :106 使用 Mesa llvmpipe、三个软件渲染工作线程核查。功能测试通过原设置按钮选择 low；默认画质加载和默认自适应性能分别记录。
- 源循环对 dt 有 0.1 秒上限，低帧率下场景动作与角色任务完成所需墙钟时间会增加。观察窗口必须覆盖真实状态变化，不能通过加速时钟来制造通过。
- 原始 HUD 的 FPS 属于源循环采样值；本步性能诊断另记实际 callback 完成数与墙钟时间。两者均不作为访客硬件帧率保证。
