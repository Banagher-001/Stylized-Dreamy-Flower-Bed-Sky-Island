# 水潭细化第六步 · 整体收口与验收

最终微调集中在池脚。12 块外沿基脚的底面从草面上方 0.005 调到草面下方 0.016 个场景单位，石脚的下缘和倒角接住草面。基脚上沿实测高度与第五步一致。石材贴地一小段随光照压成较暗的灰绿色，从离地 0.005 到约 0.062–0.074 个场景单位向上渐退。 [从第一步到第六步的同机位对照](01-pool-comparison.png)

## 石材、水面与现场光影

- 全景能看清八边轮廓和基脚的接地轮廓。水潭近景复核了 1 号短补石、2 号错台和 7 号缺角。三处共四件实体苔网格已逐件核对闭合状态，苔根在对应石面内约 0.002 个场景单位。 [近景与落点标注](02-pool-details.png)
- 水位为 Y = 0.32。第 6 段两块斜面浅石分别穿过该水位，湿线和反光沿各自的入水边收住。左后第 3、4 段的深蓝倒影和石台左前的清蓝水域在同机位逐点复核。
- 云影复拍取场景时钟 **129.4、161.4、205.4 秒**，对应池面中央取样点的经过前、经过时和离开后。覆盖时，清蓝水域局部平均每个颜色通道降低约 5.8 个色阶，以 8 位色值计。半浸浅石的水线仍可辨认，深蓝倒影仍贴着左后岸。
- 在桌面正常与像素画面分别复核 **5.14656 秒和 5.67306 秒**的入水及其扩散。两次落水的触水亮点、主环和余波近景，与第五步同一时间取样的画面逐像素一致。26 条已有轨迹均通过复核。
