# 第六步　原网页功能对照验收

将生产构建里的同一份原网页分别独立打开和放进「交互实验」作品窗口。逐项通过原网页的按钮、滑杆、鼠标、按键和触屏操作，读取实际画布、场景状态和下载文件。轮流打开两种形态，按各测试的内嵌画布尺寸与 DPR 设置独立页。通用桌面对照是 1198 × 559 CSS px，触屏竖屏与短横屏分别是 337 × 473 和 779 × 380 CSS px。有界面 Chromium 的全屏测试先在 1087 × 504 CSS px 的作品窗口测量，再核对浏览器退出和画布重绘。

配对测试用网页现有按钮暂停个人站的环境动效，正式浏览回归另外通过主站入口执行。长时间的自然运动测试使用原控件选择罗森低画质和 1.8 倍车速，以及瓶中海洋的复古画质。轨迹从原模拟时钟采集，配对比较同一参数下的实际响应。

## 罗森便利店

| 项目 | 验收动作与观测结果 |
| --- | --- |
| 界面与灯光 | 对照 41 个原控件。操作三个时段、时间滑杆、八组灯光、全开和全关，读取实际天空、光源与发光材质。验证三档画质、说明开合、控制台收展。 |
| 镜头与点选 | 通过原按钮操作八个镜头、屋顶、重置及两位店员。通过鼠标旋转、平移和缩放。对 17 类场景目标做真实点选，核实命中与门、灯光或镜头反馈。测试用原相机辅助接口取景，动作由鼠标点击触发。 |
| 车流 | 按实际速度按钮检查慢速、正常、快速，检测暂停时位置和车轮冻结、继续与重置。记录三辆车各自进场、停车、亮倒车灯、倒出和驶离的原路线。 |
| 浏览器功能 | 原按钮进入全屏、测量重新绘制，通过原按钮和系统 Esc 两条路径退出。验证鼠标锁定、鼠标观察、横移、加速及退出后的控件。 |
| 真实故障 | 控制性地让主模型返回 HTTP 404。独立页通过原重试按钮恢复，内嵌通过作品窗口重新载入。两边恢复后重新切到白天。 |

罗森已有的漫游限制在同一份原网页上复现。默认出生点的 W/S 受到碰撞约束，A/D 和左右 Shift 有实际位移反馈。漫游中直接按 R 后，实际镜头退出与原界面提示的状态同步存在差异。旋转后按 R 在两端都进入全景预设，独立页和内嵌窗口的实测地标偏移分别为 29 和 26 CSS px。原说明里的 N 在当前页面没有对应 HUD 动作。

## 瓶中海洋

| 项目 | 验收动作与观测结果 |
| --- | --- |
| 原控制台 | 对照 34 个原控件。对 12 根滑杆测试低、中、高与步进，检查原参数及波形、光照、玻璃和像素后处理的绑定。操作三档画质、灯塔、水雾、尘粒、面板收起和控制台隐藏恢复。 |
| 镜头与沙盒 | 通过五个原始镜头和鼠标旋转、平移、缩放。点选瓶子、地形和灯塔，实测放置石头、贝壳、撤销、复原和代表性放置边界。 |
| 模拟与导出 | 检查低浪、高浪、船体响应、阻尼及强浪高水位组合。比对水面采样、船姿及模拟和渲染的时钟。验证暂停、继续和重置。验证桌面、触屏高 DPR 及隐藏界面后恢复控制台时的原 PNG 下载。 |
| 真实故障 | 通过浏览器的 WebGL 上下文丢失扩展触发原错误。独立页通过刷新恢复，内嵌用同处重载按钮恢复。恢复后重新操作波高和暂停。 |

默认亮度的原内部值为 0.82，原滑杆按步进显示 0.8。原「标准」画质的内部像素倍率为 2.85，滑杆显示 2.9。相机拖动后的惯性、暂停时保留画面绘制和交互也按原页行为记录。沙盒验收覆盖实际命中的代表区域，原场景的碰撞和放置判定由原页负责。本轮 Chromium 在隐藏控制台后会清除原截图按钮的键盘焦点，两端均通过恢复控制台后点击原按钮完成导出。

## 主站和证据

手机竖屏和短横屏对照真实触屏事件，包括展开原控制台、触碰滑杆、内部滚动到底及访问底部操作。桌面核对主站导览接管、键盘焦点和项目档案边界，并浏览全景、关于我、AI 影像、交互实验及水潭。触屏设备为 Chromium 模拟。

主站回归发现稳定阅读下展开档案会改变当前章节高度。原本用于恢复阅读位置的测量程序会把第一次滚轮拉回。修复后，在展开和收起档案时同步记录当前阅读位置。两次浏览器复测都从 `scrollY = 7209` 滚到 `7449` 并保持在该位置，沉浸档案的内部滚动也通过复测。

完整原功能对照先在修复前执行。档案修复只涉及主站的档案开合和阅读位置记录。最终构建复测主站、作品切换、阅读模式切换、两页原控件、触屏和 PNG 导出。两版的 49 个原网页与资源文件逐项核对 SHA-256，验收记录标注每项对应的构建。
