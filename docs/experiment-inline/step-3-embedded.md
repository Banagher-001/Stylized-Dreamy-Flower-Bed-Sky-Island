# 交互实验同屏改版 · 第三步原网页接入

到达第三根石柱的作品窗口后，默认自动载入罗森便利店。用上方两个标签可在同一个窗口切换到瓶中海洋。窗下展开「项目档案」时，场景继续运行。在水潭章节可进入庭院现场，再打开它的档案。 [桌面罗森](evidence/step-3/desktop-lawson.png) · [桌面瓶中海洋](evidence/step-3/desktop-bottle.png)

## 窗口与加载

两个原网页各自在 iframe 内运行，使用第二步的画面尺寸和生产站点内的原入口。沉浸模式在作品站可操作时开始载入，稳定阅读在窗口进入视口时开始载入。封面在载入期间留在位置上，等原页面完成渲染并收起自己的加载层后，直接显示可操作场景。离开窗口或换作品时释放原 iframe，后续响应由当前窗口核对。

超过 12 秒显示慢载提示，失败时可以在原位置重新载入。切换标签时可以立即更换场景。自动导览会先等待窗口状态，再开始该站的阅读计时。 [加载失败与重试](evidence/step-3/inline-error.png)

档案默认收起。桌面展开时使用窗下按钮旁的可滚动区域，按 `Esc` 可收起并返回按钮。稳定阅读将档案接在窗口下方。短横屏的窗口仍有 380 CSS px 高，顶部控件被页眉遮住时，可从窗口外滑动页面，露出后点按。 [手机竖屏](evidence/step-3/phone-bottle.png) · [手机横屏](evidence/step-3/landscape-bottle.png)

## 验证

- 桌面直接拖动罗森画布使原镜头移动，切换到瓶中海洋后用原滑杆将波高从 35 调到 100。窗口尺寸、地址、页面滚动位置及主站镜头保持一致。
- 手机竖屏与横屏用触屏模拟操作两个原控制面板。原网页回归还检查了罗森的昼夜、灯光、屋顶、帮助与视角，以及瓶中海洋的画质、装饰放置与撤销、暂停和 PNG 导出。水潭的庭院档案实际播放了原片段。
- 在本机预览中控制罗森入口的响应，验证慢载切换后旧响应不占用窗口，以及错误后原位重试。生产构建的 `/` 与 `/sakan/` 入口均完成两场景切换验证。
- `npm run build` 和 13 项 Chromium 检查通过，覆盖主站的桌面、手机、键盘和减少动态浏览流程。两个原网页的 49 个文件在上一步记录、当前源码和 `dist` 中的 SHA-256 一致。 [验收记录](evidence/step-3/acceptance.json) · [构建清单](evidence/step-3/build.json)
