# 交互实验同屏改版 · 第五步窗内外操作

访客可在罗森便利店和瓶中海洋的窗口内拖动镜头、缩放和操作原控制面板。回到窗口外，下一次滚轮或滑动会继续浏览庭院。短横屏可以从窗口外滑动，先后露出原网页的上部和下部控件。 [罗森窗口](evidence/step-5/lawson.png) · [瓶中海洋窗口](evidence/step-5/bottle-ocean.png)

## 输入处理

- 滚动边界应用在当前原网页的根节点和原生滚动面板上。罗森使用 `#panel`，瓶中海洋使用 `.panel-scroll`。面板滚到边缘后，剩余的输入由原网页接收。拖动和双指缩放沿用原画布控制器的指针捕获。
- 加载、慢载和失败时，封面收到的滚轮随主站滚动。失败后点击重试，原位载入的场景继续接收输入。沉浸浏览的浮层档案自己滚动，稳定阅读的档案随正文滚动。
- 可从作品标签用 `Tab` 进入原控件，从首项用 `Shift+Tab` 返回标签，从末项继续按 `Tab` 到项目档案。方向键可调整原滑杆，`Esc` 可取消瓶中海洋的原生编辑。主站完成临时布局测量后会恢复仍可用的原焦点。
- 自动导览收到场景里的首次真实操作后交还浏览控制。子页自己的事件继续执行，包含拖动、滚轮、触控和键盘。切换、重试或离场会随当前文档清理监听和滚动样式。

## 浏览器实测

| 用例 | 实测结果 |
| --- | --- |
| 两个原画布拖动和滚轮缩放 | 子页镜头实际变化。主站保持原地址、`scrollY = 9045` 和镜头进度 `10.05`。 |
| 控制面板滚到上下边缘 | 罗森滚动区间为 0 至 552 CSS px，瓶中海洋为 0 至 463 CSS px。越过边缘仍在原站。移到窗外后滚至水潭，镜头进度到达 `11.5`。 |
| 键盘进入、退出与布局测量 | 实际遍历了两个子页的控件。快速切换后焦点留在所选标签，窗口调整后瓶中海洋仍聚焦波高滑杆。 |
| 自动导览 | 悬停时继续。实际滚动滚轮、拖动、按方向键或触控都会停止导览，同一位置可重新开启。 |
| 手机竖屏与短横屏 | 337 × 473 和 779 × 380 CSS px 的场景窗口通过触屏模拟。核对了滑杆、面板上下端、单指拖动、双指缩放和跨边界滑动。原网页独立打开的双指缩放也通过。 |
