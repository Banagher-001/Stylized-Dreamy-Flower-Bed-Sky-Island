# 交互实验同屏改版 · 第一步作品范围

「交互实验」的作品站 C2 使用两项清单。左侧是默认选中的「LAWSON 罗森便利店」，右侧是「BOTTLE OCEAN 瓶中海洋」。点击、触屏点按和键盘共用这组顺序，标题、封面、简介和档案跟随选中的作品。庭院可以从首页和水潭体验入口到达。[改动前三项](evidence/step-1/desktop-before.png) · [桌面两项](evidence/step-1/desktop-two-tabs.png) · [390px 两项](evidence/step-1/phone-two-tabs.png)

## 两个原网页的接入清单

| 作品 | 原网页入口 | 场景和控件 | 档案 |
| --- | --- | --- | --- |
| 罗森便利店 | `experiments/lawson/index.html` | 拖动、缩放和预设视角，昼夜、灯光和屋顶，店员和车辆，帮助和面板折叠。本步从环绕切到室内，回读相机模式，核对到 41 个按钮、输入和开关元素 | 「一间店，几个日夜。」及罗森场景资料 |
| 瓶中海洋 | `experiments/bottle-ocean/index.html` | 拖动、缩放和预设视角，风浪与水位、画质和播放控制，沙滩布置、撤销与截图下载。本步将波高从 35 调到 100，回读作品状态，核对到 34 个按钮与输入元素 | 「让一片海，托起一艘船。」及黄昏海岸资料 |

两个原网页入口及资源逐文件与上轮生产版核对，源码和构建中都匹配原来的 SHA-256。完整的控件记录用于后续同屏接入复验。[罗森原网页验收](../lawson-fullpage/step-7-verification.md) · [瓶中海洋原网页验收](../beach-bottle-boat/step-7-verification.md)

## 本步验收

| 场景 | 实测 |
| --- | --- |
| 首次进入与桌面切换 | 桌面 1652 × 949，双标签各 220 CSS px。罗森默认选中。往返切换时地址、滚动位置和镜头目标原位 |
| 键盘 | `Tab` 到达选项，左右键循环，`Home` 到罗森，`End` 到瓶中海洋。每次只有一个选中项且焦点可见 |
| 390px 窄屏 | 每格 156.5 CSS px，两个名称完整可读。点按任一项均可切换 |
| 原网页与档案 | 两个原网页均通过现有按钮打开。代表控件有实测响应，档案对应作品，关闭后接回当前选项 |
| 水潭 | 沉浸浏览正常到达水潭。稳定阅读的「进入庭院现场」能打开庭院，正常和像素画面均可切换 |

窄屏复核时复现过排版测量重新显示「封面载入中」的问题。封面已就绪时，排版切换会按当前加载结果恢复提示。最终构建的触屏用例等到新一轮排版测量完成后复查，瓶中海洋封面仍可见。

`npm run build` 成功。最终生产版通过 8 项浏览器检查，包含本步的桌面与触屏用例、前后章节和两页原有体验。触屏使用 Chromium 模拟。[逐项验收数据](evidence/step-1/acceptance.json) · [构建清单](evidence/step-1/build.json)
