## 访客路线

| 验收内容 | 实测结果 |
| --- | --- |
| 沉浸浏览的作品窗口 | 1440 × 900 桌面下，两部作品均使用 1198 × 559 CSS px 的画布。点击两个标签即可在原窗口切换，主站地址与浏览位置保持原位。 |
| 独立成品的连续操作 | 从解压目录启动后，在同一页完成罗森昼夜、灯光、拖动和全屏。按系统 Esc 返回，继续打开原帮助。切换到瓶中海洋后调节波高、切换镜头、暂停及继续并下载 PNG。再切回罗森，滚至水潭释放场景，返回后恢复当前选中的作品。 |
| 快速切换和阅读模式 | 正常往返、同一帧内连续选择及旧响应迟到均通过。作品窗口最多有一个活动场景。调整窗口或切换阅读模式时，保留仍可见的场景。 |
| 慢载、失败和重载 | 验证了现有 12 秒慢载提示、当前作品原位重载和加载时切换。模拟罗森模型缺失与瓶中海洋图形连接中断后，重载成功，并在恢复的原网页中操作控件，再切换到另一作品。 |
| 鼠标、键盘和触屏 | 窗内滚轮与控制台滚动由原作品接收，窗外可继续浏览主站。键盘可进入原控件并继续到档案。390 × 844 竖屏和 844 × 390 短横屏触屏模拟通过画布拖动、双指缩放、面板滚动和底部控件。 |
| 主站和档案 | 全景、关于我、AI 影像、交互实验和水潭连通。工具卡飞入、横移、详情和导览交还均通过。稳定阅读下展开档案后，第一次滚轮把 `scrollY` 从 7209 移到 7449，待布局完成后仍停留在 7449。沉浸档案也保持自己的滚动区域。 |

有界面的 Chromium 在稳定阅读下验证了独立成品，原画布为 1087 × 504 CSS px。罗森进入全屏后实际重绘到 1440 × 900，瓶中海洋的原按钮导出 1087 × 504 PNG。测试使用原界面选择低画质或复古画质。实际小屏操作由 Chromium 模拟。[罗森沉浸窗口](evidence/step-7/lawson-in-portfolio.png) · [瓶中海洋沉浸窗口](evidence/step-7/bottle-in-portfolio.png) · [原控件下载的 PNG](evidence/step-7/bottle-original.png)

第六步记录的独立页边界可用于解释漫游出生点的 W/S 碰撞、罗森 R 复位偏移，以及瓶中海洋隐藏控制台后的截图焦点行为。[原网页对照报告](step-6-parity.md)

## 本地成品

成品包包含已验收的生产网站、预览脚本、Windows 入口和简明说明。75 个归档条目通过完整性校验，并从独立目录解压启动了 Node.js 预览。验收环境使用 Node.js 24.22.1。[下载当前成品](../../release/experiment-inline-step7-4901f6d5c2824013-site.zip) · [成品包校验](evidence/step-7/package-verification.json)
