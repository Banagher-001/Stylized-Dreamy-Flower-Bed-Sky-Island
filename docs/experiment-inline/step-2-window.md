## 交互验收

- 从前一站进入作品窗口后，页眉、右侧导航和底部控件可用。测试用真实滚轮从场景外继续到 C3，再用章节导航到达水潭。手机竖屏和横屏使用触屏模拟滑动。
- 轮流点按两标签，测量了封面载入中和载入完成后的窗口。画面位置与宽高差在 1 CSS px 内，地址、页面滚动位置和镜头目标保持稳定。两个标签和预览的键盘关联继续通过。
- 五组视口共执行十次原网页尺寸核对。罗森的控制面板可折叠和展开，能到达末尾的重置视角，并实际切换屋顶。瓶中海洋的面板可折叠和展开，能调波高并触达恢复装饰及截图入口。手机首次核对在面板展开过渡中取样，后来等原页面板展开完成后通过。
- `npm run build` 成功。共 14 项检查通过，包括桌面、窄屏、200% 缩放、双标签、原有章节、作品档案和两个原网页的回归。两个原网页的 49 个源资源均通过摘要核对。[逐项验收数据](evidence/step-2/acceptance.json) · [构建清单](evidence/step-2/build.json)

第三步以 `.experiment-window-stage` 为挂载区域，用已经核对的尺寸接入两个原网页。桌面窗口接收 `--experiment-stage-height`，正文窗口随视口调整。本步的封面和已有入口用于布局验收。
