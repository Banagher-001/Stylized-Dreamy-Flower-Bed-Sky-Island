# 交互实验同屏改版 · 第四步切换与场景生命周期

作品窗口首次进入时载入罗森便利店。切换标签时，标题、简介、封面和档案跟随当前作品。重复点按当前标签会保留正在运行的场景。离开窗口会释放场景，回到窗口时会重新载入上一次选中的作品。刷新页面后从罗森开始。

## 切换与恢复

- 同一布局帧内的多次选择以最后一次为准。切换时先释放旧网页的 `iframe` 和监听，再挂载新网页。就绪、慢载和失败回调均校验当前挂载实例，包含快速切回同一个项目的情况。
- 真实离场后保留作品选择。调整窗口尺寸或切换阅读布局时，按最终布局判断窗口是否仍在可用区域。可见的窗口继续使用当前场景实例。
- 切到浏览器后台时保留场景，暂停主站对原网页的轮询和慢载计时。回到前台时立即读取进度。12 秒的慢载阈值只累计前台等待时间。
- 慢载或失败时可以原位重试，也可以直接选另一个作品。

## 实测结果

| 检查 | 结果 |
| --- | --- |
| 罗森 → 瓶中海洋 → 罗森，两次旧响应延迟到最后返回 | 当前窗口显示最后一次罗森，挂载峰值为一个 `iframe`。 |
| 同一布局帧内连续选瓶中海洋、罗森、瓶中海洋 | 连续输入后仅发出最后一次瓶中海洋的入口请求。 |
| 重复点按瓶中海洋的标签 | 波高维持 100，场景实例和入口请求次数保持一致。 |
| 离开到水潭再返回，随后刷新 | 返回后载入瓶中海洋，原网页波高初始化为 35。刷新后载入罗森。 |
| 调整窗口大小并切换稳定与沉浸布局 | 继续使用同一个瓶中海洋实例，波高保持 100。 |
| 真实浏览器标签页切到后台再回来 | 罗森在后台等待 13.23 秒后仍处于加载，累计前台等待 12.17 秒时出现慢载提示。瓶中海洋返回后保留波高 100 和暂停状态，仍可用原按钮继续模拟。 |
